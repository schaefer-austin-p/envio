# Envio Plan 4: envio-net Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/envio-net`: TLS with trust-on-first-use certificate pins, an SMTP client (lettre) and an IMAP client (async-imap) with the operations sync needs, and account autoconfig (ISPDB, the provider's autoconfig URL, the well-known URL, DNS SRV, then a guess for the manual form). Integration tests run against Stalwart in Docker, locally and in CI, with a TCP proxy that cuts connections mid-command.

**Architecture:** Async on tokio. Core's worker thread (Plan 6) owns a current-thread tokio runtime and drives envio-net from it, so net never spawns threads or its own runtime. Decisions are pure functions with unit tests: the trust verdict (`trust.rs`), SMTP reply parsing (`smtp/reply.rs`), IMAP query building and folder names (`imap/query.rs`, `imap/names.rs`), and the autoconfig order and choice (`autoconfig/plan.rs`, `autoconfig/xml.rs`). The I/O around them is thin: `tls.rs` wraps rustls, `smtp/` wraps lettre, `imap/` wraps async-imap, `autoconfig/http.rs` and `autoconfig/srv.rs` do one HTTPS GET and one SRV query. Pins are plain values on `Endpoint`, so net keeps no state and depends on no other envio crate; envio-store gets fields to keep them (#19).

**Tech Stack:** Rust 1.94 (edition 2024), tokio 1.54, rustls 0.23.46 with ring, tokio-rustls 0.26.6, rustls-native-certs 0.8.5, async-imap 0.12.0 (tokio), lettre 0.11.23 (SMTP only), hickory-resolver 0.26.3, quick-xml 0.42.0, secrecy 0.10.3, thiserror 2, ring 0.17.14; rcgen 0.14.10 in tests; Stalwart v1.0.3 in Docker.

**Spec:** `docs/superpowers/specs/2026-11-07-envio-design.md`, sections "Architecture", "Passwords, certificates, privacy", "Error handling" and "Testing and CI". Issues: #19 (pins and TLS mode outside the cache), #6, #9 and #10 (CI and xtask).

## Global Constraints

- `rust-version = "1.94"`, `edition = "2024"`, licence `GPL-3.0-only`, all from `[workspace.package]`; the crate has `[lints] workspace = true`.
- The core is Qt-free; `unsafe_code = "forbid"` in the root workspace.
- Dependencies point one way: core → sync → net, store, mime. `envio-net` depends on no other envio crate; store and mime never depend on net.
- Logic kept out of I/O code: pure planners, thin drivers.
- **TLS only.** Implicit TLS (993, 465) preferred; STARTTLS required where offered, never a plaintext fallback. Certificates checked against the system roots. A self-signed certificate is accepted only through the fingerprint prompt and pinned per account. A changed pin stops sync and shows old and new fingerprints; it is never accepted on its own.
- Passwords are held in `secrecy` types, never in logs or error text.
- A generic SMTP EHLO name instead of the device's hostname. Autodetect sends only the domain to the ISPDB.
- No user-facing text here: errors are kinds that core words with gettext. Error `Display` text is for logs only.
- Files around 300 lines; one concept per module.
- Single-crate integration tests go in `crates/envio-net/tests/`.
- Clippy: `clippy::all` plus `cognitive_complexity` (threshold 15), `too-many-arguments-threshold = 4` (at most 4 parameters, `self` included); CI runs clippy with `-D warnings`.
- `cargo make ci` (fmt, clippy, tests, audit) must pass.

## Decisions (where the brief and spec leave a gap)

1. **Runtime: tokio**, `net`, `time`, `io-util` and `rt` only. Core's worker thread builds a current-thread runtime and `block_on`s net's futures (Plan 6); net spawns nothing in library code. async-imap and lettre both have tokio backends, so there is one runtime and no compat layer.
2. **ring, not aws-lc-rs.** rustls's default provider, aws-lc-rs, builds aws-lc from C with cmake and needs a working C cross toolchain plus bindgen or its prebuilt bindings for aarch64; clickable's arm64 image cross-compiles ring with plain `cc` (checked: `cargo build --target aarch64-unknown-linux-gnu` in `clickable/amd64-ut24.04-2.x-arm64`). Every crate that pulls rustls has default features off and `ring` on (rustls, tokio-rustls; lettre and async-imap use our stream, not their own TLS), and `cargo tree -i aws-lc-rs` must report no match.
3. **The pin is a value, not a callback.** `Endpoint.pin: Option<Fingerprint>`. With a pin, only the pin counts (system roots are not consulted; a match is accepted even if expired). Without one, the system roots decide; a failure is `NetError::Untrusted { presented, reason }`. That error is the self-signed prompt hook: the wizard shows `presented.display()`, and if the user accepts, the caller stores the fingerprint as the pin and connects again. A pin mismatch is `NetError::PinChanged { pinned, presented }` and is never accepted here. The fingerprint is SHA-256 of the leaf certificate's DER (ring's digest).
4. **#19: pins and TLS mode live in envio-store's `accounts.json`**, not in the SQLite cache, so a cache rebuild can't drop a pin and quietly trust the next certificate. Store gets its own `Security` enum and `pin: Option<String>` (hex) on `Server`; net's `Fingerprint::to_hex`/`from_hex` is the format. Core maps between the two (Plan 6), so neither crate depends on the other. The file version goes to 2; version 1 files read as implicit TLS without pins; a malformed pin is refused on read and never written. #19's allow-list of other settings is left to Plan 6, which owns the settings that core adds.
5. **EHLO name `[127.0.0.1]`** (an address literal, RFC 5321 4.1.3), the same on every device.
6. **SMTP**: lettre's `AsyncSmtpConnection` over our own stream. Implicit TLS uses `tls::connect`; STARTTLS is done by us (`smtp/starttls.rs`) before lettre sees the connection, because lettre's own STARTTLS would need its TLS feature and its verifier. After `220 ready`, any byte the server already sent is refused (the STARTTLS injection attack). Authentication tries PLAIN, then LOGIN.
7. **IMAP sign-in uses LOGIN only** (the password as a quoted string; async-imap quotes it). AUTHENTICATE PLAIN adds nothing over TLS for the servers 0.1.0 targets. A PREAUTH greeting on the STARTTLS port is refused before anything is sent, since it means the server never asked for TLS.
8. **Move without MOVE**: `UID COPY`, then `+FLAGS.SILENT (\Deleted)`, then `UID EXPUNGE` only when the server has UIDPLUS. Without UIDPLUS, the messages stay flagged \Deleted: a plain EXPUNGE would remove other messages the user deleted elsewhere.
9. **Finding a message by Message-ID** (what sync needs after a cut APPEND or a UIDVALIDITY change): `UID SEARCH HEADER Message-ID <id>` first. Stalwart v1.0.3 never matches that search, so when it comes back empty, net fetches `BODY.PEEK[HEADER.FIELDS (MESSAGE-ID)]` for the newest `SCAN = 200` messages (by sequence number, from EXISTS at SELECT) and compares. A just-appended message is always within that window.
10. **Autoconfig**: https only (a plain-http answer could come from anyone on the path); no User-Agent; at most 256 KiB and 3 redirects; no trust prompt (an untrusted certificate is "no answer", and autoconfig moves on). Order: ISPDB (`autoconfig.thunderbird.net/v1.1/<domain>`), `autoconfig.<domain>/mail/config-v1.1.xml`, `<domain>/.well-known/autoconfig/mail/config-v1.1.xml`, then SRV (`_imaps`, `_imap`, `_submissions`, `_submission`), then the guess `imap.<domain>:993` and `smtp.<domain>:465` with implicit TLS. Plain (`socketType` plain) servers are skipped; among candidates, implicit TLS wins. A result needs both an IMAP and an SMTP server. The lookups sit behind a `Lookups` trait, so the order is tested without a network.
11. **Timeouts**: 20 s to connect (`CONNECT_TIMEOUT`), 60 s per command (`COMMAND_TIMEOUT`). Any error leaves an IMAP or SMTP session unusable; the caller drops it and opens a new one. Temporary errors (`NetError::is_temporary`) are `Io`, `Timeout` and `Busy`.
12. **Stalwart runs from a script, not a job service.** The spec says "Stalwart as a job service", but Stalwart 1.0 starts in bootstrap mode and needs two API calls and two restarts before it has users and STARTTLS listeners, which a service container can't do. `crates/envio-net/tests/stalwart/up.sh` does it against any Docker daemon and prints the ports. Locally: `cargo make net-it`. In CI: `tools/ci/stalwart.sh` runs `up.sh` against the runner's dind daemon (see "How the Stalwart tests run").
13. **Tests skip without Stalwart** unless `ENVIO_REQUIRE_STALWART=1`, which CI and `cargo make net-it` set, so a missing server fails there instead of passing quietly. Each test uses a fresh Message-ID, so tests share one server and can run in parallel.
14. **#16 is out of scope**: it is not needed by envio-net and isn't cheap. #6, #9 and #10 are Task 10.

## How the Stalwart tests run

- **Locally:** `cargo make net-it` runs `up.sh` against the local Docker daemon (container `envio-stalwart`, random host ports on 127.0.0.1, removed after 30 minutes), then `ENVIO_REQUIRE_STALWART=1 cargo test -p envio-net`. To rerun tests against the same server: `eval "$(crates/envio-net/tests/stalwart/up.sh)"` once, then `ENVIO_REQUIRE_STALWART=1 cargo test -p envio-net`. Without Docker, `cargo test -p envio-net` still runs every unit test and the fake-server tests; the Stalwart tests return early.
- **In CI:** the Forgejo runner runs job containers inside a dind daemon. The job container has no docker CLI and no `DOCKER_HOST`; the daemon is its default gateway on port 2375, and ports Stalwart publishes live on that daemon. `tools/ci/stalwart.sh` installs the static docker CLI (27.5.1) if needed, reads the gateway from `/proc/net/route`, names the container per run (`envio-stalwart-<run id>-<attempt>`, since the daemon is shared), runs `up.sh` and writes the ports and `ENVIO_REQUIRE_STALWART=1` to `$GITHUB_ENV`. A step after the tests removes the container under `if: always()`. The start step only runs when the picked crates include envio-net (or everything).
- **Fault injection:** `tests/support/proxy.rs` is an in-process TCP proxy between the client and Stalwart that cuts every open connection after a byte budget in one direction. The tests cut a FETCH, an APPEND and SMTP DATA halfway and check that the error is temporary and that the retry leaves exactly one copy.

```rust
//! How to reach and trust a server: host, port, TLS mode and the pinned
//! certificate, if the user accepted a self-signed one.

use std::fmt;

use secrecy::SecretString;

/// How the connection becomes encrypted. There is no plaintext mode.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Security {
    /// TLS from the first byte (IMAP 993, SMTP 465). Preferred.
    Tls,
    /// Plain connect, then STARTTLS before anything else (IMAP 143,
    /// SMTP 587). A server that doesn't offer it is an error.
    StartTls,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Endpoint {
    pub host: String,
    pub port: u16,
    pub security: Security,
    /// The accepted certificate. When set, only this certificate is
    /// trusted for this server, whatever the system roots say.
    pub pin: Option<Fingerprint>,
}

impl Endpoint {
    pub fn new(host: &str, port: u16, security: Security) -> Self {
        Self {
            host: host.to_owned(),
            port,
            security,
            pin: None,
        }
    }
}

/// The SHA-256 of a certificate's DER bytes.
#[derive(Clone, Copy, PartialEq, Eq, Hash)]
pub struct Fingerprint([u8; 32]);

impl Fingerprint {
    pub fn of(der: &[u8]) -> Self {
        let digest = ring::digest::digest(&ring::digest::SHA256, der);
        let mut bytes = [0; 32];
        bytes.copy_from_slice(digest.as_ref());
        Self(bytes)
    }

    pub fn from_bytes(bytes: [u8; 32]) -> Self {
        Self(bytes)
    }

    pub fn as_bytes(&self) -> &[u8; 32] {
        &self.0
    }

    /// 64 lowercase hex digits, the form settings files keep.
    pub fn to_hex(&self) -> String {
        self.0.iter().map(|b| format!("{b:02x}")).collect()
    }

    /// Reads [`Fingerprint::to_hex`]'s form; any case, no separators.
    pub fn from_hex(text: &str) -> Option<Self> {
        // from_str_radix alone would take a "+" sign.
        if text.len() != 64 || !text.bytes().all(|b| b.is_ascii_hexdigit()) {
            return None;
        }
        let mut bytes = [0; 32];
        for (i, byte) in bytes.iter_mut().enumerate() {
            *byte = u8::from_str_radix(&text[i * 2..i * 2 + 2], 16).ok()?;
        }
        Some(Self(bytes))
    }

    /// Uppercase pairs joined by colons, as the certificate prompt shows it.
    pub fn display(&self) -> String {
        self.0
            .iter()
            .map(|b| format!("{b:02X}"))
            .collect::<Vec<_>>()
            .join(":")
    }
}

impl fmt::Debug for Fingerprint {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "Fingerprint({})", self.to_hex())
    }
}

/// A sign-in. The password stays in a `SecretString`, which is wiped when
/// dropped and never printed by `Debug`.
#[derive(Debug, Clone)]
pub struct Credentials {
    pub username: String,
    pub password: SecretString,
}

impl Credentials {
    pub fn new(username: &str, password: &str) -> Self {
        Self {
            username: username.to_owned(),
            password: SecretString::from(password.to_owned()),
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn a_fingerprint_is_the_sha256_of_the_der() {
        // SHA-256 of the empty input.
        let fp = Fingerprint::of(b"");
        assert_eq!(
            fp.to_hex(),
            "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
        );
        assert!(fp.display().starts_with("E3:B0:C4:42:"));
        assert_eq!(fp.display().len(), 32 * 3 - 1);
    }

    #[test]
    fn hex_round_trips_in_either_case() {
        let fp = Fingerprint::from_bytes([0xab; 32]);
        assert_eq!(Fingerprint::from_hex(&fp.to_hex()), Some(fp));
        assert_eq!(Fingerprint::from_hex(&fp.to_hex().to_uppercase()), Some(fp));
    }

    #[test]
    fn malformed_hex_is_refused() {
        assert_eq!(Fingerprint::from_hex("ab"), None);
        assert_eq!(Fingerprint::from_hex(&"g".repeat(64)), None);
        // u8::from_str_radix alone would read "+f" as 15.
        assert_eq!(Fingerprint::from_hex(&"+f".repeat(32)), None);
    }

    #[test]
    fn debug_never_shows_the_password() {
        let creds = Credentials::new("alice", "hunter2");
        assert!(!format!("{creds:?}").contains("hunter2"));
    }
}
```

`crates/envio-net/src/error.rs`:

```rust
//! One error type for the crate. Each variant maps to one of the spec's
//! failure kinds, which core picks (and words, with gettext): `Io`,
//! `Timeout` and `Busy` are temporary; `SignIn` pauses the account;
//! `Untrusted` asks the user; `PinChanged` stops sync; `Refused` is an
//! error on that item. The text here is for logs only and never holds a
//! password.

use std::io;

use crate::server::Fingerprint;

#[derive(Debug, thiserror::Error)]
pub enum NetError {
    #[error("network: {0}")]
    Io(#[from] io::Error),
    #[error("timed out")]
    Timeout,
    /// No pin, and the system roots don't vouch for the certificate. The
    /// wizard shows the fingerprint; if the user accepts, the caller
    /// stores it as the endpoint's pin and connects again.
    #[error("certificate not trusted ({reason:?})")]
    Untrusted {
        presented: Fingerprint,
        reason: Untrusted,
    },
    /// A pinned server showed another certificate. Never accepted here.
    #[error("certificate changed")]
    PinChanged {
        pinned: Fingerprint,
        presented: Fingerprint,
    },
    #[error("TLS: {0}")]
    Tls(String),
    /// STARTTLS was asked for and the server didn't offer or refused it.
    #[error("the server offers no STARTTLS")]
    NoStartTls,
    #[error("sign-in rejected: {0}")]
    SignIn(String),
    /// The server is up but said "not now" (SMTP 4xx, IMAP BYE).
    #[error("server busy: {0}")]
    Busy(String),
    /// The server refused this request for good (SMTP 5xx, IMAP NO).
    #[error("refused by the server: {0}")]
    Refused(String),
    #[error("protocol: {0}")]
    Protocol(String),
}

/// Why the system roots didn't vouch for a certificate.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Untrusted {
    /// Self-signed, or signed by a CA the system doesn't know.
    UnknownIssuer,
    Expired,
    /// Valid, but for another host name.
    WrongName,
    Other,
}

impl NetError {
    /// Worth retrying with backoff.
    pub fn is_temporary(&self) -> bool {
        matches!(self, Self::Io(_) | Self::Timeout | Self::Busy(_))
    }
}

pub type Result<T> = std::result::Result<T, NetError>;
```

```rust
//! Test certificates and an in-process TLS acceptor.

use std::sync::Arc;

use rcgen::{BasicConstraints, CertificateParams, CertifiedIssuer, IsCa, KeyPair};
use rustls::ServerConfig;
use rustls::pki_types::{CertificateDer, PrivateKeyDer, PrivatePkcs8KeyDer};
use tokio_rustls::TlsAcceptor;

/// A server certificate with its key.
pub struct Cert {
    pub der: Vec<u8>,
    key: Vec<u8>,
}

impl Cert {
    /// Self-signed for `name`, like a home server's.
    pub fn self_signed(name: &str) -> Self {
        let made = rcgen::generate_simple_self_signed(vec![name.to_owned()]).unwrap();
        Self {
            der: made.cert.der().to_vec(),
            key: made.signing_key.serialize_der(),
        }
    }

    pub fn acceptor(&self) -> TlsAcceptor {
        let provider = Arc::new(rustls::crypto::ring::default_provider());
        let key = PrivateKeyDer::Pkcs8(PrivatePkcs8KeyDer::from(self.key.clone()));
        let config = ServerConfig::builder_with_provider(provider)
            .with_safe_default_protocol_versions()
            .unwrap()
            .with_no_client_auth()
            .with_single_cert(vec![CertificateDer::from(self.der.clone())], key)
            .unwrap();
        TlsAcceptor::from(Arc::new(config))
    }
}

/// A private CA that signs server certificates.
pub struct Ca {
    issuer: CertifiedIssuer<'static, KeyPair>,
}

impl Ca {
    pub fn new() -> Self {
        let mut params = CertificateParams::new(Vec::<String>::new()).unwrap();
        params.is_ca = IsCa::Ca(BasicConstraints::Unconstrained);
        let issuer = CertifiedIssuer::self_signed(params, KeyPair::generate().unwrap()).unwrap();
        Self { issuer }
    }

    pub fn der(&self) -> Vec<u8> {
        self.issuer.der().to_vec()
    }

    pub fn sign(&self, name: &str) -> Cert {
        let key = KeyPair::generate().unwrap();
        let params = CertificateParams::new(vec![name.to_owned()]).unwrap();
        let cert = params.signed_by(&key, &self.issuer).unwrap();
        Cert {
            der: cert.der().to_vec(),
            key: key.serialize_der(),
        }
    }
}
```

```rust
mod support;

use envio_net::{Endpoint, Fingerprint, NetError, Roots, Security, Untrusted};
use support::certs::{Ca, Cert};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::TcpListener;

/// Serves TLS with `cert` on a free port; each connection gets "ok".
async fn serve(cert: &Cert) -> u16 {
    let acceptor = cert.acceptor();
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let port = listener.local_addr().unwrap().port();
    tokio::spawn(async move {
        while let Ok((tcp, _)) = listener.accept().await {
            let acceptor = acceptor.clone();
            tokio::spawn(async move {
                if let Ok(mut tls) = acceptor.accept(tcp).await {
                    let _ = tls.write_all(b"ok").await;
                    let _ = tls.shutdown().await;
                }
            });
        }
    });
    port
}
```

```rust
//! TCP connect and the timeouts every network step runs under.

use std::future::Future;
use std::time::Duration;

use tokio::net::TcpStream;

use crate::error::{NetError, Result};

/// How long a TCP connect may take.
pub const CONNECT_TIMEOUT: Duration = Duration::from_secs(20);
/// How long one command (handshake, login, fetch, send) may take.
pub const COMMAND_TIMEOUT: Duration = Duration::from_secs(60);

pub(crate) async fn tcp(host: &str, port: u16) -> Result<TcpStream> {
    let stream = tokio::time::timeout(CONNECT_TIMEOUT, TcpStream::connect((host, port)))
        .await
        .map_err(|_| NetError::Timeout)??;
    stream.set_nodelay(true)?;
    Ok(stream)
}

/// Runs `step` under [`COMMAND_TIMEOUT`].
pub(crate) async fn within<T>(step: impl Future<Output = Result<T>>) -> Result<T> {
    within_for(COMMAND_TIMEOUT, step).await
}

pub(crate) async fn within_for<T>(
    limit: Duration,
    step: impl Future<Output = Result<T>>,
) -> Result<T> {
    tokio::time::timeout(limit, step)
        .await
        .map_err(|_| NetError::Timeout)?
}
```

```rust
//! Whether to trust a server certificate: pure, so every case is a unit
//! test. A pin, when there is one, is the only thing that counts; without
//! one, the system roots decide and a failure becomes the user's prompt.

use crate::error::Untrusted;
use crate::server::Fingerprint;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Verdict {
    Accept,
    /// Ask the user (the self-signed prompt).
    Untrusted(Untrusted),
    /// Stop: the pinned certificate was replaced.
    Changed {
        pinned: Fingerprint,
    },
}

/// `system` runs the roots check; it is only called when there is no pin.
pub fn decide(
    pin: Option<&Fingerprint>,
    presented: &Fingerprint,
    system: impl FnOnce() -> Result<(), Untrusted>,
) -> Verdict {
    match pin {
        Some(pinned) if pinned == presented => Verdict::Accept,
        Some(pinned) => Verdict::Changed { pinned: *pinned },
        None => match system() {
            Ok(()) => Verdict::Accept,
            Err(reason) => Verdict::Untrusted(reason),
        },
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    fn fp(byte: u8) -> Fingerprint {
        Fingerprint::from_bytes([byte; 32])
    }

    #[test]
    fn a_matching_pin_is_accepted_without_asking_the_roots() {
        let verdict = decide(Some(&fp(1)), &fp(1), || panic!("roots consulted"));
        assert_eq!(verdict, Verdict::Accept);
    }

    #[test]
    fn a_different_certificate_on_a_pinned_server_is_a_change() {
        let verdict = decide(Some(&fp(1)), &fp(2), || Ok(()));
        assert_eq!(verdict, Verdict::Changed { pinned: fp(1) });
    }

    #[test]
    fn without_a_pin_the_roots_decide() {
        assert_eq!(decide(None, &fp(1), || Ok(())), Verdict::Accept);
        assert_eq!(
            decide(None, &fp(1), || Err(Untrusted::UnknownIssuer)),
            Verdict::Untrusted(Untrusted::UnknownIssuer)
        );
    }
}
```

```rust
//! The rustls side of [`crate::trust`]: a certificate verifier that hashes
//! the server's certificate, asks `trust::decide`, and turns a "no" into a
//! handshake error that carries the fingerprint back to the caller.

use std::error::Error as StdError;
use std::fmt;
use std::sync::Arc;

use rustls::client::WebPkiServerVerifier;
use rustls::client::danger::{HandshakeSignatureValid, ServerCertVerified, ServerCertVerifier};
use rustls::crypto::{CryptoProvider, WebPkiSupportedAlgorithms};
use rustls::pki_types::{CertificateDer, ServerName, UnixTime};
use rustls::{CertificateError, DigitallySignedStruct, Error, OtherError, SignatureScheme};

use crate::error::Untrusted;
use crate::server::Fingerprint;
use crate::trust::{self, Verdict};

/// Why the verifier said no; rides inside the rustls error.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct Rejected {
    pub presented: Fingerprint,
    pub verdict: Verdict,
}

impl fmt::Display for Rejected {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "certificate rejected: {:?}", self.verdict)
    }
}

impl StdError for Rejected {}

#[derive(Debug)]
pub(crate) struct PinningVerifier {
    pin: Option<Fingerprint>,
    /// None when the system has no roots at all: then every unpinned
    /// server goes to the prompt instead of failing to build a config.
    webpki: Option<Arc<WebPkiServerVerifier>>,
    algorithms: WebPkiSupportedAlgorithms,
}

impl PinningVerifier {
    pub fn new(
        pin: Option<Fingerprint>,
        roots: Arc<rustls::RootCertStore>,
        provider: Arc<CryptoProvider>,
    ) -> Self {
        let algorithms = provider.signature_verification_algorithms;
        let webpki = WebPkiServerVerifier::builder_with_provider(roots, provider)
            .build()
            .ok();
        Self {
            pin,
            webpki,
            algorithms,
        }
    }
}

impl ServerCertVerifier for PinningVerifier {
    fn verify_server_cert(
        &self,
        end_entity: &CertificateDer<'_>,
        intermediates: &[CertificateDer<'_>],
        server_name: &ServerName<'_>,
        ocsp_response: &[u8],
        now: UnixTime,
    ) -> Result<ServerCertVerified, Error> {
        let presented = Fingerprint::of(end_entity.as_ref());
        let system = || match &self.webpki {
            None => Err(Untrusted::UnknownIssuer),
            Some(webpki) => webpki
                .verify_server_cert(end_entity, intermediates, server_name, ocsp_response, now)
                .map(|_| ())
                .map_err(|e| reason_of(&e)),
        };
        match trust::decide(self.pin.as_ref(), &presented, system) {
            Verdict::Accept => Ok(ServerCertVerified::assertion()),
            verdict => Err(Error::InvalidCertificate(CertificateError::Other(
                OtherError(Arc::new(Rejected { presented, verdict })),
            ))),
        }
    }

    fn verify_tls12_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> Result<HandshakeSignatureValid, Error> {
        rustls::crypto::verify_tls12_signature(message, cert, dss, &self.algorithms)
    }

    fn verify_tls13_signature(
        &self,
        message: &[u8],
        cert: &CertificateDer<'_>,
        dss: &DigitallySignedStruct,
    ) -> Result<HandshakeSignatureValid, Error> {
        rustls::crypto::verify_tls13_signature(message, cert, dss, &self.algorithms)
    }

    fn supported_verify_schemes(&self) -> Vec<SignatureScheme> {
        self.algorithms.supported_schemes()
    }
}

/// The prompt's reason for a webpki failure.
pub(crate) fn reason_of(error: &Error) -> Untrusted {
    match error {
        Error::InvalidCertificate(cert) => match cert {
            CertificateError::UnknownIssuer => Untrusted::UnknownIssuer,
            CertificateError::Expired | CertificateError::ExpiredContext { .. } => {
                Untrusted::Expired
            }
            CertificateError::NotValidForName | CertificateError::NotValidForNameContext { .. } => {
                Untrusted::WrongName
            }
            _ => Untrusted::Other,
        },
        _ => Untrusted::Other,
    }
}

/// Finds a [`Rejected`] inside a failed handshake's error.
pub(crate) fn rejection(error: &std::io::Error) -> Option<Rejected> {
    let tls = error.get_ref()?.downcast_ref::<Error>()?;
    match tls {
        Error::InvalidCertificate(CertificateError::Other(other)) => {
            other.0.downcast_ref::<Rejected>().copied()
        }
        _ => None,
    }
}
```

```rust
//! TLS client setup: which roots to trust, the handshake, and turning a
//! rejected certificate into `NetError::Untrusted` or `PinChanged`.

use std::sync::Arc;

use rustls::pki_types::{CertificateDer, ServerName};
use rustls::{ClientConfig, RootCertStore};
use tokio::io::{AsyncRead, AsyncWrite};
use tokio::net::TcpStream;
use tokio_rustls::TlsConnector;

use crate::connect;
use crate::error::{NetError, Result};
use crate::server::{Endpoint, Fingerprint, Security};
use crate::trust::Verdict;
use crate::verifier::{self, PinningVerifier};

pub use tokio_rustls::client::TlsStream;

/// The certificate authorities an unpinned server must chain to.
#[derive(Debug, Clone)]
pub struct Roots(Arc<RootCertStore>);

impl Roots {
    /// The system's CA bundle. Certificates that fail to load are skipped;
    /// if none load (say, AppArmor hides the bundle), every server goes to
    /// the certificate prompt rather than failing outright.
    pub fn system() -> Self {
        let loaded = rustls_native_certs::load_native_certs();
        let mut store = RootCertStore::empty();
        store.add_parsable_certificates(loaded.certs);
        Self(Arc::new(store))
    }

    /// Specific CAs, as DER. For tests and private CAs.
    pub fn from_der(certs: impl IntoIterator<Item = Vec<u8>>) -> Self {
        let mut store = RootCertStore::empty();
        store.add_parsable_certificates(certs.into_iter().map(CertificateDer::from));
        Self(Arc::new(store))
    }

    /// No CAs: only pinned servers connect.
    pub fn empty() -> Self {
        Self(Arc::new(RootCertStore::empty()))
    }

    pub fn len(&self) -> usize {
        self.0.len()
    }

    pub fn is_empty(&self) -> bool {
        self.0.is_empty()
    }
}

/// Runs the TLS handshake on an open stream (a fresh TCP connection, or
/// one that just agreed to STARTTLS).
pub async fn handshake<S>(
    stream: S,
    host: &str,
    roots: &Roots,
    pin: Option<Fingerprint>,
) -> Result<TlsStream<S>>
where
    S: AsyncRead + AsyncWrite + Unpin,
{
    let provider = Arc::new(rustls::crypto::ring::default_provider());
    let verifier = PinningVerifier::new(pin, roots.0.clone(), provider.clone());
    let config = ClientConfig::builder_with_provider(provider)
        .with_safe_default_protocol_versions()
        .map_err(|e| NetError::Tls(e.to_string()))?
        .dangerous()
        .with_custom_certificate_verifier(Arc::new(verifier))
        .with_no_client_auth();
    let name = ServerName::try_from(host.to_owned())
        .map_err(|_| NetError::Tls(format!("not a host name: {host}")))?;
    let connector = TlsConnector::from(Arc::new(config));
    connect::within(async {
        connector
            .connect(name, stream)
            .await
            .map_err(handshake_error)
    })
    .await
}

/// Opens TCP and does the handshake straight away: [`Security::Tls`].
/// STARTTLS is protocol-specific and lives with IMAP and SMTP.
pub async fn connect(endpoint: &Endpoint, roots: &Roots) -> Result<TlsStream<TcpStream>> {
    if endpoint.security != Security::Tls {
        return Err(NetError::Protocol("tls::connect needs implicit TLS".into()));
    }
    let tcp = connect::tcp(&endpoint.host, endpoint.port).await?;
    handshake(tcp, &endpoint.host, roots, endpoint.pin).await
}

fn handshake_error(error: std::io::Error) -> NetError {
    match verifier::rejection(&error) {
        Some(rejected) => match rejected.verdict {
            Verdict::Changed { pinned } => NetError::PinChanged {
                pinned,
                presented: rejected.presented,
            },
            Verdict::Untrusted(reason) => NetError::Untrusted {
                presented: rejected.presented,
                reason,
            },
            Verdict::Accept => NetError::Tls("accepted certificate rejected".into()),
        },
        None if error.kind() == std::io::ErrorKind::InvalidData => NetError::Tls(error.to_string()),
        None => NetError::Io(error),
    }
}
```

```rust
//! A scripted SMTP server, in process, that records what the client says.

use std::sync::{Arc, Mutex};

use tokio::io::{AsyncBufReadExt, AsyncRead, AsyncWrite, AsyncWriteExt, BufReader};
use tokio::net::TcpListener;

use super::certs::Cert;

#[derive(Clone, Copy)]
pub struct Script {
    /// Implicit TLS (465) instead of plaintext with STARTTLS (587).
    pub implicit: bool,
    /// Offer STARTTLS in the plaintext EHLO reply.
    pub offer_starttls: bool,
    /// Send extra bytes right after "220 go ahead" (STARTTLS injection).
    pub inject: bool,
    /// The reply to AUTH.
    pub auth_reply: &'static str,
}

impl Default for Script {
    fn default() -> Self {
        Self {
            implicit: false,
            offer_starttls: true,
            inject: false,
            auth_reply: "235 2.7.0 ok",
        }
    }
}

/// Every line the client sent, in order; `tls` marks lines sent over TLS.
#[derive(Clone, Default)]
pub struct Transcript(Arc<Mutex<Vec<(bool, String)>>>);

impl Transcript {
    pub fn lines(&self) -> Vec<(bool, String)> {
        self.0.lock().unwrap().clone()
    }

    pub fn push(&self, tls: bool, line: &str) {
        self.0
            .lock()
            .unwrap()
            .push((tls, line.trim_end().to_owned()));
    }
}

/// Serves one connection; returns the port and the transcript.
pub async fn serve(cert: &Cert, script: Script) -> (u16, Transcript) {
    let acceptor = cert.acceptor();
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let port = listener.local_addr().unwrap().port();
    let transcript = Transcript::default();
    let log = transcript.clone();
    tokio::spawn(async move {
        let (tcp, _) = listener.accept().await.unwrap();
        if script.implicit {
            let tls = acceptor.accept(tcp).await.unwrap();
            let mut io = BufReader::new(tls);
            io.write_all(b"220 fake ESMTP\r\n").await.unwrap();
            secure_part(&mut io, script, &log).await;
            return;
        }
        let mut io = BufReader::new(tcp);
        io.write_all(b"220 fake ESMTP\r\n").await.unwrap();
        let Some(_ehlo) = line(&mut io, false, &log).await else {
            return;
        };
        if script.offer_starttls {
            io.write_all(b"250-fake\r\n250-PIPELINING\r\n250 STARTTLS\r\n")
                .await
                .unwrap();
        } else {
            io.write_all(b"250-fake\r\n250 AUTH PLAIN\r\n")
                .await
                .unwrap();
        }
        let Some(next) = line(&mut io, false, &log).await else {
            return;
        };
        if next != "STARTTLS" {
            return;
        }
        let ready: &[u8] = if script.inject {
            b"220 go ahead\r\n250 injected\r\n"
        } else {
            b"220 go ahead\r\n"
        };
        io.write_all(ready).await.unwrap();
        let Ok(tls) = acceptor.accept(io.into_inner()).await else {
            return;
        };
        secure_part(&mut BufReader::new(tls), script, &log).await;
    });
    (port, transcript)
}

async fn line<S: AsyncRead + Unpin>(
    io: &mut BufReader<S>,
    tls: bool,
    log: &Transcript,
) -> Option<String> {
    let mut text = String::new();
    match io.read_line(&mut text).await {
        Ok(0) | Err(_) => None,
        Ok(_) => {
            log.push(tls, &text);
            Some(text.trim_end().to_owned())
        }
    }
}

async fn secure_part<S: AsyncRead + AsyncWrite + Unpin>(
    io: &mut BufReader<S>,
    script: Script,
    log: &Transcript,
) {
    while let Some(command) = line(io, true, log).await {
        let verb = command.split(' ').next().unwrap_or("").to_ascii_uppercase();
        let reply: String = match verb.as_str() {
            "EHLO" => "250-fake\r\n250-8BITMIME\r\n250 AUTH PLAIN LOGIN\r\n".into(),
            "AUTH" => format!("{}\r\n", script.auth_reply),
            "MAIL" | "RCPT" => "250 ok\r\n".into(),
            "DATA" => {
                io.write_all(b"354 go\r\n").await.unwrap();
                while let Some(body) = line(io, true, log).await {
                    if body == "." {
                        break;
                    }
                }
                "250 queued\r\n".into()
            }
            "QUIT" => {
                let _ = io.write_all(b"221 bye\r\n").await;
                return;
            }
            _ => "500 what\r\n".into(),
        };
        if io.write_all(reply.as_bytes()).await.is_err() {
            return;
        }
    }
}
```

```rust
//! SMTP replies (RFC 5321 4.2) for the part before TLS, which envio
//! speaks itself, and the mapping from reply codes to `NetError`.

use crate::error::NetError;

/// Longest reply line accepted; RFC 5321 allows 512 octets.
pub(crate) const MAX_LINE: usize = 1024;
/// Most lines in one reply. EHLO lists maybe 15 extensions.
pub(crate) const MAX_LINES: usize = 64;

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct Reply {
    pub code: u16,
    /// The text of each line, without code and separator.
    pub lines: Vec<String>,
}

/// One reply line: its code, whether more lines follow, and its text.
pub(crate) fn parse_line(line: &str) -> Option<(u16, bool, &str)> {
    let line = line.strip_suffix('\n').unwrap_or(line);
    let line = line.strip_suffix('\r').unwrap_or(line);
    let digits = line.get(..3)?;
    if !digits.bytes().all(|b| b.is_ascii_digit()) {
        return None;
    }
    let code: u16 = digits.parse().ok()?;
    if !(200..600).contains(&code) {
        return None;
    }
    match line.as_bytes().get(3) {
        None => Some((code, false, "")),
        Some(b' ') => Some((code, false, &line[4..])),
        Some(b'-') => Some((code, true, &line[4..])),
        Some(_) => None,
    }
}

/// Whether an EHLO reply offers STARTTLS. The first line is the greeting,
/// so only the extension lines count.
pub(crate) fn has_starttls(ehlo: &Reply) -> bool {
    ehlo.lines.iter().skip(1).any(|line| {
        line.split_ascii_whitespace()
            .next()
            .is_some_and(|word| word.eq_ignore_ascii_case("STARTTLS"))
    })
}

/// What a failing reply means for the caller. 4xx is "try later"; 5xx
/// during sign-in is a bad password; any other 5xx refuses this message.
pub(crate) fn error_for(code: u16, text: String, signing_in: bool) -> NetError {
    match code {
        400..=499 => NetError::Busy(format!("{code} {text}")),
        // 535: credentials invalid; 534/538: mechanism or TLS needed.
        500..=599 if signing_in => NetError::SignIn(format!("{code} {text}")),
        500..=599 => NetError::Refused(format!("{code} {text}")),
        _ => NetError::Protocol(format!("unexpected reply {code} {text}")),
    }
}
```

```rust
//! The plaintext prelude of SMTP STARTTLS (RFC 3207), done by envio rather
//! than lettre so the handshake uses envio's pinning verifier: greeting,
//! EHLO, STARTTLS, then TLS. Nothing but these three exchanges is ever
//! sent in the clear, and a missing STARTTLS is an error, never a
//! plaintext fallback.

use tokio::io::{AsyncBufReadExt, AsyncRead, AsyncReadExt, AsyncWrite, AsyncWriteExt, BufReader};
use tokio::net::TcpStream;

use super::EHLO_NAME;
use super::reply::{self, MAX_LINE, MAX_LINES, Reply};
use crate::connect;
use crate::error::{NetError, Result};
use crate::server::Endpoint;
use crate::tls::{self, Roots, TlsStream};

pub(crate) async fn upgrade(
    tcp: TcpStream,
    endpoint: &Endpoint,
    roots: &Roots,
) -> Result<TlsStream<TcpStream>> {
    let mut io = BufReader::new(tcp);
    connect::within(prelude(&mut io)).await?;
    // Bytes the server sent after its 220 would be read as if they came
    // over TLS (the STARTTLS injection attack); refuse instead.
    if !io.buffer().is_empty() {
        return Err(NetError::Protocol("data after the STARTTLS reply".into()));
    }
    tls::handshake(io.into_inner(), &endpoint.host, roots, endpoint.pin).await
}

async fn prelude<S>(io: &mut BufReader<S>) -> Result<()>
where
    S: AsyncRead + AsyncWrite + Unpin,
{
    let greeting = read_reply(io).await?;
    if greeting.code != 220 {
        return Err(reply::error_for(
            greeting.code,
            greeting.lines.join(" "),
            false,
        ));
    }
    io.write_all(format!("EHLO {EHLO_NAME}\r\n").as_bytes())
        .await?;
    let ehlo = read_reply(io).await?;
    if ehlo.code != 250 {
        return Err(reply::error_for(ehlo.code, ehlo.lines.join(" "), false));
    }
    if !reply::has_starttls(&ehlo) {
        return Err(NetError::NoStartTls);
    }
    io.write_all(b"STARTTLS\r\n").await?;
    let ready = read_reply(io).await?;
    match ready.code {
        220 => Ok(()),
        400..=499 => Err(reply::error_for(ready.code, ready.lines.join(" "), false)),
        _ => Err(NetError::NoStartTls),
    }
}

/// Reads one reply, possibly over several lines.
pub(crate) async fn read_reply<S>(io: &mut BufReader<S>) -> Result<Reply>
where
    S: AsyncRead + Unpin,
{
    let mut lines = Vec::new();
    loop {
        let mut raw = Vec::new();
        let n = (&mut *io)
            .take(MAX_LINE as u64)
            .read_until(b'\n', &mut raw)
            .await?;
        if n == 0 {
            return Err(NetError::Io(std::io::ErrorKind::UnexpectedEof.into()));
        }
        if raw.last() != Some(&b'\n') {
            return Err(NetError::Protocol("SMTP reply line too long".into()));
        }
        let text = String::from_utf8_lossy(&raw);
        let (code, more, rest) = reply::parse_line(&text)
            .ok_or_else(|| NetError::Protocol(format!("not an SMTP reply: {text:?}")))?;
        lines.push(rest.to_owned());
        if !more {
            return Ok(Reply { code, lines });
        }
        if lines.len() >= MAX_LINES {
            return Err(NetError::Protocol("SMTP reply too long".into()));
        }
    }
}
```

```rust
//! The TLS stream handed to lettre. lettre always starts by reading a
//! greeting; after STARTTLS the real one was read in the clear, so this
//! stream first plays back a stand-in 220, then passes everything through.

use std::io;
use std::net::SocketAddr;
use std::pin::Pin;
use std::task::{Context, Poll};

use lettre::transport::smtp::client::AsyncTokioStream;
use tokio::io::{AsyncRead, AsyncWrite, ReadBuf};
use tokio::net::TcpStream;

use crate::tls::TlsStream;

const STAND_IN: &[u8] = b"220 envio STARTTLS done\r\n";

#[derive(Debug)]
pub(crate) struct SmtpStream {
    tls: TlsStream<TcpStream>,
    /// Bytes of the stand-in greeting still to play back.
    replay: &'static [u8],
}

impl SmtpStream {
    /// After implicit TLS: the server's own greeting comes next.
    pub fn implicit(tls: TlsStream<TcpStream>) -> Self {
        Self { tls, replay: &[] }
    }

    /// After STARTTLS: lettre gets the stand-in greeting first.
    pub fn upgraded(tls: TlsStream<TcpStream>) -> Self {
        Self {
            tls,
            replay: STAND_IN,
        }
    }
}

impl AsyncRead for SmtpStream {
    fn poll_read(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
        buf: &mut ReadBuf<'_>,
    ) -> Poll<io::Result<()>> {
        if !self.replay.is_empty() {
            let n = self.replay.len().min(buf.remaining());
            buf.put_slice(&self.replay[..n]);
            self.replay = &self.replay[n..];
            return Poll::Ready(Ok(()));
        }
        Pin::new(&mut self.tls).poll_read(cx, buf)
    }
}

impl AsyncWrite for SmtpStream {
    fn poll_write(
        mut self: Pin<&mut Self>,
        cx: &mut Context<'_>,
        data: &[u8],
    ) -> Poll<io::Result<usize>> {
        Pin::new(&mut self.tls).poll_write(cx, data)
    }

    fn poll_flush(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<io::Result<()>> {
        Pin::new(&mut self.tls).poll_flush(cx)
    }

    fn poll_shutdown(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<io::Result<()>> {
        Pin::new(&mut self.tls).poll_shutdown(cx)
    }
}

impl AsyncTokioStream for SmtpStream {
    fn peer_addr(&self) -> io::Result<SocketAddr> {
        self.tls.get_ref().0.peer_addr()
    }
}
```

```rust
//! Sending mail: one SMTP session per Outbox run. TLS is set up by envio
//! (implicit, or STARTTLS in `starttls`), then lettre speaks SMTP over the
//! finished stream. The EHLO name is a fixed address literal, so mail
//! never carries the phone's host name.

mod reply;
mod starttls;
mod stream;

use std::net::Ipv4Addr;

use lettre::address::{Address, Envelope};
use lettre::transport::smtp::authentication::{Credentials as LettreCredentials, Mechanism};
use lettre::transport::smtp::client::AsyncSmtpConnection;
use lettre::transport::smtp::extension::ClientId;
use secrecy::ExposeSecret;

use crate::connect;
use crate::error::{NetError, Result};
use crate::server::{Credentials, Endpoint, Security};
use crate::tls::{self, Roots};
use stream::SmtpStream;

/// What envio says in EHLO: the same for every user.
pub const EHLO_NAME: &str = "[127.0.0.1]";

pub struct SmtpSession {
    conn: AsyncSmtpConnection,
}

impl SmtpSession {
    /// Connects, secures the connection and greets the server.
    pub async fn connect(endpoint: &Endpoint, roots: &Roots) -> Result<Self> {
        let stream = match endpoint.security {
            Security::Tls => SmtpStream::implicit(tls::connect(endpoint, roots).await?),
            Security::StartTls => {
                let tcp = connect::tcp(&endpoint.host, endpoint.port).await?;
                SmtpStream::upgraded(starttls::upgrade(tcp, endpoint, roots).await?)
            }
        };
        let hello = ClientId::Ipv4(Ipv4Addr::LOCALHOST);
        let conn = connect::within(async {
            AsyncSmtpConnection::connect_with_transport(Box::new(stream), &hello)
                .await
                .map_err(|e| map_error(e, false))
        })
        .await?;
        Ok(Self { conn })
    }

    /// Signs in with PLAIN, or LOGIN if that's all the server offers.
    pub async fn login(&mut self, credentials: &Credentials) -> Result<()> {
        // lettre keeps a plain String copy until this returns.
        let lettre = LettreCredentials::new(
            credentials.username.clone(),
            credentials.password.expose_secret().to_owned(),
        );
        connect::within(async {
            self.conn
                .auth(&[Mechanism::Plain, Mechanism::Login], &lettre)
                .await
                .map(drop)
                .map_err(|e| map_error(e, true))
        })
        .await
    }

    /// Sends one message. `eml` is the finished RFC 5322 message (from
    /// envio-mime); `from` and `to` are the envelope, which may differ
    /// from its headers (Bcc).
    pub async fn send(&mut self, from: &str, to: &[String], eml: &[u8]) -> Result<()> {
        let envelope = envelope(from, to)?;
        connect::within(async {
            self.conn
                .send(&envelope, eml)
                .await
                .map(drop)
                .map_err(|e| map_error(e, false))
        })
        .await
    }

    pub async fn quit(mut self) -> Result<()> {
        connect::within(async {
            self.conn
                .quit()
                .await
                .map(drop)
                .map_err(|e| map_error(e, false))
        })
        .await
    }
}

fn envelope(from: &str, to: &[String]) -> Result<Envelope> {
    let address = |text: &str| {
        text.parse::<Address>()
            .map_err(|_| NetError::Refused(format!("not an address: {text:?}")))
    };
    let recipients = to.iter().map(|t| address(t)).collect::<Result<Vec<_>>>()?;
    Envelope::new(Some(address(from)?), recipients)
        .map_err(|e| NetError::Refused(format!("bad envelope: {e}")))
}

fn map_error(error: lettre::transport::smtp::Error, signing_in: bool) -> NetError {
    if let Some(code) = error.status() {
        let code = code.to_string().parse().unwrap_or(0);
        return reply::error_for(code, error.to_string(), signing_in);
    }
    if error.is_timeout() {
        return NetError::Timeout;
    }
    if error.is_client() || error.is_response() {
        return NetError::Protocol(error.to_string());
    }
    NetError::Io(std::io::Error::new(
        std::io::ErrorKind::ConnectionAborted,
        error.to_string(),
    ))
}
```

```rust
//! A scripted IMAP server, in process, that records what the client says.
//! Just enough for the connect path: greeting, STARTTLS, LOGIN,
//! CAPABILITY, NOOP, LOGOUT.

use tokio::net::TcpListener;

use super::certs::Cert;
pub use super::fake_smtp::Transcript;

#[derive(Clone, Copy)]
pub struct Script {
    /// Implicit TLS (993) instead of plaintext with STARTTLS (143).
    pub implicit: bool,
    /// The greeting line, without CRLF.
    pub greeting: &'static str,
    /// The status word STARTTLS gets: "OK", "NO" or "BAD".
    pub starttls: &'static str,
    /// Bytes sent right after the STARTTLS OK, in the same write.
    pub inject: &'static str,
    /// The status and text LOGIN gets.
    pub login: &'static str,
}

impl Default for Script {
    fn default() -> Self {
        Self {
            implicit: false,
            greeting: "* OK fake IMAP ready",
            starttls: "OK",
            inject: "",
            login: "OK signed in",
        }
    }

/// Serves one connection; returns the port and the transcript.
pub async fn serve(cert: &Cert, script: Script) -> (u16, Transcript) {
    let acceptor = cert.acceptor();
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let port = listener.local_addr().unwrap().port();
    let transcript = Transcript::default();
    let log = transcript.clone();
    tokio::spawn(async move {
        let (tcp, _) = listener.accept().await.unwrap();
        let greeting = format!("{}\r\n", script.greeting);
        if script.implicit {
            let mut io = BufReader::new(acceptor.accept(tcp).await.unwrap());
            io.write_all(greeting.as_bytes()).await.unwrap();
            secure_part(&mut io, script, &log).await;
            return;
        }
        let mut io = BufReader::new(tcp);
        io.write_all(greeting.as_bytes()).await.unwrap();
        let Some(command) = line(&mut io, false, &log).await else {
            return;
        };
        let (tag, verb) = split(&command);
        if verb != "STARTTLS" {
            let _ = io
                .write_all(format!("{tag} BAD say STARTTLS first\r\n").as_bytes())
                .await;
            return;
        }
        let reply = format!("{tag} {} begin TLS\r\n{}", script.starttls, script.inject);
        io.write_all(reply.as_bytes()).await.unwrap();
        if script.starttls != "OK" {
            // Keep reading so anything sent after a refusal is recorded.
            while line(&mut io, false, &log).await.is_some() {}
            return;
        }
        let Ok(tls) = acceptor.accept(io.into_inner()).await else {
            return;
        };
        secure_part(&mut BufReader::new(tls), script, &log).await;
    });
    (port, transcript)
}

fn split(command: &str) -> (String, String) {
    let mut words = command.split(' ');
    let tag = words.next().unwrap_or("*").to_owned();
    let verb = words.next().unwrap_or("").to_ascii_uppercase();
    (tag, verb)
}

async fn line<S: AsyncRead + Unpin>(
    io: &mut BufReader<S>,
    tls: bool,
    log: &Transcript,
) -> Option<String> {
    let mut text = String::new();
    match io.read_line(&mut text).await {
        Ok(0) | Err(_) => None,
        Ok(_) => {
            log.push(tls, &text);
            Some(text.trim_end().to_owned())
        }
    }
}

async fn secure_part<S: AsyncRead + AsyncWrite + Unpin>(
    io: &mut BufReader<S>,
    script: Script,
    log: &Transcript,
) {
    while let Some(command) = line(io, true, log).await {
        let (tag, verb) = split(&command);
        let reply = match verb.as_str() {
            "LOGIN" => format!("{tag} {}\r\n", script.login),
            "CAPABILITY" => format!("* CAPABILITY IMAP4rev1 IDLE UIDPLUS\r\n{tag} OK done\r\n"),
            "NOOP" => format!("{tag} OK done\r\n"),
            "LOGOUT" => {
                let _ = io
                    .write_all(format!("* BYE bye\r\n{tag} OK done\r\n").as_bytes())
                    .await;
                return;
            }
            _ => format!("{tag} BAD what\r\n"),
        };
        if io.write_all(reply.as_bytes()).await.is_err() {
            return;
        }
    }
}
```

```rust
//! Folder names: modified UTF-7 (RFC 3501 5.1.3) for display, and which
//! folder is Sent, Drafts, Trash and so on (RFC 6154 special use).

use async_imap::types::NameAttribute;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Role {
    Inbox,
    Sent,
    Drafts,
    Trash,
    Junk,
    Archive,
    All,
    Flagged,
}

/// The folder's role: INBOX by name (any case, RFC 3501 5.1), the rest
/// from the server's special-use attributes.
pub fn role_of(path: &str, attributes: &[NameAttribute<'_>]) -> Option<Role> {
    if path.eq_ignore_ascii_case("INBOX") {
        return Some(Role::Inbox);
    }
    attributes.iter().find_map(|attribute| match attribute {
        NameAttribute::Sent => Some(Role::Sent),
        NameAttribute::Drafts => Some(Role::Drafts),
        NameAttribute::Trash => Some(Role::Trash),
        NameAttribute::Junk => Some(Role::Junk),
        NameAttribute::Archive => Some(Role::Archive),
        NameAttribute::All => Some(Role::All),
        NameAttribute::Flagged => Some(Role::Flagged),
        _ => None,
    })
}

/// Whether the folder can be opened (`\Noselect` and RFC 5258
/// `\NonExistent` can't).
pub fn selectable(attributes: &[NameAttribute<'_>]) -> bool {
    !attributes.iter().any(|attribute| match attribute {
        NameAttribute::NoSelect => true,
        NameAttribute::Extension(name) => name.eq_ignore_ascii_case("\\NonExistent"),
        _ => false,
    })
}

/// The display form of a modified UTF-7 name. None if it's malformed;
/// callers then show the raw name.
pub fn decode_utf7(raw: &str) -> Option<String> {
    let mut out = String::with_capacity(raw.len());
    let mut rest = raw;
    while let Some(start) = rest.find('&') {
        out.push_str(&rest[..start]);
        let after = &rest[start + 1..];
        let end = after.find('-')?;
        let encoded = &after[..end];
        if encoded.is_empty() {
            out.push('&');
        } else {
            out.push_str(&decode_run(encoded)?);
        }
        rest = &after[end + 1..];
    }
    if !rest.bytes().all(|b| (0x20..0x7f).contains(&b)) {
        return None;
    }
    out.push_str(rest);
    Some(out)
}

/// One `&...-` run: modified base64 (`,` for `/`, no padding) of UTF-16BE.
fn decode_run(encoded: &str) -> Option<String> {
    let mut bits: u32 = 0;
    let mut count = 0;
    let mut bytes = Vec::new();
    for c in encoded.bytes() {
        let value = match c {
            b'A'..=b'Z' => c - b'A',
            b'a'..=b'z' => c - b'a' + 26,
            b'0'..=b'9' => c - b'0' + 52,
            b'+' => 62,
            b',' => 63,
            _ => return None,
        };
        bits = (bits << 6) | u32::from(value);
        count += 6;
        if count >= 8 {
            count -= 8;
            bytes.push((bits >> count) as u8);
            bits &= (1 << count) - 1;
        }
    }
    if bytes.len() % 2 != 0 || bits != 0 {
        return None;
    }
    let units: Vec<u16> = bytes
        .as_chunks::<2>()
        .0
        .iter()
        .map(|pair| u16::from_be_bytes(*pair))
        .collect();
    let text = String::from_utf16(&units).ok()?;
    // A run must hold something that couldn't be written plainly.
    if text.chars().any(|c| (' '..='~').contains(&c)) {
        return None;
    }
    Some(text)
}
```

```rust
//! Building IMAP command arguments: UID sets, quoted strings, flag lists
//! and search keys. Anything that could smuggle a second command (CR, LF,
//! NUL) is refused here, before it reaches the wire.

use crate::error::{NetError, Result};

/// A message flag envio reads and sets.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Flag {
    Seen,
    Answered,
    Flagged,
    Deleted,
    Draft,
    /// A keyword such as `$Forwarded` or `$Junk`.
    Keyword(String),
}

/// The flags on one message.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct MessageFlags {
    pub seen: bool,
    pub answered: bool,
    pub flagged: bool,
    pub deleted: bool,
    pub draft: bool,
    pub keywords: Vec<String>,
}

impl MessageFlags {
    pub fn from_flags(flags: impl IntoIterator<Item = Flag>) -> Self {
        let mut out = Self::default();
        for flag in flags {
            match flag {
                Flag::Seen => out.seen = true,
                Flag::Answered => out.answered = true,
                Flag::Flagged => out.flagged = true,
                Flag::Deleted => out.deleted = true,
                Flag::Draft => out.draft = true,
                Flag::Keyword(word) => out.keywords.push(word),
            }
        }
        out
    }
}

/// `1:3,7,9:10` for UIDs in any order; None for no UIDs.
pub fn uid_set(uids: &[u32]) -> Option<String> {
    let mut sorted = uids.to_vec();
    sorted.sort_unstable();
    sorted.dedup();
    let mut parts = Vec::new();
    let mut iter = sorted.into_iter().peekable();
    while let Some(start) = iter.next() {
        let mut end = start;
        while let Some(next) = iter.next_if(|&uid| Some(uid) == end.checked_add(1)) {
            end = next;
        }
        parts.push(if start == end {
            start.to_string()
        } else {
            format!("{start}:{end}")
        });
    }
    (!parts.is_empty()).then(|| parts.join(","))
}

/// An IMAP quoted string. Non-ASCII goes through [`search_text`] instead.
pub fn quote(text: &str) -> Result<String> {
    if text
        .bytes()
        .any(|b| matches!(b, b'\r' | b'\n' | 0) || !b.is_ascii())
    {
        return Err(NetError::Refused(
            "text with line breaks or non-ASCII can't be quoted".into(),
        ));
    }
    Ok(format!(
        "\"{}\"",
        text.replace('\\', "\\\\").replace('"', "\\\"")
    ))
}

/// `(\Seen $Forwarded)`.
pub fn flag_list(flags: &[Flag]) -> Result<String> {
    let mut words = Vec::with_capacity(flags.len());
    for flag in flags {
        words.push(match flag {
            Flag::Seen => "\\Seen".to_owned(),
            Flag::Answered => "\\Answered".to_owned(),
            Flag::Flagged => "\\Flagged".to_owned(),
            Flag::Deleted => "\\Deleted".to_owned(),
            Flag::Draft => "\\Draft".to_owned(),
            Flag::Keyword(word) if is_atom(word) => word.clone(),
            Flag::Keyword(word) => {
                return Err(NetError::Refused(format!("not a keyword: {word:?}")));
            }
        });
    }
    Ok(format!("({})", words.join(" ")))
}

/// RFC 3501 atom, minus the characters with meaning in flags.
fn is_atom(word: &str) -> bool {
    !word.is_empty()
        && word.bytes().all(|b| {
            b.is_ascii_graphic()
                && !matches!(b, b'(' | b')' | b'{' | b'%' | b'*' | b'"' | b'\\' | b']')
        })
}

/// The FETCH items for a message summary.
pub fn summary_items(condstore: bool) -> &'static str {
    if condstore {
        "(UID FLAGS RFC822.SIZE INTERNALDATE MODSEQ BODY.PEEK[HEADER])"
    } else {
        "(UID FLAGS RFC822.SIZE INTERNALDATE BODY.PEEK[HEADER])"
    }
}

/// The flags-only FETCH items; with `changed_since`, only messages whose
/// flags changed after that mod-sequence (RFC 7162 CONDSTORE).
pub fn flag_items(changed_since: Option<u64>) -> String {
    match changed_since {
        Some(modseq) => format!("(UID FLAGS MODSEQ) (CHANGEDSINCE {modseq})"),
        None => "(UID FLAGS)".to_owned(),
    }
}

/// The search key for one Message-ID header.
pub fn search_message_id(message_id: &str) -> Result<String> {
    Ok(format!("HEADER Message-ID {}", quote(message_id)?))
}

/// The Message-ID in a `BODY[HEADER.FIELDS (MESSAGE-ID)]` answer: the
/// header name in any case, folded lines joined, spaces trimmed.
pub fn message_id_of(fields: &[u8]) -> Option<String> {
    let text = String::from_utf8_lossy(fields);
    let mut value: Option<String> = None;
    for line in text.split("\r\n") {
        if line.starts_with([' ', '\t']) {
            if let Some(value) = value.as_mut() {
                value.push_str(line.trim());
            }
            continue;
        }
        if value.is_some() {
            break;
        }
        if let Some((name, rest)) = line.split_once(':')
            && name.trim().eq_ignore_ascii_case("message-id")
        {
            value = Some(rest.trim().to_owned());
        }
    }
    value.filter(|id| !id.is_empty())
}

/// A full-text search. ASCII is quoted; anything else needs a literal,
/// sent non-synchronizing (`{n+}`), which needs LITERAL+ or LITERAL-.
pub fn search_text(text: &str, literal_plus: bool) -> Result<String> {
    if text.is_ascii() {
        return Ok(format!("TEXT {}", quote(text)?));
    }
    if text.contains(['\r', '\n', '\0']) {
        return Err(NetError::Refused("search text with line breaks".into()));
    }
    if !literal_plus {
        return Err(NetError::Refused(
            "this server can't search for non-ASCII text".into(),
        ));
    }
    Ok(format!("CHARSET UTF-8 TEXT {{{}+}}\r\n{text}", text.len()))
}
```

```rust
//! Opening an IMAP connection: TLS (implicit or STARTTLS), the greeting,
//! LOGIN; and what async-imap's errors mean for envio.

use async_imap::imap_proto::{Response, Status};

/// How the server greeted us.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Greeting {
    Ok,
    PreAuth,
    Bye,
    Other,
}
use async_imap::{Client, Session};
use secrecy::ExposeSecret;
use tokio::net::TcpStream;

use crate::connect;
use crate::error::{NetError, Result};
use crate::server::{Credentials, Endpoint, Security};
use crate::tls::{self, Roots, TlsStream};

pub(crate) type Stream = TlsStream<TcpStream>;

pub(crate) async fn open(
    endpoint: &Endpoint,
    roots: &Roots,
    credentials: &Credentials,
) -> Result<Session<Stream>> {
    let client = match endpoint.security {
        Security::Tls => {
            let mut client = Client::new(tls::connect(endpoint, roots).await?);
            connect::within(greeting(&mut client)).await?;
            client
        }
        Security::StartTls => {
            let tcp = connect::tcp(&endpoint.host, endpoint.port).await?;
            let tcp = connect::within(starttls(tcp)).await?;
            // No greeting after STARTTLS (RFC 3501 6.2.1).
            Client::new(tls::handshake(tcp, &endpoint.host, roots, endpoint.pin).await?)
        }
    };
    // async-imap refuses CR and LF here and sends both as quoted strings.
    let password = credentials.password.expose_secret();
    connect::within(async move {
        client
            .login(&credentials.username, password)
            .await
            .map_err(|(error, _)| match error {
                async_imap::error::Error::No(text) => NetError::SignIn(text),
                other => map_error(other),
            })
    })
    .await
}

/// The plaintext prelude: greeting, then STARTTLS. Nothing else is sent
/// in the clear. Bytes the server sent after its OK are dropped with the
/// buffer, never read as if they came over TLS.
async fn starttls(tcp: TcpStream) -> Result<TcpStream> {
    let mut client = Client::new(tcp);
    let status = greeting_status(&mut client).await?;
    if status == Greeting::PreAuth {
        // Already signed in, so STARTTLS is not allowed: refuse.
        return Err(NetError::NoStartTls);
    }
    check_greeting(status)?;
    match client.run_command_and_check_ok("STARTTLS", None).await {
        Ok(()) => Ok(client.into_inner()),
        Err(async_imap::error::Error::No(_) | async_imap::error::Error::Bad(_)) => {
            Err(NetError::NoStartTls)
        }
        Err(other) => Err(map_error(other)),
    }
}

async fn greeting<S>(client: &mut Client<S>) -> Result<()>
where
    S: tokio::io::AsyncRead + tokio::io::AsyncWrite + Unpin + std::fmt::Debug + Send,
{
    check_greeting(greeting_status(client).await?)
}

async fn greeting_status<S>(client: &mut Client<S>) -> Result<Greeting>
where
    S: tokio::io::AsyncRead + tokio::io::AsyncWrite + Unpin + std::fmt::Debug + Send,
{
    let response = client
        .read_response()
        .await?
        .ok_or(NetError::Io(std::io::ErrorKind::UnexpectedEof.into()))?;
    match response.parsed() {
        Response::Data { status, .. } => Ok(match status {
            Status::Ok => Greeting::Ok,
            Status::PreAuth => Greeting::PreAuth,
            Status::Bye => Greeting::Bye,
            _ => Greeting::Other,
        }),
        other => Err(NetError::Protocol(format!(
            "not an IMAP greeting: {other:?}"
        ))),
    }
}

/// OK goes on; BYE is "busy, try later"; anything else is not IMAP.
pub(crate) fn check_greeting(status: Greeting) -> Result<()> {
    match status {
        Greeting::Ok => Ok(()),
        Greeting::Bye => Err(NetError::Busy("server said BYE".into())),
        other => Err(NetError::Protocol(format!("greeting {other:?}"))),
    }
}

pub(crate) fn map_error(error: async_imap::error::Error) -> NetError {
    use async_imap::error::Error;
    match error {
        Error::Io(e) if e.kind() == std::io::ErrorKind::TimedOut => NetError::Timeout,
        Error::Io(e) => NetError::Io(e),
        Error::ConnectionLost => NetError::Io(std::io::ErrorKind::UnexpectedEof.into()),
        Error::No(text) if is_busy(&text) => NetError::Busy(text),
        Error::No(text) => NetError::Refused(text),
        Error::Validate(e) => NetError::Refused(e.to_string()),
        Error::Append => NetError::Refused("APPEND failed".into()),
        other => NetError::Protocol(other.to_string()),
    }
}

/// RFC 5530 codes for "not now".
fn is_busy(text: &str) -> bool {
    ["[UNAVAILABLE]", "[INUSE]", "[LIMIT]"]
        .iter()
        .any(|code| text.contains(code))
}
```

```rust
    /// Connects, secures the connection, signs in and reads capabilities.
    pub async fn open(
        endpoint: &Endpoint,
        roots: &Roots,
        credentials: &Credentials,
    ) -> Result<Self> {
        let mut session = client::open(endpoint, roots, credentials).await?;
        let caps = connect::within(async {
            let caps = session.capabilities().await.map_err(map_error)?;
            Ok(Caps::from_names(caps.iter().filter_map(|cap| match cap {
                async_imap::types::Capability::Atom(name) => Some(name.as_str()),
                _ => None,
            })))
        })
        .await?;
        Ok(Self { session, caps })
    }

    pub fn caps(&self) -> Caps {
        self.caps
    }

    /// A round trip: keeps the connection alive and collects news.
    pub async fn noop(&mut self) -> Result<()> {
        connect::within(async { self.session.noop().await.map_err(map_error) }).await
    }

    pub async fn logout(mut self) -> Result<()> {
        connect::within(async { self.session.logout().await.map_err(map_error) }).await
    }
}
```

```rust
    pub async fn store_flags(&mut self, uids: &[u32], add: bool, flags: &[Flag]) -> Result<()> {
        let Some(set) = query::uid_set(uids) else {
            return Ok(());

            if add { '+' } else { '-' },

                .await

                .try_collect()
                .await
                .map_err(map_error)?;

        .await

    /// COPY, mark \Deleted, then UID EXPUNGE if the server has UIDPLUS. A
    /// plain EXPUNGE would also remove other messages marked \Deleted, so
    /// without UIDPLUS the originals stay, marked \Deleted.
    pub async fn move_to(&mut self, uids: &[u32], target: &str) -> Result<()> {
        let Some(set) = query::uid_set(uids) else {
            return Ok(());
        };
        if self.caps.r#move {
            return connect::within(async {
                self.session.uid_mv(&set, target).await.map_err(map_error)
            })
            .await;
        }
        connect::within(async { self.session.uid_copy(&set, target).await.map_err(map_error) })
            .await?;
        self.store_flags(uids, true, &[Flag::Deleted]).await?;
        if !self.caps.uidplus {
            return Ok(());
        }
        connect::within(async {
            let _: Vec<_> = self
                .session
                .uid_expunge(&set)
                .await
                .map_err(map_error)?
                .try_collect()
                .await
                .map_err(map_error)?;
            Ok(())
        })
        .await
    }

    /// Uploads a message (Sent copy, draft) with `flags`.
    pub async fn append(&mut self, folder: &str, flags: &[Flag], eml: &[u8]) -> Result<()> {
        let flags = if flags.is_empty() {
            None
        } else {
            Some(query::flag_list(flags)?)
        };
        connect::within(async {
            self.session
                .append(folder, flags.as_deref(), None, eml)
                .await
                .map_err(map_error)
        })
        .await
    }

    /// UIDs in the selected folder with this Message-ID (the Outbox's
    /// "may have been sent" check). Some servers (Stalwart 1.0) never
    /// match HEADER Message-ID, so an empty answer is checked against the
    /// Message-ID headers of the newest [`SCAN`] messages.
    pub async fn search_message_id(&mut self, message_id: &str) -> Result<Vec<u32>> {
        let key = query::search_message_id(message_id)?;
        let found = self.search(&key).await?;
        if !found.is_empty() || self.exists == 0 {
            return Ok(found);
        }
        let first = self.exists.saturating_sub(SCAN - 1).max(1);
        connect::within(async {
            let fetches: Vec<_> = self
                .session
                .fetch(
                    format!("{first}:*"),
                    "(UID BODY.PEEK[HEADER.FIELDS (MESSAGE-ID)])",
                )
                .await
                .map_err(map_error)?
                .try_collect()
                .await
                .map_err(map_error)?;
            let mut uids: Vec<u32> = fetches
                .iter()
                .filter(|fetch| {
                    query::message_id_of(fetch.header().unwrap_or_default()).as_deref()
                        == Some(message_id)
                })
                .filter_map(|fetch| fetch.uid)
                .collect();
            uids.sort_unstable();
            Ok(uids)
        })
        .await
    }

    /// "Search on server" in the selected folder.
    pub async fn search_text(&mut self, text: &str) -> Result<Vec<u32>> {
        let key = query::search_text(text, self.caps.literal_plus)?;
        self.search(&key).await
    }

    async fn search(&mut self, key: &str) -> Result<Vec<u32>> {
        connect::within(async {
            let found = self.session.uid_search(key).await.map_err(map_error)?;
            let mut uids: Vec<u32> = found.into_iter().collect();
            uids.sort_unstable();
            Ok(uids)
        })
        .await
    }
}

        F::Custom(word) => Some(Flag::Keyword(word.into_owned())),

    }))
}
```

```rust
//! A TCP proxy that can cut connections mid-stream: the network dropping
//! out in the middle of a download, an upload or SMTP DATA.

use std::sync::{Arc, Mutex};

use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::tcp::{OwnedReadHalf, OwnedWriteHalf};
use tokio::net::{TcpListener, TcpStream};
use tokio::sync::watch;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Direction {
    /// Client to server (uploads, APPEND, DATA).
    Up,
    /// Server to client (downloads, FETCH).
    Down,
}

#[derive(Default)]
struct Budget {
    /// Bytes still allowed in one direction before every connection is cut.
    left: Option<(Direction, usize)>,
}

pub struct Proxy {
    pub port: u16,
    budget: Arc<Mutex<Budget>>,
}

impl Proxy {
    /// Forwards every connection on a free local port to `host:port`.
    pub async fn start(host: &str, port: u16) -> Self {
        let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
        let local = listener.local_addr().unwrap().port();
        let budget = Arc::new(Mutex::new(Budget::default()));
        let target = format!("{host}:{port}");
        let shared = budget.clone();
        tokio::spawn(async move {
            while let Ok((client, _)) = listener.accept().await {
                let Ok(server) = TcpStream::connect(&target).await else {
                    continue;
                };
                tokio::spawn(pipe(client, server, shared.clone()));
            }
        });
        Self {
            port: local,
            budget,
        }
    }

    /// From now on, cut every open connection once `bytes` more have
    /// passed in `direction`. The budget is spent once: later
    /// connections pass untouched.
    pub fn cut_after(&self, direction: Direction, bytes: usize) {
        self.budget.lock().unwrap().left = Some((direction, bytes));
    }
}

async fn pipe(client: TcpStream, server: TcpStream, budget: Arc<Mutex<Budget>>) {
    let (client_read, client_write) = client.into_split();
    let (server_read, server_write) = server.into_split();
    let (cut_tx, cut_rx) = watch::channel(false);
    let up = Leg {
        direction: Direction::Up,
        budget: budget.clone(),
        cut_tx: cut_tx.clone(),
        cut_rx: cut_rx.clone(),
    };
    let down = Leg {
        direction: Direction::Down,
        budget,
        cut_tx,
        cut_rx,
    };
    tokio::join!(
        up.copy(client_read, server_write),
        down.copy(server_read, client_write)
    );
}

/// One direction of a proxied connection.
struct Leg {
    direction: Direction,
    budget: Arc<Mutex<Budget>>,
    /// A cut on either leg closes both.
    cut_tx: watch::Sender<bool>,
    cut_rx: watch::Receiver<bool>,
}

impl Leg {
    /// Copies until EOF or a cut.
    async fn copy(mut self, mut from: OwnedReadHalf, mut to: OwnedWriteHalf) {
        let mut buf = vec![0; 4096];
        loop {
            let n = tokio::select! {
                read = from.read(&mut buf) => match read {
                    Ok(0) | Err(_) => break,
                    Ok(n) => n,
                },
                _ = self.cut_rx.changed() => return,
            };
            let allowed = take(&self.budget, self.direction, n);
            if to.write_all(&buf[..allowed]).await.is_err() {
                break;
            }
            if allowed < n {
                let _ = self.cut_tx.send(true);
                return;
            }
        }
        let _ = to.shutdown().await;
    }
}

/// How many of `n` bytes may pass; spends the budget.
fn take(budget: &Mutex<Budget>, direction: Direction, n: usize) -> usize {
    let mut budget = budget.lock().unwrap();
    match budget.left {
        Some((cut, left)) if cut == direction => {
            if n <= left {
                budget.left = Some((cut, left - n));
                n
            } else {
                budget.left = None;
                left
            }
        }
        _ => n,
    }
}
```

```rust
//! lookups themselves are in `http` and `srv`.

use crate::server::{Endpoint, Security};

/// Where a server setting came from (the UI says "found by ...").
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Source {
    /// Thunderbird's ISPDB.
    Ispdb,
    /// autoconfig.<domain>, run by the provider.
    Provider,
    /// <domain>/.well-known/autoconfig.
    WellKnown,
    /// DNS SRV records (RFC 6186, RFC 8314).
    Srv,
    /// imap.<domain> and smtp.<domain>; the user should check them.
    Guess,
}

/// One server and the name to sign in with.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Setting {
    pub endpoint: Endpoint,
    pub username: String,
}

/// Every usable server one source offered, in its order.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Candidates {
    pub imap: Vec<Setting>,
    pub smtp: Vec<Setting>,
}

/// The settings autoconfig settled on.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Found {
    pub imap: Setting,
    pub smtp: Setting,
    pub source: Source,
}

    pub weight: u16,
    pub port: u16,
    pub target: String,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]

    Imap,
    Smtp,

/// The lowercased domain of an address; None if it isn't one.
pub fn domain_of(email: &str) -> Option<String> {
    let (local, domain) = email.trim().rsplit_once('@')?;
    let domain = domain.to_ascii_lowercase();
    (!local.is_empty() && domain.contains('.') && is_hostname(&domain)).then_some(domain)
}

/// Letters, digits, '-' and '.', not starting or ending with a dot.
pub fn is_hostname(host: &str) -> bool {
    !host.is_empty()
        && host.len() <= 253
        && !host.starts_with('.')
        && !host.ends_with('.')
        && host
            .bytes()
            .all(|b| b.is_ascii_alphanumeric() || b == b'-' || b == b'.')
}

/// The config files to try, in order. https only: a plain-http answer
/// could come from anyone on the path.
pub fn config_urls(domain: &str) -> [(Source, String); 3] {
    [
        (
            Source::Ispdb,
            format!("https://autoconfig.thunderbird.net/v1.1/{domain}"),
        ),
        (
            Source::Provider,
            format!("https://autoconfig.{domain}/mail/config-v1.1.xml"),
        ),
        (
            Source::WellKnown,
            format!("https://{domain}/.well-known/autoconfig/mail/config-v1.1.xml"),
        ),
    ]
}

/// The SRV names to ask, implicit TLS first (RFC 8314).
pub fn srv_queries(domain: &str) -> [(String, Service, Security); 4] {
    [
        (
            format!("_imaps._tcp.{domain}"),
            Service::Imap,
            Security::Tls,
        ),
        (
            format!("_imap._tcp.{domain}"),
            Service::Imap,
            Security::StartTls,
        ),
        (
            format!("_submissions._tcp.{domain}"),
            Service::Smtp,
            Security::Tls,
        ),
        (
            format!("_submission._tcp.{domain}"),
            Service::Smtp,
            Security::StartTls,
        ),
    ]
}

/// SRV answers as settings: target "." means "not offered here" and is
/// dropped; lowest priority first, then highest weight. The username is
/// the address (RFC 6186 3.2).
pub fn srv_candidates(
    mut records: Vec<SrvRecord>,
    security: Security,
    email: &str,
) -> Vec<Setting> {
    records.sort_by_key(|r| (r.priority, std::cmp::Reverse(r.weight)));
    records
        .into_iter()
        .filter_map(|r| {
            let host = r.target.trim_end_matches('.').to_ascii_lowercase();
            (r.port != 0 && is_hostname(&host)).then(|| Setting {
                endpoint: Endpoint::new(&host, r.port, security),
                username: email.trim().to_owned(),
            })
        })
        .collect()
}

/// The first implicit-TLS server of each kind, else the first STARTTLS
/// one. None unless there is both an IMAP and an SMTP server.
pub fn best(candidates: &Candidates, source: Source) -> Option<Found> {
    fn pick(list: &[Setting]) -> Option<&Setting> {
        list.iter()
            .find(|s| s.endpoint.security == Security::Tls)
            .or_else(|| list.first())
    }
    Some(Found {
        imap: pick(&candidates.imap)?.clone(),
        smtp: pick(&candidates.smtp)?.clone(),
        source,
    })
}

/// The last resort, for the manual form to start from.
pub fn guess(domain: &str, email: &str) -> Found {
    let setting = |host: String, port| Setting {
        endpoint: Endpoint::new(&host, port, Security::Tls),
        username: email.trim().to_owned(),
    };
    Found {
        imap: setting(format!("imap.{domain}"), 993),
        smtp: setting(format!("smtp.{domain}"), 465),
        source: Source::Guess,
    }
}
```

```rust
//! Thunderbird's autoconfig format (config-v1.1.xml): the IMAP and SMTP
//! servers in it, with the %EMAIL...% placeholders filled in. Servers
//! without TLS ("plain") and other protocols (POP3) are skipped.

use quick_xml::Reader;
use quick_xml::XmlVersion;
use quick_xml::escape::resolve_predefined_entity;
use quick_xml::events::Event;

use super::plan::{Candidates, Setting, is_hostname};
use crate::server::{Endpoint, Security};

#[derive(Clone, Copy, PartialEq, Eq)]
enum Kind {
    Imap,
    Smtp,
}

#[derive(Default)]
struct Server {
    hostname: String,
    port: String,
    socket_type: String,
    username: String,
}

/// The servers in `xml` for `email`; None if it isn't an autoconfig file.
pub fn parse(xml: &str, email: &str) -> Option<Candidates> {
    let mut reader = Reader::from_str(xml);
    reader.config_mut().trim_text(true);
    let mut out = Candidates::default();
    let mut saw_root = false;
    let mut server: Option<(Kind, Server)> = None;
    let mut field: Option<String> = None;
    loop {
        match reader.read_event().ok()? {
            Event::Start(e) => {
                let name = e.local_name().as_ref().to_owned();
                saw_root |= name == "clientConfig";
                let kind = e.try_get_attribute("type").ok().flatten().and_then(|a| {
                    a.normalized_value(XmlVersion::Implicit1_0)
                        .ok()
                        .map(|v| v.into_owned())
                });
                match (name.as_str(), kind.as_deref()) {
                    ("incomingServer", Some("imap")) => {
                        server = Some((Kind::Imap, Server::default()))
                    }
                    ("outgoingServer", Some("smtp")) => {
                        server = Some((Kind::Smtp, Server::default()))
                    }
                    _ => field = Some(name),
                }
            }
            Event::Text(t) => push_text(&mut server, field.as_deref(), &t.xml10_content()),
            Event::GeneralRef(r) => {
                let text = match r.resolve_char_ref().ok().flatten() {
                    Some(c) => c.to_string(),
                    None => resolve_predefined_entity(&r).unwrap_or("").to_owned(),
                };
                push_text(&mut server, field.as_deref(), &text);
            }
            Event::End(e) => {
                let name = e.local_name();
                if matches!(name.as_ref(), "incomingServer" | "outgoingServer")
                    && let Some((kind, s)) = server.take()
                    && let Some(setting) = setting(&s, email)
                {
                    match kind {
                        Kind::Imap => out.imap.push(setting),
                        Kind::Smtp => out.smtp.push(setting),
                    }
                }
                field = None;
            }
            Event::Eof => break,
            _ => {}
        }
    }
    saw_root.then_some(out)
}

fn push_text(server: &mut Option<(Kind, Server)>, field: Option<&str>, text: &str) {
    let Some((_, s)) = server.as_mut() else {
        return;
    };
    let target = match field {
        Some("hostname") => &mut s.hostname,
        Some("port") => &mut s.port,
        Some("socketType") => &mut s.socket_type,
        Some("username") => &mut s.username,
        _ => return,
    };
    target.push_str(text);
}

fn setting(s: &Server, email: &str) -> Option<Setting> {
    let security = match s.socket_type.trim() {
        "SSL" => Security::Tls,
        "STARTTLS" => Security::StartTls,
        _ => return None,
    };
    let host = fill(s.hostname.trim(), email).to_ascii_lowercase();
    let port: u16 = s.port.trim().parse().ok().filter(|&p| p != 0)?;
    if !is_hostname(&host) {
        return None;
    }
    Some(Setting {
        endpoint: Endpoint::new(&host, port, security),
        username: fill(s.username.trim(), email),
    })
}

/// The placeholders Thunderbird defines.
fn fill(template: &str, email: &str) -> String {
    let email = email.trim();
    let (local, domain) = email.rsplit_once('@').unwrap_or((email, ""));
    template
        .replace("%EMAILADDRESS%", email)
        .replace("%EMAILLOCALPART%", local)
        .replace("%EMAILDOMAIN%", domain)
}
```

```rust
/// An HTTPS server on localhost: /moved redirects to /config, which
/// answers `body`; anything else is 404.
async fn https_server(ca: &Ca, body: String) -> u16 {
    let acceptor = ca.sign("localhost").acceptor();
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let port = listener.local_addr().unwrap().port();
    tokio::spawn(async move {
        while let Ok((tcp, _)) = listener.accept().await {
            let acceptor = acceptor.clone();
            let body = body.clone();
            tokio::spawn(async move {
                let Ok(mut tls) = acceptor.accept(tcp).await else {
                    return;
                };
                let mut buf = vec![0; 4096];
                let n = tls.read(&mut buf).await.unwrap_or(0);
                let request = String::from_utf8_lossy(&buf[..n]).into_owned();
                let reply = if request.starts_with("GET /moved ") {
                    format!(
                        "HTTP/1.1 301 Moved\r\nLocation: https://localhost:{port}/config\r\n\r\n"
                    )
                } else if request.starts_with("GET /config ") {
                    format!("HTTP/1.1 200 OK\r\nContent-Type: text/xml\r\n\r\n{body}")
                } else {
                    "HTTP/1.1 404 Not Found\r\n\r\n".to_owned()
                };
                let _ = tls.write_all(reply.as_bytes()).await;
                let _ = tls.shutdown().await;
            });
        }
    });
    port
}
```

```rust
//! Just enough HTTPS to fetch an autoconfig file: GET over HTTP/1.0 (so
//! no chunked replies), no cookies, no User-Agent, a size cap and at most
//! three redirects, all to https. The request and response handling is
//! pure; `get` only moves bytes.

use tokio::io::{AsyncReadExt, AsyncWriteExt};

use crate::connect;
use crate::error::{NetError, Result};
use crate::server::{Endpoint, Security};
use crate::tls::{self, Roots};

/// Autoconfig files are a few KiB; anything bigger isn't one.
pub const MAX_BODY: usize = 256 * 1024;
pub const MAX_REDIRECTS: usize = 3;

#[derive(Debug, PartialEq, Eq)]
pub struct Url {
    pub host: String,
    pub port: u16,
    pub path: String,
}

#[derive(Debug, PartialEq, Eq)]
pub enum Reply {
    Body(String),
    Redirect(String),
    /// Any other status: there is no file here.
    Nothing,
}

/// `https://host[:port]/path`; anything else (http, user info) is None.
pub fn parse_url(url: &str) -> Option<Url> {
    let rest = url.strip_prefix("https://")?;
    let (authority, path) = match rest.find('/') {
        Some(i) => (&rest[..i], &rest[i..]),
        None => (rest, "/"),
    };
    let (host, port) = match authority.rsplit_once(':') {
        Some((host, port)) => (host, port.parse().ok()?),
        None => (authority, 443),
    };
    let ok_path = path.bytes().all(|b| b.is_ascii_graphic());
    (super::plan::is_hostname(host) && ok_path).then(|| Url {
        host: host.to_ascii_lowercase(),
        port,
        path: path.to_owned(),
    })
}

pub fn request(url: &Url) -> String {
    format!(
        "GET {} HTTP/1.0\r\nHost: {}\r\nAccept: application/xml, text/xml\r\nConnection: close\r\n\r\n",
        url.path, url.host
    )
}

/// The whole response, read to EOF (HTTP/1.0).
pub fn parse_reply(raw: &[u8]) -> Reply {
    let Some(split) = raw.windows(4).position(|w| w == b"\r\n\r\n") else {
        return Reply::Nothing;
    };
    let head = String::from_utf8_lossy(&raw[..split]);
    let mut lines = head.split("\r\n");
    let status: u16 = lines
        .next()
        .and_then(|line| line.split(' ').nth(1))
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    let header = |wanted: &str| {
        head.split("\r\n").skip(1).find_map(|line| {
            let (name, value) = line.split_once(':')?;
            name.trim()
                .eq_ignore_ascii_case(wanted)
                .then(|| value.trim().to_owned())
        })
    };
    match status {
        200 => match String::from_utf8(raw[split + 4..].to_vec()) {
            Ok(body) => Reply::Body(body),
            Err(_) => Reply::Nothing,
        },
        301 | 302 | 303 | 307 | 308 => header("location").map_or(Reply::Nothing, Reply::Redirect),
        _ => Reply::Nothing,
    }
}

/// The file at `url`, following redirects; Ok(None) when there is none.
pub async fn get(url: &str, roots: &Roots) -> Result<Option<String>> {
    let mut url = url.to_owned();
    for _ in 0..=MAX_REDIRECTS {
        let parsed =
            parse_url(&url).ok_or_else(|| NetError::Refused(format!("not an https URL: {url}")))?;
        let raw = fetch_once(&parsed, roots).await?;
        if raw.len() > MAX_BODY {
            return Ok(None);
        }
        match parse_reply(&raw) {
            Reply::Body(body) => return Ok(Some(body)),
            Reply::Nothing => return Ok(None),
            Reply::Redirect(next) => url = next,
        }
    }
    Ok(None)
}

async fn fetch_once(url: &Url, roots: &Roots) -> Result<Vec<u8>> {
    // No pin: autoconfig hosts must have a certificate the system trusts.
    let endpoint = Endpoint::new(&url.host, url.port, Security::Tls);
    let mut stream = tls::connect(&endpoint, roots).await?;
    connect::within(async {
        stream.write_all(request(url).as_bytes()).await?;
        let mut raw = Vec::new();
        (&mut stream)
            .take(MAX_BODY as u64 + 8 * 1024)
            .read_to_end(&mut raw)
            .await?;
        Ok(raw)
    })
    .await
}
```

```rust
//! Finding an account's servers from its address: Thunderbird's ISPDB,
//! the provider's autoconfig file, the well-known URL, DNS SRV, then a
//! guess for the manual form. The order and choices are in `plan`; the
//! lookups sit behind [`Lookups`] so tests run without a network.

mod http;
pub mod plan;
mod srv;
mod xml;

use std::future::Future;

use crate::error::{NetError, Result};
use crate::tls::Roots;
use plan::{Candidates, Service};

pub use plan::{Found, Setting, Source, SrvRecord};

/// The two kinds of lookup autoconfig makes. Failures are "nothing
/// here": autoconfig moves on to the next source.
pub trait Lookups: Sync {
    /// The body at an https URL, or None.
    fn fetch(&self, url: &str) -> impl Future<Output = Option<String>> + Send;
    /// The SRV records for a name; empty if none.
    fn srv(&self, name: &str) -> impl Future<Output = Vec<SrvRecord>> + Send;
}

/// The real thing: HTTPS checked against `roots`, DNS from the system.
pub struct Internet {
    roots: Roots,
}

impl Internet {
    pub fn new(roots: Roots) -> Self {
        Self { roots }
    }
}

impl Lookups for Internet {
    async fn fetch(&self, url: &str) -> Option<String> {
        http::get(url, &self.roots).await.ok().flatten()
    }

    async fn srv(&self, name: &str) -> Vec<SrvRecord> {
        srv::lookup(name).await
    }
}

/// The settings for `email`. Only an address without a domain is an
/// error; when every lookup comes up empty, the answer is the guess.
pub async fn detect(email: &str, lookups: &impl Lookups) -> Result<Found> {
    let domain =
        plan::domain_of(email).ok_or_else(|| NetError::Refused("not an email address".into()))?;
    for (source, url) in plan::config_urls(&domain) {
        let Some(body) = lookups.fetch(&url).await else {
            continue;
        };
        if let Some(found) = xml::parse(&body, email).and_then(|c| plan::best(&c, source)) {
            return Ok(found);
        }
    }
    let mut candidates = Candidates::default();
    for (name, service, security) in plan::srv_queries(&domain) {
        let settings = plan::srv_candidates(lookups.srv(&name).await, security, email);
        match service {
            Service::Imap => candidates.imap.extend(settings),
            Service::Smtp => candidates.smtp.extend(settings),
        }
    }
    Ok(plan::best(&candidates, Source::Srv).unwrap_or_else(|| plan::guess(&domain, email)))
}
```

- Self-signed accepted only through the prompt and pinned per account; a changed pin stops: `trust::decide` and `NetError::{Untrusted, PinChanged}` (Task 2), pins kept per account outside the cache (Task 3, #19), Stalwart's self-signed certificate used through exactly that path in every Stalwart test (Task 6).
- Passwords in `secrecy`: `Credentials.password: SecretString`, `Debug` redacted (Task 1). See concerns below for copies that libraries make.
- Error kinds: `NetError` maps onto Temporary (`is_temporary`), Sign-in, Certificate and Refused (Task 1); core does the wording.
- Testing: Stalwart in Docker with a fault-injecting TCP proxy (Tasks 6 and 7), self-signed and changed-certificate cases (Task 2 with rcgen certificates, Task 6 with Stalwart's). Unit tests for every pure module.
- CI: Stalwart in the dind runner (Task 6), only when envio-net is picked; #6, #9, #10 (Task 10). #16 is out of scope (Decision 14).

**Placeholder scan.** Every code step has the full file or an exact diff; the two "tests block only" steps (Tasks 1 and 8) point at the test module printed in full in the next step.

**Type consistency.** Checked by building each task's state from origin/master in order: `Endpoint::new` (3 arguments, no pin), `Roots::{system, from_der, empty}`, `ImapSession::open(&Endpoint, &Roots, &Credentials)`, `SmtpSession::connect(&Endpoint, &Roots)` then `login`, `Lookups::{fetch, srv}`, `Stalwart::{find, endpoint, imap}` are the same everywhere they are used; store's `Security` is a separate type from net's on purpose (Decision 4).

**Known limits and open points.**
- lettre copies the password into its own `String` for AUTH, which isn't wiped; async-imap does the same for LOGIN. The `SecretString` is wiped; the copies live only for the sign-in call.
- A password with non-ASCII characters goes in an IMAP quoted string as UTF-8, which servers without UTF8=ACCEPT may refuse; AUTHENTICATE PLAIN would avoid that and can be added if it shows up.
- The Message-ID fallback (Decision 9) only looks at the newest 200 messages; that covers sync's use (a just-appended message), not a general search.
- The dind steps and the per-run concurrency group are only proven by this branch's own CI run (Task 6 Step 6, Task 10).
- Under AppArmor confinement, `Roots::system()` reads the system certificate store; if the confined app can't read it, every server looks self-signed and the prompt appears. To check on a phone in Plan 7.
