# Envio Plan 3: envio-mime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/envio-mime`: parse mail into envelopes, bodies and attachment lists; render plain text and sanitized HTML as Qt rich text with remote images blocked and trackers removed; build outgoing mail with our own Message-ID and no hostname; reply, reply all, forward, `mailto:` and the thread root.

**Architecture:** A pure library: bytes and strings in, values out. No I/O, no other envio crate, no gettext (every user-facing string is passed in by core). `mail.rs` is the only caller of mail-parser; `envelope.rs`, `message.rs` and `attachments.rs` turn its result into envio types, and mail that can't be made sense of becomes `Message::Raw` (the spec's "Strange message"). HTML goes through one static ammonia `Builder` limited to Qt's rich-text subset, then a small tag pass (`images.rs`) decides about images and over-wide tables. Outgoing mail is built with mail-builder, but the Message-ID, Date and recipient list are always ours. Nothing here panics on mail; functions return `Option` or total values, so there is no error type.

**Tech Stack:** Rust 1.94 (edition 2024), mail-parser 0.11.9 (`full_encoding`), mail-builder 2.0.1 (no default features), ammonia 4.2.4, getrandom 0.4.3, insta 1.49 (tests).

**Spec:** `docs/superpowers/specs/2026-11-07-envio-design.md`, sections "Scope", "Architecture", "Passwords, certificates, privacy", "Error handling", "Testing and CI".

## Global Constraints

- `rust-version = "1.94"`, `edition = "2024"`, licence `GPL-3.0-only`, all from `[workspace.package]`; the crate has `[lints] workspace = true`.
- The core is Qt-free; `unsafe_code = "forbid"` in the root workspace.
- Dependencies point one way: core → sync → net, store, mime. `envio-mime` depends on no other envio crate.
- Pure: no I/O except tests reading their fixtures. Logic kept out of I/O code.
- User-facing text comes from the caller ("On … wrote:", forward labels, the blocked-image label). No gettext here.
- Mail is untrusted input: nothing panics on it. Functions return `Option` or total values.
- Privacy: remote images are blocked by default; tracking pixels are removed even when images are allowed; a link keeps its real address. Nothing we emit carries the hostname, a User-Agent or an X-Mailer.
- Files around 300 lines; one concept per module.
- Single-crate integration tests go in `crates/envio-mime/tests/`.
- Clippy: `clippy::all` plus `cognitive_complexity` (threshold 15), `too-many-arguments-threshold = 4` (so at most 4 parameters, `self` included; use a struct for options); CI runs clippy with `-D warnings`.
- `cargo make ci` (fmt, clippy, tests, audit) must pass.

## Decisions (where the brief leaves a gap)

1. **No `MimeError`.** Nothing needs one: parsing falls back to `Message::Raw`, lookups return `Option`, building is total. No thiserror dependency.
2. **Versions.** mail-parser 1.0 needs rustc 1.98, so 0.11.9 (the last 0.11). mail-builder 2.0.1 without default features (that drops `gethostname`); it only writes its own `Message-ID: <…@localhost>` when none is set, and `build` always sets ours. `getrandom` 0.4 is already in `Cargo.lock` (through tempfile). All resolve with the workspace's MSRV-aware resolver 3.
3. **`Envelope.from` is a `Vec<Address>`** (RFC 5322 allows several) and `subject` is a `String` (empty when missing). `Envelope::thread_root()` is a helper over `thread_root`.
4. **What counts as "strange" (`Message::Raw`):** mail-parser finds none of From, To, Subject, Date, Message-ID or Content-Type, or the message says multipart but its boundary never appears. `envelope()` still returns `Some` for the broken multipart, so the list shows it; `parse()` gives `Raw`, so the reader shows the text.
5. **Body choice:** the first HTML body part if there is one, else the first text part, else `Empty`. `has_attachments` ignores inline parts; `text/calendar` parts count as attachments.
6. **`reply` takes a `Quote { text, attribution }`** instead of two string arguments, to stay within four parameters. Replying to my own message (every From address is mine) goes to the original To.
7. **Quoting:** each quoted line gets `> `, except an empty line (`>`) and a line that is already quoted (`>>`, no space), as mail clients do. The signature after `-- ` is dropped.
8. **Forward header** starts with `---------- <label> ----------`, then From, Date, Subject and To lines with the caller's labels.
9. **`new_message_id`:** 16 random bytes as hex, then `@` and the sender's domain, or `@invalid` when the address has no usable domain. If getrandom fails, it falls back to std's `RandomState` hashes.
10. **Extra modules** beyond the brief, to keep files small: `mail.rs` (the only mail-parser caller and the strange-mail checks), `preview.rs`, `attachments.rs`, `images.rs` (the image and width pass after ammonia).
11. **Qt subset:** the brief's tags plus `cite`, `kbd`, `var`, `samp` and `dfn`, which Qt also supports. Dropped with their content: the brief's list plus `embed`, `applet`, `link`, `title`, `head`, `noscript`, `template`, `frame`, `frameset`, `select`, `textarea` and `button`. Style values also refuse `/*`, `<`, `>`, `javascript:` and `vbscript:`, and need balanced quotes.
12. **Images:** `width`/`height` are allowed in an img's `style` and become attributes; a tracker is width or height ≤ 2 px, or a host on a built-in list (whole labels only). An image wider than `max_image_width` is scaled down keeping its aspect ratio; a table, td or th width above it is dropped (percentages stay). `max_image_width = 0` means no limit. A blocked image becomes its alt text, else `blocked_label`. `cid:` lookups go through `normalize_id`; `cid:` hrefs are dropped.
13. **Plain text:** `www.` links get `https://`; email equality ignores ASCII case only. `Address::parse` (for `mailto:`) is added.
14. **`mailto:`** decodes `%XX`, leaves `+` as is and keeps invalid escapes as written.
15. **Snapshots** are a hand-written text description per corpus file (not insta's Debug output), so they read well in review. CI sets `INSTA_UPDATE: "no"` so a missing or changed snapshot fails instead of being written.
16. **Fixtures** are ASCII with LF line endings. The format=flowed fixture is quoted-printable, so its trailing spaces are `=20` and survive editors and git.
17. **`build`** never calls mail-builder's `.bcc()`: Bcc goes only into `Built.recipients`.

```rust
//! A mailbox: an optional display name and an email address.

/// One mailbox, as shown to the user and written into headers.
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Address {
    pub name: Option<String>,
    pub email: String,
}

impl Address {
    /// An address with an optional name. A blank name counts as none.
    pub fn new(name: Option<&str>, email: &str) -> Self {
        let name = name.map(str::trim).filter(|n| !n.is_empty());
        Self {
            name: name.map(str::to_owned),
            email: email.trim().to_owned(),
        }
    }

    /// Reads `Name <email>`, `<email>` or a bare `email`. `None` when there
    /// is no `@` in the address part.
    pub fn parse(text: &str) -> Option<Self> {
        let text = text.trim();
        let (name, email) = match (text.rfind('<'), text.ends_with('>')) {
            (Some(open), true) => (
                Some(text[..open].trim().trim_matches('"')),
                &text[open + 1..text.len() - 1],
            ),
            _ => (None, text),
        };
        email.contains('@').then(|| Self::new(name, email))
    }

    /// "Name <email>", or the bare email when there is no name.
    pub fn display(&self) -> String {
        match &self.name {
            Some(name) => format!("{name} <{}>", self.email),
            None => self.email.clone(),
        }
    }

    /// Whether this is the given email, ignoring ASCII case.
    pub fn is(&self, email: &str) -> bool {
        same_email(&self.email, email)
    }
}

/// Email equality as users expect it: ASCII case and outer spaces ignored.
pub fn same_email(a: &str, b: &str) -> bool {
    a.trim().eq_ignore_ascii_case(b.trim())
}
```

```rust
//! Message-ID normalization and the thread root.

/// A Message-ID without its angle brackets or outer spaces; `None` when
/// nothing is left.
pub fn normalize_id(raw: &str) -> Option<String> {
    let id = raw.trim();
    let id = id.strip_prefix('<').unwrap_or(id);
    let id = id.strip_suffix('>').unwrap_or(id).trim();
    (!id.is_empty()).then(|| id.to_owned())
}

/// The id a thread is grouped under: the first reference, else the
/// In-Reply-To, else the message's own id. Normalized; empty when the
/// message has no ids at all.
pub fn thread_root(message_id: &str, in_reply_to: Option<&str>, references: &[String]) -> String {
    references
        .iter()
        .find_map(|r| normalize_id(r))
        .or_else(|| in_reply_to.and_then(normalize_id))
        .or_else(|| normalize_id(message_id))
        .unwrap_or_default()
}
```

```rust
//! The one-line preview shown in the message list.

/// Longest preview, in characters.
pub const PREVIEW_CHARS: usize = 200;

/// The first [`PREVIEW_CHARS`] characters of `text`, whitespace collapsed,
/// `>` quoted lines dropped, and nothing from the signature line (`-- `) on.
pub fn preview(text: &str) -> String {
    let mut out = String::new();
    let mut count = 0;
    for line in text.lines() {
        if is_signature_line(line) {
            break;
        }
        if line.trim_start().starts_with('>') {
            continue;
        }
        for word in line.split_whitespace() {
            if !push_word(&mut out, &mut count, word) {
                return out;
            }
        }
    }
    out
}

/// The RFC 3676 signature separator, also when a client trimmed its space.
pub(crate) fn is_signature_line(line: &str) -> bool {
    line == "-- " || line.trim_end() == "--"
}

/// Appends `word` (with a separating space) up to the limit; false once full.
fn push_word(out: &mut String, count: &mut usize, word: &str) -> bool {
    if !out.is_empty() {
        if *count >= PREVIEW_CHARS {
            return false;
        }
        out.push(' ');
        *count += 1;
    }
    for c in word.chars() {
        if *count >= PREVIEW_CHARS {
            return false;
        }
        out.push(c);
        *count += 1;
    }
    true
}
```

```rust
//! The one place that calls mail-parser, and the checks for "strange" mail.

use mail_parser::{MessageParser, MimeHeaders, PartType};

pub(crate) type Parsed<'x> = mail_parser::Message<'x>;

/// Parses a full message or a header-only blob. `None` when it doesn't look
/// like mail: mail-parser found no headers, or none of the ones every mail
/// has (From, To, Subject, Date, Message-ID, Content-Type).
pub(crate) fn parse_mail(raw: &[u8]) -> Option<Parsed<'_>> {
    let message = MessageParser::default().parse(raw)?;
    let looks_like_mail = message.from().is_some()
        || message.to().is_some()
        || message.subject().is_some()
        || message.date().is_some()
        || message.message_id().is_some()
        || message.content_type().is_some();
    looks_like_mail.then_some(message)
}

/// A multipart message whose boundary never shows up: mail-parser keeps the
/// whole body as one part. Shown as raw text, not as a lone attachment.
pub(crate) fn is_broken_multipart(message: &Parsed<'_>) -> bool {
    let declared = message
        .content_type()
        .is_some_and(|ct| ct.c_type.eq_ignore_ascii_case("multipart"));
    let root_is_multipart = matches!(message.root_part().body, PartType::Multipart(_));
    declared && !root_is_multipart
}
```

```rust
//! Listing a message's attachments and fetching one's decoded bytes.

use mail_parser::{MessagePart, MimeHeaders};

use crate::mail::{Parsed, is_broken_multipart, parse_mail};
use crate::thread::normalize_id;

/// One attachment as the reader lists it.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AttachmentInfo {
    /// Position in the message's attachment list; pass it to
    /// [`attachment_bytes`].
    pub index: usize,
    pub filename: Option<String>,
    /// `type/subtype`, lower case.
    pub content_type: String,
    /// Decoded size in bytes.
    pub size: usize,
    /// Content-ID without angle brackets (what `cid:` URLs name).
    pub content_id: Option<String>,
    /// Shown inside the body (an inline image) rather than as a file.
    pub inline: bool,
}

/// Every attachment, `text/calendar` parts included. Empty for a broken
/// multipart message.
pub(crate) fn list(message: &Parsed<'_>) -> Vec<AttachmentInfo> {
    if is_broken_multipart(message) {
        return Vec::new();
    }
    message
        .attachments()
        .enumerate()
        .map(|(index, part)| info(index, part))
        .collect()
}

/// The decoded bytes of attachment `index`, as listed by [`crate::parse`].
pub fn attachment_bytes(raw: &[u8], index: usize) -> Option<Vec<u8>> {
    let message = parse_mail(raw)?;
    if is_broken_multipart(&message) {
        return None;
    }
    let index = u32::try_from(index).ok()?;
    Some(message.attachment(index)?.contents().to_vec())
}

fn info(index: usize, part: &MessagePart<'_>) -> AttachmentInfo {
    let content_type = part.content_type().map_or_else(
        || "application/octet-stream".to_owned(),
        |ct| match ct.subtype() {
            Some(sub) => format!("{}/{}", ct.ctype(), sub).to_ascii_lowercase(),
            None => ct.ctype().to_ascii_lowercase(),
        },
    );
    let content_id = part.content_id().and_then(normalize_id);
    let disposition = part.content_disposition();
    let inline = match disposition {
        Some(d) => d.is_inline(),
        None => content_id.is_some(),
    };
    AttachmentInfo {
        index,
        filename: part.attachment_name().map(str::to_owned),
        content_type,
        size: part.len(),
        content_id,
        inline,
    }
}
```

```rust
//! The envelope: what the message list and the store keep for each message.

use mail_parser::HeaderValue;

use crate::address::{Address, from_header};
use crate::mail::{Parsed, parse_mail};
use crate::preview::preview;
use crate::thread::{normalize_id, thread_root};

/// Headers plus the preview and the attachment flag.
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct Envelope {
    /// Without angle brackets.
    pub message_id: Option<String>,
    /// Decoded; empty when missing.
    pub subject: String,
    pub from: Vec<Address>,
    pub to: Vec<Address>,
    pub cc: Vec<Address>,
    pub reply_to: Vec<Address>,
    /// Unix seconds; `None` when missing or invalid.
    pub date: Option<i64>,
    /// Without angle brackets.
    pub in_reply_to: Option<String>,
    /// Without angle brackets, oldest first.
    pub references: Vec<String>,
    pub preview: String,
    /// A non-inline attachment is present.
    pub has_attachments: bool,
}

impl Envelope {
    /// The id this message's thread is grouped under.
    pub fn thread_root(&self) -> String {
        thread_root(
            self.message_id.as_deref().unwrap_or_default(),
            self.in_reply_to.as_deref(),
            &self.references,
        )
    }
}

/// The envelope of a full message or a header-only blob (then the preview is
/// empty). `None` when the bytes don't look like mail.
pub fn envelope(raw: &[u8]) -> Option<Envelope> {
    parse_mail(raw).map(|message| from_parsed(&message))
}

pub(crate) fn from_parsed(message: &Parsed<'_>) -> Envelope {
    let attachments = crate::attachments::list(message);
    Envelope {
        message_id: message.message_id().and_then(normalize_id),
        subject: message.subject().unwrap_or_default().trim().to_owned(),
        from: from_header(message.from()),
        to: from_header(message.to()),
        cc: from_header(message.cc()),
        reply_to: from_header(message.reply_to()),
        date: message
            .date()
            .filter(|d| d.is_valid())
            .map(|d| d.to_timestamp()),
        in_reply_to: ids(message.in_reply_to()).into_iter().next(),
        references: ids(message.references()),
        preview: message
            .body_text(0)
            .map(|text| preview(&text))
            .unwrap_or_default(),
        has_attachments: attachments.iter().any(|a| !a.inline),
    }
}

/// Message-IDs from an In-Reply-To or References header, normalized.
fn ids(value: &HeaderValue<'_>) -> Vec<String> {
    match value {
        HeaderValue::Text(id) => normalize_id(id).into_iter().collect(),
        HeaderValue::TextList(list) => list.iter().filter_map(|id| normalize_id(id)).collect(),
        _ => Vec::new(),
    }
}
```

```rust
//! A whole message for the reader: envelope, chosen body, attachments.

use mail_parser::{MessagePart, MimeHeaders, PartType};

use crate::attachments::{AttachmentInfo, list};
use crate::envelope::{Envelope, from_parsed};
use crate::mail::{Parsed, is_broken_multipart, parse_mail};

/// A parsed message, or the spec's "Strange message": raw text to show as is.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Message {
    Parsed {
        envelope: Box<Envelope>,
        body: Body,
        attachments: Vec<AttachmentInfo>,
    },
    /// The whole message as lossy UTF-8.
    Raw(String),
}

/// The body the reader shows. HTML wins when there is an alternative.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Body {
    Html(String),
    /// `flowed` and `delsp` come from `format=flowed; delsp=yes` (RFC 3676).
    Text {
        text: String,
        flowed: bool,
        delsp: bool,
    },
    Empty,
}

/// Parses a full message. Never panics; mail that can't be made sense of
/// comes back as [`Message::Raw`].
pub fn parse(raw: &[u8]) -> Message {
    match parse_mail(raw) {
        Some(message) if !is_broken_multipart(&message) => Message::Parsed {
            envelope: Box::new(from_parsed(&message)),
            body: body(&message),
            attachments: list(&message),
        },
        _ => Message::Raw(String::from_utf8_lossy(raw).into_owned()),
    }
}

fn body(message: &Parsed<'_>) -> Body {
    if let Some(PartType::Html(html)) = message.html_part(0).map(|p| &p.body) {
        return Body::Html(html.to_string());
    }
    match message.text_part(0) {
        Some(part) => text_body(part),
        None => Body::Empty,
    }
}

fn text_body(part: &MessagePart<'_>) -> Body {
    let PartType::Text(text) = &part.body else {
        return Body::Empty;
    };
    let param = |name: &str, want: &str| {
        part.content_type()
            .and_then(|ct| ct.attribute(name))
            .is_some_and(|v| v.trim().eq_ignore_ascii_case(want))
    };
    Body::Text {
        text: text.to_string(),
        flowed: param("format", "flowed"),
        delsp: param("delsp", "yes"),
    }
}
```

```rust
//! Plain text to Qt rich text: format=flowed, quotes, links, escaping.

/// Wraps the output so Qt keeps runs of spaces and wraps long lines.
const BLOCK_STYLE: &str = "white-space:pre-wrap";
const SCHEMES: [&str; 4] = ["https://", "http://", "mailto:", "www."];

/// One displayed line and its quote depth.
#[derive(Debug, PartialEq, Eq)]
struct Line {
    depth: usize,
    text: String,
}

/// Plain text as Qt rich text. `flowed` and `delsp` are the RFC 3676
/// parameters of the text part; quote levels become nested blockquotes and
/// http, https, mailto and `www.` addresses become links.
pub fn plain_to_rich(text: &str, flowed: bool, delsp: bool) -> String {
    let lines = if flowed {
        unflow(text, delsp)
    } else {
        text.lines().map(fixed_line).collect()
    };
    let mut out = format!("<div style=\"{BLOCK_STYLE}\">");
    let mut depth = 0;
    let mut first = true;
    for line in &lines {
        if line.depth != depth {
            change_depth(&mut out, depth, line.depth);
            depth = line.depth;
            first = true;
        }
        if !first {
            out.push_str("<br>");
        }
        linkify(&line.text, &mut out);
        first = false;
    }
    change_depth(&mut out, depth, 0);
    out.push_str("</div>");
    out
}

/// HTML-escapes `text` into `out`.
pub(crate) fn escape_into(text: &str, out: &mut String) {
    for c in text.chars() {
        match c {
            '&' => out.push_str("&amp;"),
            '<' => out.push_str("&lt;"),
            '>' => out.push_str("&gt;"),
            '"' => out.push_str("&quot;"),
            _ => out.push(c),
        }
    }
}

fn change_depth(out: &mut String, from: usize, to: usize) {
    for _ in to..from {
        out.push_str("</blockquote>");
    }
    for _ in from..to {
        out.push_str("<blockquote style=\"");
        out.push_str(BLOCK_STYLE);
        out.push_str("\">");
    }
}

/// Counts leading `>` marks (spaces between them allowed) and strips them
/// plus one following space.
fn split_quote(line: &str) -> (usize, &str) {
    let mut depth = 0;
    let mut rest = line;
    loop {
        if let Some(r) = rest.strip_prefix('>') {
            depth += 1;
            rest = r;
        } else if depth > 0 && rest.starts_with(" >") {
            rest = &rest[1..];
        } else {
            break;
        }
    }
    let rest = if depth > 0 {
        rest.strip_prefix(' ').unwrap_or(rest)
    } else {
        rest
    };
    (depth, rest)
}

fn fixed_line(line: &str) -> Line {
    let (depth, text) = split_quote(line);
    Line {
        depth,
        text: text.to_owned(),
    }
}

/// RFC 3676: a line ending in a space continues on the next line of the
/// same quote depth. With delsp=yes that space is removed. A leading space
/// on an unquoted line is space-stuffing and is removed.
fn unflow(text: &str, delsp: bool) -> Vec<Line> {
    let mut out: Vec<Line> = Vec::new();
    let mut open = false;
    for raw in text.lines() {
        let (depth, body) = split_quote(raw);
        let body = if depth == 0 {
            body.strip_prefix(' ').unwrap_or(body)
        } else {
            body
        };
        let soft = body.ends_with(' ') && body != "-- ";
        let piece = if soft && delsp {
            &body[..body.len() - 1]
        } else {
            body
        };
        match out.last_mut() {
            Some(last) if open && last.depth == depth => last.text.push_str(piece),
            _ => out.push(Line {
                depth,
                text: piece.to_owned(),
            }),
        }
        open = soft;
    }
    out
}

/// Escapes `line` into `out`, turning addresses into links. The link text
/// is the address exactly as written; `www.` links get `https://`.
fn linkify(line: &str, out: &mut String) {
    let lower = line.to_ascii_lowercase();
    let mut pos = 0;
    while let Some((start, end)) = next_link(line, &lower, pos) {
        escape_into(&line[pos..start], out);
        let url = &line[start..end];
        let href = if lower[start..].starts_with("www.") {
            format!("https://{url}")
        } else {
            url.to_owned()
        };
        out.push_str("<a href=\"");
        escape_into(&href, out);
        out.push_str("\">");
        escape_into(url, out);
        out.push_str("</a>");
        pos = end;
    }
    escape_into(&line[pos..], out);
}

/// The byte range of the next link at or after `from`. A link starts at a
/// word boundary and needs at least one character after its scheme.
fn next_link(line: &str, lower: &str, from: usize) -> Option<(usize, usize)> {
    let mut search = from;
    loop {
        let (start, scheme) = SCHEMES
            .iter()
            .filter_map(|s| lower[search..].find(s).map(|i| (i + search, *s)))
            .min_by_key(|(i, _)| *i)?;
        let at_boundary = line[..start]
            .chars()
            .next_back()
            .is_none_or(|c| c.is_whitespace() || "(<[\"'".contains(c));
        let end = url_end(line, start);
        if at_boundary && end > start + scheme.len() {
            return Some((start, end));
        }
        // Schemes are ASCII, so the next byte is a char boundary.
        search = start + 1;
    }
}

/// Where the address starting at `start` ends: at whitespace, `<`, `>` or
/// `"`, minus trailing punctuation and an unbalanced `)`.
fn url_end(line: &str, start: usize) -> usize {
    let rest = &line[start..];
    let len = rest
        .find(|c: char| c.is_whitespace() || matches!(c, '<' | '>' | '"'))
        .unwrap_or(rest.len());
    let mut url = &rest[..len];
    loop {
        let mut trimmed = url.trim_end_matches(['.', ',', ';', ':', '!', '?', '\'']);
        if trimmed.ends_with(')') && !trimmed.contains('(') {
            trimmed = &trimmed[..trimmed.len() - 1];
        }
        if trimmed.len() == url.len() {
            break;
        }
        url = trimmed;
    }
    start + url.len()
}
```

```rust
/// Runs on every attribute ammonia kept. Links keep their exact address
/// (the reader shows it) but only for http, https and mailto.
fn filter_attribute<'u>(element: &str, attribute: &str, value: &'u str) -> Option<Cow<'u, str>> {
    match attribute {
        "href" => {
            has_scheme(value, &["http:", "https:", "mailto:"]).then_some(Cow::Borrowed(value))
        }
        "src" => has_scheme(value, &["http:", "https:", "cid:"]).then_some(Cow::Borrowed(value)),
        "style" => filter_style(element, value).map(Cow::Owned),
        _ => Some(Cow::Borrowed(value)),
    }
}

fn has_scheme(url: &str, schemes: &[&str]) -> bool {
    let url = url.trim_start().to_ascii_lowercase();
    schemes.iter().any(|s| url.starts_with(s))
}

/// Keeps only allowed properties with safe values; `None` when nothing is
/// left.
pub(crate) fn filter_style(element: &str, style: &str) -> Option<String> {
    let kept: Vec<String> = style
        .split(';')
        .filter_map(|declaration| {
            let (prop, value) = declaration.split_once(':')?;
            let prop = prop.trim().to_ascii_lowercase();
            let value = value.trim();
            let allowed = STYLE_PROPS.contains(&prop.as_str())
                || (element == "img" && IMG_SIZE_PROPS.contains(&prop.as_str()));
            (allowed && safe_css_value(value)).then(|| format!("{prop}:{value}"))
        })
        .collect();
    (!kept.is_empty()).then(|| kept.join(";"))
}

fn safe_css_value(value: &str) -> bool {
    let lower = value.to_ascii_lowercase();
    let balanced = |q: char| value.chars().filter(|&c| c == q).count() % 2 == 0;
    !value.is_empty()
        && !BAD_CSS.iter().any(|bad| lower.contains(bad))
        && balanced('"')
        && balanced('\'')
}
```

```rust
//! Second pass over ammonia's output: images (remote, `cid:`, trackers)
//! and over-wide tables. Ammonia's serializer always double-quotes
//! attribute values and escapes `<` in text, so every `<` starts a tag and
//! a quote-aware scan finds where it ends.

use crate::plain::escape_into;
use crate::sanitize::{RenderOptions, Rendered};

/// Hosts that serve tracking pixels; subdomains match too.
const TRACKER_HOSTS: &[&str] = &[
    "google-analytics.com",
    "doubleclick.net",
    "list-manage.com",
    "mandrillapp.com",
    "sendgrid.net",
    "mailtrack.io",
    "mailfoogae.appspot.com",
    "pixel.wp.com",
    "bat.bing.com",
    "t.yesware.com",
    "r.superhuman.com",
    "bananatag.com",
    "getnotify.com",
    "mailstat.us",
];

/// An image this small (width or height, in pixels) is a tracking pixel.
const PIXEL_MAX: u32 = 2;

/// A start tag: lower-case name and unescaped attribute values.
struct Tag {
    name: String,
    attrs: Vec<(String, String)>,
}

impl Tag {
    fn attr(&self, name: &str) -> Option<&str> {
        self.attrs
            .iter()
            .find(|(n, _)| n == name)
            .map(|(_, v)| v.as_str())
    }

    fn write(&self, out: &mut String) {
        out.push('<');
        out.push_str(&self.name);
        for (name, value) in &self.attrs {
            out.push(' ');
            out.push_str(name);
            out.push_str("=\"");
            escape_into(value, out);
            out.push('"');
        }
        out.push('>');
    }
}

/// Applies the image and width rules to sanitized HTML.
pub(crate) fn fit(html: &str, options: &RenderOptions) -> Rendered {
    let mut out = Rendered {
        html: String::with_capacity(html.len()),
        ..Rendered::default()
    };
    let mut rest = html;
    while let Some(start) = rest.find('<') {
        out.html.push_str(&rest[..start]);
        let len = tag_len(&rest[start..]);
        let raw = &rest[start..start + len];
        match parse_tag(raw) {
            Some(tag) if tag.name == "img" => image(&tag, options, &mut out),
            Some(mut tag) if matches!(tag.name.as_str(), "table" | "td" | "th") => {
                limit_width(&mut tag, options.max_image_width);
                tag.write(&mut out.html);
            }
            _ => out.html.push_str(raw),
        }
        rest = &rest[start + len..];
    }
    out.html.push_str(rest);
    out
}

/// Bytes up to and including the `>` that closes the tag at the start of
/// `s`, skipping `>` inside double-quoted values.
fn tag_len(s: &str) -> usize {
    let mut quoted = false;
    for (i, c) in s.char_indices() {
        match c {
            '"' => quoted = !quoted,
            '>' if !quoted => return i + 1,
            _ => {}
        }
    }
    s.len()
}

/// Parses `<name a="v" ...>`; `None` for end tags and anything else.
fn parse_tag(raw: &str) -> Option<Tag> {
    let inner = raw.strip_prefix('<')?.strip_suffix('>')?;
    let inner = inner.strip_suffix('/').unwrap_or(inner);
    if !inner.starts_with(|c: char| c.is_ascii_alphabetic()) {
        return None;
    }
    let name_end = inner.find(char::is_whitespace).unwrap_or(inner.len());
    let mut tag = Tag {
        name: inner[..name_end].to_ascii_lowercase(),
        attrs: Vec::new(),
    };
    let mut rest = inner[name_end..].trim_start();
    while !rest.is_empty() {
        let name_len = rest
            .find(|c: char| c == '=' || c.is_whitespace())
            .unwrap_or(rest.len());
        let name = rest[..name_len].to_ascii_lowercase();
        rest = &rest[name_len..];
        let value = match rest.strip_prefix("=\"") {
            Some(after) => {
                let end = after.find('"')?;
                rest = &after[end + 1..];
                unescape(&after[..end])
            }
            None => String::new(),
        };
        tag.attrs.push((name, value));
        rest = rest.trim_start();
    }
    Some(tag)
}

/// Undoes html5ever's attribute escaping (`&amp;` last, so `&amp;lt;`
/// stays `&lt;`).
fn unescape(value: &str) -> String {
    value
        .replace("&quot;", "\"")
        .replace("&lt;", "<")
        .replace("&gt;", ">")
        .replace("&nbsp;", "\u{a0}")
        .replace("&amp;", "&")
}

fn image(tag: &Tag, options: &RenderOptions, out: &mut Rendered) {
    let src = tag.attr("src").unwrap_or_default().trim();
    let width = size(tag, "width");
    let height = size(tag, "height");
    if is_tracker(src, width, height) {
        out.removed_trackers += 1;
        return;
    }
    let lower = src.to_ascii_lowercase();
    let url = if lower.starts_with("cid:") {
        match cid_url(&src[4..], options) {
            Some(url) => url.to_owned(),
            None => return,
        }
    } else if lower.starts_with("http:") || lower.starts_with("https:") {
        if !options.allow_remote_images {
            out.blocked_images += 1;
            let alt = tag.attr("alt").map(str::trim).unwrap_or_default();
            let label = if alt.is_empty() {
                &options.blocked_label
            } else {
                alt
            };
            escape_into(label, &mut out.html);
            return;
        }
        src.to_owned()
    } else {
        return;
    };
    let (width, height) = scale(width, height, options.max_image_width);
    let mut attrs = vec![("src".to_owned(), url)];
    if let Some(alt) = tag.attr("alt") {
        attrs.push(("alt".to_owned(), alt.to_owned()));
    }
    if let Some(w) = width {
        attrs.push(("width".to_owned(), w.to_string()));
    }
    if let Some(h) = height {
        attrs.push(("height".to_owned(), h.to_string()));
    }
    Tag {
        name: "img".to_owned(),
        attrs,
    }
    .write(&mut out.html);
}

/// The loadable URL for a `cid:` reference, with or without angle brackets.
fn cid_url<'o>(cid: &str, options: &'o RenderOptions) -> Option<&'o str> {
    let id = crate::thread::normalize_id(cid)?;
    options.cid_urls.get(&id).map(String::as_str)
}

fn is_tracker(src: &str, width: Option<u32>, height: Option<u32>) -> bool {
    if width.is_some_and(|w| w <= PIXEL_MAX) || height.is_some_and(|h| h <= PIXEL_MAX) {
        return true;
    }
    let Some(host) = ammonia::Url::parse(src)
        .ok()
        .and_then(|url| url.host_str().map(str::to_ascii_lowercase))
    else {
        return false;
    };
    TRACKER_HOSTS.iter().any(|t| {
        host == *t
            || host
                .strip_suffix(t)
                .is_some_and(|prefix| prefix.ends_with('.'))
    })
}

/// A pixel size from the attribute, else from `style` (`width:20px`).
fn size(tag: &Tag, name: &str) -> Option<u32> {
    tag.attr(name).and_then(pixels).or_else(|| {
        tag.attr("style")
            .and_then(|s| style_value(s, name))
            .and_then(pixels)
    })
}

fn style_value<'s>(style: &'s str, name: &str) -> Option<&'s str> {
    style.split(';').find_map(|declaration| {
        let (prop, value) = declaration.split_once(':')?;
        prop.trim().eq_ignore_ascii_case(name).then_some(value)
    })
}

/// `20`, `20px` or ` 20 px` as pixels; percentages and the like are `None`.
fn pixels(value: &str) -> Option<u32> {
    let value = value.trim();
    let value = value.strip_suffix("px").unwrap_or(value).trim_end();
    value.parse().ok()
}

/// Scales a too-wide image down to `max`, keeping its aspect ratio when
/// the height is known.
fn scale(width: Option<u32>, height: Option<u32>, max: u32) -> (Option<u32>, Option<u32>) {
    match width {
        Some(w) if max > 0 && w > max => {
            let h = height.map(|h| {
                let scaled = u64::from(h) * u64::from(max) / u64::from(w);
                u32::try_from(scaled).unwrap_or(u32::MAX).max(1)
            });
            (Some(max), h)
        }
        _ => (width, height),
    }
}

/// Drops a pixel `width` wider than `max` from a table or cell.
fn limit_width(tag: &mut Tag, max: u32) {
    if max == 0 {
        return;
    }
    tag.attrs
        .retain(|(name, value)| name != "width" || pixels(value).is_none_or(|w| w <= max));
}
```

```rust
//! One entry point for the reader: any [`Message`] to Qt rich text.

use crate::message::{Body, Message};
use crate::plain::{escape_into, plain_to_rich};
use crate::sanitize::{RenderOptions, Rendered, sanitize_html};

/// The message body as Qt rich text. A raw ("strange") message is shown
/// as escaped preformatted text.
pub fn render(message: &Message, options: &RenderOptions) -> Rendered {
    let html = match message {
        Message::Raw(text) => {
            let mut html = String::from("<pre>");
            escape_into(text, &mut html);
            html.push_str("</pre>");
            html
        }
        Message::Parsed { body, .. } => match body {
            Body::Html(html) => return sanitize_html(html, options),
            Body::Text {
                text,
                flowed,
                delsp,
            } => plain_to_rich(text, *flowed, *delsp),
            Body::Empty => String::new(),
        },
    };
    Rendered {
        html,
        ..Rendered::default()
    }
}
```

```rust
/// Attribute names of a start tag (values skipped).
fn attribute_names(tag: &str) -> Vec<String> {
    let mut names = Vec::new();
    let mut chars = tag.trim_start_matches('<').chars().peekable();
    while chars.next_if(|c| !c.is_whitespace() && *c != '>').is_some() {}
    loop {
        while chars.next_if(|c| c.is_whitespace()).is_some() {}
        let name: String = std::iter::from_fn(|| {
            chars.next_if(|c| !c.is_whitespace() && !matches!(c, '=' | '>' | '/'))
        })
        .collect();
        if name.is_empty() {
            break;

        names.push(name.to_ascii_lowercase());
```

```rust
/// The snapshot text for one corpus file.
fn describe(raw: &[u8]) -> String {
    let mut out = String::new();
    match envelope(raw) {
        Some(e) => {
            writeln!(out, "message_id: {:?}", e.message_id).unwrap();
            writeln!(out, "subject: {:?}", e.subject).unwrap();
            writeln!(out, "from: {}", names(&e.from)).unwrap();
            writeln!(out, "to: {}", names(&e.to)).unwrap();
            writeln!(out, "cc: {}", names(&e.cc)).unwrap();
            writeln!(out, "reply_to: {}", names(&e.reply_to)).unwrap();
            writeln!(out, "date: {:?}", e.date).unwrap();
            writeln!(out, "in_reply_to: {:?}", e.in_reply_to).unwrap();
            writeln!(out, "references: {:?}", e.references).unwrap();
            writeln!(out, "thread_root: {:?}", e.thread_root()).unwrap();
            writeln!(out, "preview: {:?}", e.preview).unwrap();
            writeln!(out, "has_attachments: {}", e.has_attachments).unwrap();
        }
        None => writeln!(out, "envelope: none").unwrap(),
    }
    let message = parse(raw);
    match &message {
        Message::Parsed { attachments, .. } => {
            for a in attachments {
                writeln!(
                    out,
                    "attachment {}: {:?} {} {} bytes cid={:?} inline={}",
                    a.index, a.filename, a.content_type, a.size, a.content_id, a.inline
                )
                .unwrap();
            }
        }
        Message::Raw(_) => writeln!(out, "raw message").unwrap(),
    }
    let rendered = render(&message, &options());
    writeln!(
        out,
        "blocked: {} trackers: {}",
        rendered.blocked_images, rendered.removed_trackers
    )
    .unwrap();
    writeln!(out, "---").unwrap();
    out.push_str(&rendered.html);
    out
}
```

```rust
pub struct Built {

    pub bytes: Vec<u8>,

/// Builds the message. `date_unix` is the Date header (seconds) and
/// `message_id` (without angle brackets) comes from [`new_message_id`],
/// so a retry from the Outbox sends the same id.
pub fn build(outgoing: &Outgoing, date_unix: i64, message_id: &str) -> Built {
    let mut builder = MessageBuilder::new()
        .from(builder_address(&outgoing.from))
        .subject(outgoing.subject.as_str())
        .date(date_unix)
        .message_id(message_id)
        .text_body(outgoing.text.replace("\r\n", "\n"));
    if !outgoing.to.is_empty() {
        builder = builder.to(address_list(&outgoing.to));
    }
    if !outgoing.cc.is_empty() {
        builder = builder.cc(address_list(&outgoing.cc));
    }
    if let Some(id) = &outgoing.in_reply_to {
        builder = builder.in_reply_to(id.as_str());
    }
    if !outgoing.references.is_empty() {
        let refs: Vec<&str> = outgoing.references.iter().map(String::as_str).collect();
        builder = builder.references(refs);
    }
    for file in &outgoing.attachments {
        builder = builder.attachment(
            file.content_type.as_str(),
            file.filename.as_str(),
            file.bytes.as_slice(),
        );
    }
    let mut bytes = Vec::new();
    builder.serialize(&mut bytes);
    Built {
        message_id: message_id.to_owned(),
        bytes,
        recipients: recipients(outgoing),
    }
}

/// A fresh Message-ID (without angle brackets): 128 random bits in hex,
/// then `@` and the sender's domain. Never the device's hostname.
pub fn new_message_id(from_email: &str) -> String {
    let domain = from_email
        .rsplit_once('@')
        .map(|(_, d)| d.trim())
        .filter(|d| !d.is_empty() && !d.contains(['<', '>', ' ']))
        .unwrap_or("invalid");
    let mut random = [0u8; 16];
    if getrandom::fill(&mut random).is_err() {
        // No OS randomness: fall back to std's per-process random keys.
        let state = RandomState::new();
        let (a, b) = (state.hash_one(1u8), state.hash_one(2u8));
        random[..8].copy_from_slice(&a.to_le_bytes());
        random[8..].copy_from_slice(&b.to_le_bytes());
    }
    let hex: String = random.iter().map(|b| format!("{b:02x}")).collect();
    format!("{hex}@{domain}")
}

fn builder_address(address: &Address) -> BuilderAddress<'_> {
    BuilderAddress::new_address(address.name.as_deref(), address.email.as_str())
}

fn address_list(addresses: &[Address]) -> BuilderAddress<'_> {
    BuilderAddress::new_list(addresses.iter().map(builder_address).collect())
}

fn recipients(outgoing: &Outgoing) -> Vec<String> {
    let all = [&outgoing.to, &outgoing.cc, &outgoing.bcc]
        .into_iter()
        .flatten()
        .cloned()
        .collect();
    dedup(all).into_iter().map(|a| a.email).collect()
}
```

```rust
    All,

    pub quoted: String,
}

    pub fn quoted_lines(&self) -> usize {
        self.quoted.lines().count()
    }

            to: self.to,
            cc: self.cc,
            subject: self.subject,
            text: join(text, &self.quoted),
            in_reply_to: self.in_reply_to,
            references: self.references,

        }
    }

    /// The message to send. Recipients and the original attachments (see

/// A reply to `original`. `me` holds the user's own emails, which never end
/// up in Cc.
pub fn reply(original: &Envelope, quote: &Quote<'_>, me: &[String], kind: ReplyKind) -> ReplyDraft {
    let is_me = |a: &Address| me.iter().any(|m| a.is(m));
    let from_me = !original.from.is_empty() && original.from.iter().all(is_me);
    let to = if from_me {
        // Replying to my own sent message goes to its recipients.
        original.to.clone()
    } else if !original.reply_to.is_empty() {
        original.reply_to.clone()
    } else {
        original.from.clone()
    };
    let to = dedup(to);
    let cc = match kind {
        ReplyKind::Sender => Vec::new(),
        ReplyKind::All => {
            let all = original.to.iter().chain(&original.cc).cloned().collect();
            dedup(all)
                .into_iter()
                .filter(|a| !is_me(a) && !to.iter().any(|t| t.is(&a.email)))
                .collect()
        }
    };
    let mut references = original.references.clone();
    if let Some(id) = &original.message_id
        && !references.contains(id)
    {
        references.push(id.clone());
    }
    ReplyDraft {
        to,
        cc,
        subject: prefixed(&original.subject, "Re: ", &["re:"]),
        in_reply_to: original.message_id.clone(),
        references,
        quoted: quoted(quote),
    }
}

/// A forward of `original`. `date_text` is the original date, formatted by
/// the caller.
pub fn forward(
    original: &Envelope,
    original_text: &str,
    labels: &ForwardLabels,
    date_text: &str,
) -> ForwardDraft {
    let list = |addresses: &[Address]| {
        addresses
            .iter()
            .map(Address::display)
            .collect::<Vec<_>>()
            .join(", ")
    };
    let forwarded = format!(
        "---------- {} ----------\n{}: {}\n{}: {}\n{}: {}\n{}: {}\n\n{}",
        labels.forwarded_message,
        labels.from,
        list(&original.from),
        labels.date,
        date_text,
        labels.subject,
        original.subject,
        labels.to,
        list(&original.to),
        original_text.trim_end(),
    );
    ForwardDraft {
        subject: prefixed(&original.subject, "Fwd: ", &["fwd:", "fw:"]),
        forwarded,
    }
}

/// `subject` with `prefix` unless it already starts with one of `known`
/// (lower case), ignoring case.
fn prefixed(subject: &str, prefix: &str, known: &[&str]) -> String {
    let subject = subject.trim();
    let lower = subject.to_lowercase();
    if known.iter().any(|k| lower.starts_with(k)) {
        subject.to_owned()
    } else {
        format!("{prefix}{subject}")
    }
}

/// The attribution line, then each line up to the signature as `> line`
/// (`>` alone for blank lines, `>>` for lines already quoted).
fn quoted(quote: &Quote<'_>) -> String {
    let mut out = String::from(quote.attribution.trim_end());
    for line in quote.text.trim_end().lines() {
        if is_signature_line(line) {
            break;
        }
        out.push('\n');
        out.push('>');
        if !line.is_empty() && !line.starts_with('>') {
            out.push(' ');
        }
        out.push_str(line);
    }
    out
}

fn join(text: &str, tail: &str) -> String {
    format!("{}\n\n{}", text.trim_end(), tail)
}
```

```rust
//! `mailto:` links (RFC 6068) into a compose draft.

use crate::address::Address;
use crate::thread::normalize_id;

/// What a `mailto:` link fills in. Other headers in the link are ignored.
#[derive(Debug, Clone, PartialEq, Eq, Default)]
pub struct MailtoDraft {
    pub to: Vec<Address>,
    pub cc: Vec<Address>,
    pub bcc: Vec<Address>,
    pub subject: String,
    /// `\n` line ends.
    pub body: String,
    /// Without angle brackets.
    pub in_reply_to: Option<String>,
}

/// Parses a `mailto:` URI; `None` when it isn't one.
pub fn parse_mailto(uri: &str) -> Option<MailtoDraft> {
    let uri = uri.trim();
    let scheme = uri.get(..7)?;
    if !scheme.eq_ignore_ascii_case("mailto:") {
        return None;
    }
    let rest = &uri[7..];
    let (path, query) = rest.split_once('?').unwrap_or((rest, ""));
    let mut draft = MailtoDraft {
        to: addresses(&decode(path)),
        ..MailtoDraft::default()
    };
    for pair in query.split('&').filter(|p| !p.is_empty()) {
        let (name, value) = pair.split_once('=').unwrap_or((pair, ""));
        let value = decode(value);
        match decode(name).to_ascii_lowercase().as_str() {
            "to" => draft.to.extend(addresses(&value)),
            "cc" => draft.cc.extend(addresses(&value)),
            "bcc" => draft.bcc.extend(addresses(&value)),
            "subject" => draft.subject = value,
            "body" => draft.body = value.replace("\r\n", "\n"),
            "in-reply-to" => draft.in_reply_to = normalize_id(&value),
            _ => {}
        }
    }
    Some(draft)
}

/// Comma-separated addresses; entries without `@` are skipped.
fn addresses(list: &str) -> Vec<Address> {
    list.split(',').filter_map(Address::parse).collect()
}

/// Percent-decoding as RFC 3986 (`+` stays `+`), lossy UTF-8. A `%` not
/// followed by two hex digits is kept as is.
fn decode(text: &str) -> String {
    let bytes = text.as_bytes();
    let mut out = Vec::with_capacity(bytes.len());
    let mut i = 0;
    while i < bytes.len() {
        let hex = bytes.get(i + 1..i + 3).and_then(|h| {
            let h = std::str::from_utf8(h).ok()?;
            u8::from_str_radix(h, 16).ok()
        });
        match (bytes[i], hex) {
            (b'%', Some(byte)) => {
                out.push(byte);
                i += 3;
            }
            (byte, _) => {
                out.push(byte);
                i += 1;
            }
        }
    }
    String::from_utf8_lossy(&out).into_owned()
}
```
