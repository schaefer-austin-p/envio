# Envio Plan 5: envio-sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/envio-sync`: keep each account's folders and the last 30 days of mail in the cache (CONDSTORE when the server has it, a full flag check when not), replay the user's journalled actions after the Undo window, send the Outbox over SMTP and file sent mail in Sent, and never lose or resend unsent mail on the way. Add what that needs to envio-net (IDLE and unsolicited changes, the window search, delete for good, an SMTP send that knows whether a cut may have delivered the message) and to envio-store (message size, lookups, the Outbox's SMTP envelope).

**Architecture:** Pure planners in `plan/` take server state and cache state and return steps: which folders to add or drop, which UIDs to fetch in which batches, which flags changed, what a journal action becomes on the server, what an SMTP result means for an Outbox item. The `driver/` runs those steps against a `MailServer` / `MailSender` (traits over envio-net's `ImapSession` and `SmtpSession`) and a `Local` view of the store, one database transaction (`Db::step`) per step, so a cut connection loses nothing and the next run resumes from the cache. Sync spawns nothing and never sleeps: core's worker (Plan 6) passes the time in and asks the in-memory `Schedule` when work is next due. Tests run the driver against an in-memory IMAP/SMTP fake, with property tests over random fault sequences, and the whole stack against Stalwart in `envio-e2e`.

**Tech Stack:** Rust 1.94 (edition 2024), tokio 1.54 (tests only; envio-sync has no runtime of its own), thiserror 2, tempfile 3 (tests); envio-net, envio-store and envio-mime from Plans 2 to 4; Stalwart v1.0.3 in Docker. No new third-party crates.

**Spec:** `docs/superpowers/specs/2026-11-07-envio-design.md`, sections "Architecture", "Sync", "Unsent work", "Error handling" and "Testing and CI". Issues: #34 (net gaps found in Plan 4: unsolicited changes and IDLE, MOVE fallback retries, SMTP cut after DATA), #22 (store queries sync needs; account removal), #12 (migration 0002 needs a row-preserving test), #37 (credentials at trace level in async-imap).

## Global Constraints

- `rust-version = "1.94"`, `edition = "2024"`, licence `GPL-3.0-only`, all from `[workspace.package]`; the crate has `[lints] workspace = true`.
- The core is Qt-free; `unsafe_code = "forbid"` in the root workspace.
- Dependencies point one way: core → sync → net, store, mime. net, store and mime never depend on each other; envio-sync is the only crate that sees both net and store types, and `convert.rs` is where they meet.
- Logic kept out of I/O code: pure planners, thin drivers. Files around 300 lines; one concept per module.
- **Never lose unsent writing; never resend mail on its own.** An Outbox item leaves the Outbox only once the server accepted it and it is in Sent (or the server files it itself). After a cut that may have delivered it ("May have been sent"), sync searches Sent by Message-ID and otherwise waits for the user (Send again / Move to Sent).
- Retention: 30 days, by arrival date. Sync is resumable steps, one DB transaction per step.
- User actions apply locally at once, wait out a 5 s Undo window, then go to the server. A failed action is dropped quietly when the end state is what the user wanted, otherwise reverted locally with a notice.
- Error kinds: Temporary (backoff 1 s to 5 min with jitter), Sign-in (pause the account), Certificate (stop), Refused (an error on the item), Local.
- Passwords stay in `secrecy` types and out of logs and error text. Sync adds no logging that formats credentials, and never enables trace logging for `async_imap` or `imap_proto` (#37: async-imap logs LOGIN at trace).
- No user-facing text here: errors are kinds that core words with gettext.
- Single-crate integration tests go in `crates/<crate>/tests/`; anything that needs two crates goes in `envio-e2e`.
- Clippy: `clippy::all` plus `cognitive_complexity` (threshold 15), `too-many-arguments-threshold = 4` (at most 4 parameters, `self` included); CI runs clippy with `-D warnings`.
- Migrations are numbered and never edited after merge.
- `cargo make ci` (fmt, clippy, tests, audit) must pass.

## Decisions (where the brief and spec leave a gap)

1. **The driver is generic over two traits**, `MailServer` (the IMAP operations sync uses) and `MailSender` (one SMTP send), implemented by envio-net's `ImapSession` and `SmtpSession` in `server.rs` and by `tests/support/fake.rs` in tests. Functions take `&mut impl MailServer` (async fn in traits, no boxing). IDLE stays off the trait: core waits on `ImapSession::idle` between runs (Plan 6).
2. **`Local<'a>` is the store as sync sees it**: `db`, `bodies`, `journal`, `outbox` and the `Schedule`, borrowed from core's worker for one run. Every driver function takes `(server, local, …, now_ms)`, within the four-parameter limit.
3. **Time is passed in, never read.** `now_ms` is a parameter everywhere; `Schedule` keeps the retry waits in memory (`Key::Action(seq)` / `Key::Outbox(id)`), `backoff_ms(failures, seed)` is 1 s doubling to 5 min minus up to a quarter of jitter, and `next_due()` tells core when to call again. After a restart everything is simply due. `UNDO_MS = 5_000`, `POLL_MS = 5 min` (servers without IDLE).
4. **The window is `UID SEARCH SINCE <day>`** (`search_since`, added to envio-net) at `now - 30 days`, so arrival date decides, as the spec says. New UIDs are fetched newest first in batches of 50 (`BATCH`), one transaction each. A first sync (or the sync after a UIDVALIDITY change) first stores `begin`, a `SyncState` with the new UIDVALIDITY and `uidnext = 0`, the marker of an unfinished sync; the real `finish` state is stored last. A cut sync therefore resumes against the right UIDVALIDITY and refetches nothing it already has.
5. **Flags:** with CONDSTORE and a cached `highestmodseq`, `FETCH (FLAGS) CHANGEDSINCE`; when HIGHESTMODSEQ is unchanged, nothing is fetched at all. Without CONDSTORE every cached UID in the window is checked. `Pending` lays the journal's not-yet-replayed actions over the server's flags, and keeps messages with a pending Move or Delete out of the cache, so a sync never undoes what the user just did.
6. **UIDVALIDITY change:** the folder's rows and its bodies are dropped (`reset`) and the folder syncs as new. Journal actions name their message by `(uidvalidity, uid, message_id)`; an action from an older UIDVALIDITY is found again by Message-ID when replayed, and dropped quietly when it can't be found (`Find::Lost`).
7. **Replay:** an action becomes `ServerOp::SetFlags`, `Move { to }` or `Expunge` (Delete outside Trash is a move to Trash; in Trash, or without one, it deletes for good with the new `ImapSession::delete`). A Move without the MOVE extension (#34) first looks for the message in the target by Message-ID (`MoveRoute::CheckTarget`), so a retry after a cut between COPY and the delete doesn't copy twice. Outcomes: done; `Refused` → reverted locally and reported in `Replayed::reverted` (a refused SELECT means the folder is gone: done); temporary → backoff, the run stops; sign-in or certificate → the run stops with that kind and the action stays.
8. **SMTP knows whether a cut may have delivered the message** (#34). `SmtpSession::send` now does MAIL, RCPT, DATA and the upload itself (lettre's command types, our writes) and returns `SendError { error, unconfirmed }`: `unconfirmed` is true once the final `.` went out and no reply came back. The Outbox planner maps that to `MayHaveBeenSent`, never to a retry. A cut mid-upload may also report unconfirmed (writes can sit in socket buffers): conservative, it asks rather than risks a second copy.
9. **Filing in Sent**: `file_sent` APPENDs accepted items to Sent with `\Seen`, after searching Sent by Message-ID, so a retried APPEND never files twice; Gmail (`files_itself(smtp_host)`) and accounts with no Sent folder skip the APPEND. A "May have been sent" item found in Sent leaves the Outbox; one not found is returned in `Filed::ask` for the user.
10. **The SMTP envelope lives in the Outbox** (`OutboxMeta.from`, `recipients`): Bcc is not in the `.eml`, so the envelope can't be read back from it. Composer (Plan 7) fills it when it queues.
11. **Account removal (#22)** goes through sync: `unsent(local, drafts, account)` counts Outbox items not yet accepted, drafts and pending actions, so core can warn before removing; `remove_account` then drops the account's journal actions, Outbox items, drafts, cache rows, bodies and schedule entries. Nothing is orphaned.
12. **Store additions (#22) are only what sync reads**: `messages.size` (migration 0002, `RFC822.SIZE`, so a body download's time limit grows with the message), `message_at(folder, uid)`, `flags_by_uid(folder)` and `folder_by_path(account, path)`. Unified inbox, body full-text search and autocomplete queries are left to Plan 7, which uses them. Migration 0002 gets a test that a database with 0001 and rows in it keeps its rows (#12).
13. **IDLE and unsolicited changes (#34)** are in envio-net: `ImapSession::idle(self, wait, stop)` returns `Woke::Changed`, `Quiet` (after `wait`, at most `IDLE_MAX` = 29 min) or `Stopped`; `take_changes()` drains unsolicited replies that came along with other commands (`select` drains them, since a fresh SELECT reports the state anyway). STATUS and RECENT don't count as changes (Stalwart sends STATUS during IDLE). Driving IDLE is core's job (Plan 6).
14. **No new logging** (#37). Sync logs nothing in this plan; error `Display` text is net's and store's, which never carries passwords.

## How tests run

- **Planners:** table tests in each `plan/*.rs` (`cargo test -p envio-sync --lib`).
- **Driver:** `crates/envio-sync/tests/` against `tests/support/fake.rs`, an in-memory IMAP server (folders, UIDs that only grow, UIDVALIDITY, flags with MODSEQ, MOVE on or off, injected failures with `fail_on` / `fail_after`) and SMTP sender, over a store in a temporary directory (`tests/support/local.rs`).
- **Properties:** `tests/properties.rs` runs 64 seeds × 40 random steps (queue, send, file, sync, flag, fail, reconnect) with a small xorshift generator (no new crate). Invariants: a queued item stays in the Outbox until it is in Sent or accepted, an accepted or unconfirmed message is never sent again, and flags converge on the server's, with and without CONDSTORE, once failures stop.
- **Against Stalwart:** envio-net's new IMAP operations in `crates/envio-net/tests/changes.rs` and the whole stack in `crates/envio-e2e/tests/sync_stalwart.rs`. Both skip without Stalwart unless `ENVIO_REQUIRE_STALWART=1`. Locally: `cargo make net-it` and `cargo make e2e-it` (each starts a fresh container with `up.sh` and removes it). `up.sh` creates one user per e2e test (carol, dave, erin, frank; password `<name>-secret-1`) so they run in parallel without seeing each other's mail. A second e2e run needs a fresh container (`cargo make e2e-it` does that). In CI the Stalwart step also runs when the picked crates include envio-sync, so the cross-crate step sees it.

```rust
        return;

    session.delete(&uids).await.unwrap();
    session.logout().await.unwrap();
    other.logout().await.unwrap();
}
```

```rust
/// RFC 2177: servers may drop an IDLE after 30 minutes, so it is renewed
/// before that.
pub const IDLE_MAX: Duration = Duration::from_secs(29 * 60);

/// Why `idle` returned.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Woke {
    /// The selected folder changed (new mail, expunge, flags).
    Changed,
    /// `wait` passed with no change.
    Quiet,
    /// The caller's `stop` future finished (the user did something).
    Stopped,
}

impl ImapSession {
    /// Whether the server reported a change in the selected folder since
    /// the last call (EXISTS, EXPUNGE, FETCH sent along with other
    /// replies). Drains what was reported; async-imap keeps at most 100
    /// and drops the rest, which still leaves this true.
    pub fn take_changes(&mut self) -> bool {
        let mut changed = false;
        while let Ok(response) = self.session.unsolicited_responses.try_recv() {
            // STATUS is about a folder's counts, sent by some servers
            // (Stalwart) on their own; RECENT comes with EXISTS.
            changed |= !matches!(
                response,
                UnsolicitedResponse::Status { .. } | UnsolicitedResponse::Recent(_)
            );
        }
        changed
    }

    /// Waits in IDLE until the selected folder changes, `wait` passes
    /// (capped at [`IDLE_MAX`]) or `stop` finishes. Consumes the session
    /// and gives it back, since nothing else can run during IDLE. Check
    /// `caps().idle` first; without IDLE, poll with `noop`.
    pub async fn idle(
        self,
        wait: Duration,
        stop: impl Future<Output = ()>,
    ) -> Result<(Self, Woke)> {
        let Self {
            session,
            caps,
            exists,
        } = self;
        let mut handle = session.idle();
        connect::within(async { handle.init().await.map_err(map_error) }).await?;
        let deadline = Instant::now() + wait.min(IDLE_MAX);
        let mut stop = pin!(stop);
        let woke = loop {
            let left = deadline.saturating_duration_since(Instant::now());
            let (waiting, interrupt) = handle.wait_with_timeout(left);
            let heard = match select(pin!(waiting), stop.as_mut()).await {
                Either::Left((heard, _)) => heard.map_err(map_error)?,
                Either::Right(((), _)) => break Woke::Stopped,
            };
            drop(interrupt);
            match heard {
                IdleResponse::NewData(data) if is_status(data.parsed()) => {}
                IdleResponse::NewData(_) => break Woke::Changed,
                IdleResponse::Timeout | IdleResponse::ManualInterrupt => break Woke::Quiet,
            }
        };
        let session = connect::within(async { handle.done().await.map_err(map_error) }).await?;
        let mut this = Self {
            session,
            caps,
            exists,
        };
        // DONE's reply may carry what changed while it was sent.
        let woke = if woke != Woke::Changed && this.take_changes() {
            Woke::Changed
        } else {
            woke
        };
        Ok((this, woke))
    }
}

fn is_status(response: &Response<'_>) -> bool {
    matches!(response, Response::MailboxData(MailboxDatum::Status { .. }))
}
```

```rust
//! One SMTP transaction (MAIL, RCPT, DATA, the message), and whether a
//! failure may still have delivered the message. lettre's own `send` does
//! the same steps but can't tell a cut before the end of the message
//! (nothing sent: safe to retry) from one after it (the server may have
//! taken it: retrying could send it twice).

use std::cell::Cell;

use lettre::address::Envelope;
use lettre::transport::smtp::commands::{Data, Mail, Rcpt};
use lettre::transport::smtp::extension::{Extension, MailBodyParameter, MailParameter};

use super::{SmtpSession, envelope, map_error};
use crate::connect;
use crate::error::NetError;

/// How much of the message goes out per write.
const CHUNK: usize = 64 * 1024;

/// A failed send. `unconfirmed` is true when the whole message went out
/// but no reply to it came back (cut or timeout after the final dot): the
/// server may have delivered it, so the Outbox must not resend it on its
/// own. A reply with a code (4xx, 5xx) is always confirmed: not sent.
#[derive(Debug)]
pub struct SendError {
    pub error: NetError,
    pub unconfirmed: bool,
}

impl SendError {
    fn confirmed(error: NetError) -> Self {
        Self {
            error,
            unconfirmed: false,
        }
    }
}

impl From<SendError> for NetError {
    fn from(error: SendError) -> Self {
        error.error
    }
}

impl std::fmt::Display for SendError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        if self.unconfirmed {
            write!(f, "{} (the message may have been sent)", self.error)
        } else {
            self.error.fmt(f)
        }
    }
}

impl std::error::Error for SendError {}

impl SmtpSession {
    /// Sends one message. `eml` is the finished RFC 5322 message (from
    /// envio-mime); `from` and `to` are the envelope, which may differ
    /// from its headers (Bcc). Any error leaves the session unusable.
    pub async fn send(&mut self, from: &str, to: &[String], eml: &[u8]) -> Result<(), SendError> {
        let envelope = envelope(from, to).map_err(SendError::confirmed)?;
        let non_ascii = !from.is_ascii() || to.iter().any(|t| !t.is_ascii());
        let options = self.mail_options(non_ascii, eml)?;
        let all_out = Cell::new(false);
        // The upload alone can outlast a command, so the limit grows with
        // the message.
        let outcome = connect::within_for(connect::transfer_timeout(eml.len()), async {
            let chunks = Chunks {
                rest: eml,
                all_out: &all_out,
            };
            Ok(self.transaction(&envelope, options, chunks).await)
        })
        .await;
        match outcome {
            Ok(Ok(())) => Ok(()),
            Ok(Err(error)) => Err(SendError {
                unconfirmed: all_out.get() && error.status().is_none(),
                error: map_error(error, false),
            }),
            Err(timeout) => Err(SendError {
                error: timeout,
                unconfirmed: all_out.get(),
            }),
        }
    }

    /// SMTPUTF8 and 8BITMIME, as lettre's `send` sets them.
    fn mail_options(&self, non_ascii: bool, eml: &[u8]) -> Result<Vec<MailParameter>, SendError> {
        let info = self.conn.server_info();
        let mut options = Vec::new();
        if non_ascii {
            if !info.supports_feature(Extension::SmtpUtfEight) {
                return Err(SendError::confirmed(NetError::Refused(
                    "the server can't take non-ASCII addresses (no SMTPUTF8)".into(),
                )));
            }
            options.push(MailParameter::SmtpUtfEight);
        }
        if !eml.is_ascii() {
            if !info.supports_feature(Extension::EightBitMime) {
                return Err(SendError::confirmed(NetError::Refused(
                    "the server can't take 8-bit mail (no 8BITMIME)".into(),
                )));
            }
            options.push(MailParameter::Body(MailBodyParameter::EightBitMime));
        }
        Ok(options)
    }

    async fn transaction(
        &mut self,
        envelope: &Envelope,
        options: Vec<MailParameter>,
        chunks: Chunks<'_>,
    ) -> Result<(), lettre::transport::smtp::Error> {
        self.conn
            .command(Mail::new(envelope.from().cloned(), options))
            .await?;
        for to in envelope.to() {
            self.conn.command(Rcpt::new(to.clone(), vec![])).await?;
        }
        self.conn.command(Data).await?;
        self.conn.message_iter(chunks).await?;
        Ok(())
    }
}

/// The message in [`CHUNK`]s. lettre asks for the next chunk only after
/// writing the previous one, so asking past the end means every byte was
/// written: from then on, only the final dot and the reply are missing.
struct Chunks<'a> {
    rest: &'a [u8],
    all_out: &'a Cell<bool>,
}

impl<'a> Iterator for Chunks<'a> {
    type Item = &'a [u8];

    fn next(&mut self) -> Option<&'a [u8]> {
        if self.rest.is_empty() {
            self.all_out.set(true);
            return None;
        }
        let (chunk, rest) = self.rest.split_at(self.rest.len().min(CHUNK));
        self.rest = rest;
        Some(chunk)
    }
}
```

```rust
//! The lookups sync's planner and driver need (issue #22): one message by
//! UID, a folder's flags in one read, and a folder by its server path.

use rusqlite::{OptionalExtension, params};

use crate::db::Db;
use crate::error::Result;
use crate::folders::{self, Folder, FolderId};
use crate::messages::{self, Flags, Message};

impl Db {
    /// The cached message with this UID, if any.
    pub fn message_at(&self, folder: FolderId, uid: u32) -> Result<Option<Message>> {
        let message = self
            .conn()
            .query_row(
                &format!(
                    "SELECT {} FROM messages m WHERE m.folder_id = ?1 AND m.uid = ?2",
                    messages::COLUMNS
                ),
                params![folder.0, uid],
                messages::from_row,
            )
            .optional()?;
        Ok(message)
    }

    /// Every cached UID of a folder with its flags, ascending by UID: what
    /// the planner compares with the server's flags.
    pub fn flags_by_uid(&self, folder: FolderId) -> Result<Vec<(u32, Flags)>> {
        let mut stmt = self
            .conn()
            .prepare("SELECT uid, flags FROM messages WHERE folder_id = ?1 ORDER BY uid")?;
        let flags = stmt
            .query_map([folder.0], |row| {
                Ok((row.get(0)?, Flags::from_bits(row.get(1)?)))
            })?
            .collect::<rusqlite::Result<_>>()?;
        Ok(flags)
    }

    /// An account's folder by its path on the server, if it is cached.
    pub fn folder_by_path(&self, account: &str, path: &str) -> Result<Option<Folder>> {
        let folder = self
            .conn()
            .query_row(
                &format!(
                    "SELECT {} FROM folders WHERE account = ?1 AND path = ?2",
                    folders::COLUMNS
                ),
                params![account, path],
                folders::from_row,
            )
            .optional()?;
        Ok(folder)
    }
}
```

```rust
/// The store's flag bits from the server's flags. Keywords are not
/// cached.
pub fn store_flags(flags: &MessageFlags) -> Flags {
    [
        (flags.seen, Flags::SEEN),
        (flags.answered, Flags::ANSWERED),
        (flags.flagged, Flags::FLAGGED),
        (flags.deleted, Flags::DELETED),
        (flags.draft, Flags::DRAFT),
    ]
    .into_iter()
    .filter(|(set, _)| *set)
    .fold(Flags::empty(), |all, (_, flag)| all.with(flag))
}

/// The IMAP flags named by `flags`, for STORE.
pub fn net_flags(flags: Flags) -> Vec<Flag> {
    [
        (Flags::SEEN, Flag::Seen),
        (Flags::ANSWERED, Flag::Answered),
        (Flags::FLAGGED, Flag::Flagged),
        (Flags::DELETED, Flag::Deleted),
        (Flags::DRAFT, Flag::Draft),
    ]
    .into_iter()
    .filter(|(bit, _)| flags.contains(*bit))
    .map(|(_, flag)| flag)
    .collect()
}

pub fn folder_role(role: Option<Role>) -> FolderRole {
    match role {
        Some(Role::Inbox) => FolderRole::Inbox,
        Some(Role::Sent) => FolderRole::Sent,
        Some(Role::Drafts) => FolderRole::Drafts,
        Some(Role::Trash) => FolderRole::Trash,
        Some(Role::Junk) => FolderRole::Junk,
        Some(Role::Archive) => FolderRole::Archive,
        Some(Role::All | Role::Flagged) | None => FolderRole::Other,

/// The row for a message from its summary. A header that doesn't parse
/// still gives a row (empty subject and sender), so sync goes on; the
/// date falls back to the server's arrival time.
pub fn new_message(summary: &Summary) -> NewMessage {
    let parsed = envio_mime::envelope(&summary.header).unwrap_or_default();
    NewMessage {
        uid: summary.uid,
        size: summary.size,
        envelope: store_envelope(&parsed, summary.internal_date.unwrap_or(0)),
        flags: store_flags(&summary.flags),
        preview: parsed.preview,
    }
}

/// `message`'s row again with what the whole message adds: the preview.
pub fn with_body(message: &Message, eml: &[u8]) -> NewMessage {
    let preview = envio_mime::envelope(eml)
        .map(|parsed| parsed.preview)
        .unwrap_or_default();
    NewMessage {
        uid: message.uid,
        size: message.size,
        envelope: message.envelope.clone(),
        flags: message.flags,
        preview,
    }
}

/// The Message-ID as the store and the journal keep it: in angle brackets.
pub fn bracketed(message_id: &str) -> String {
    format!("<{message_id}>")
}

fn store_envelope(parsed: &envio_mime::Envelope, arrived: i64) -> Envelope {
    let shown = |list: &[envio_mime::Address]| {
        list.iter()
            .map(envio_mime::Address::display)
            .collect::<Vec<_>>()
            .join(", ")
    };
    Envelope {
        message_id: parsed.message_id.as_deref().map(bracketed),
        subject: parsed.subject.clone(),
        from: shown(&parsed.from),
        to: shown(&parsed.to),
        date: parsed.date.unwrap_or(arrived),
        in_reply_to: parsed.in_reply_to.as_deref().map(bracketed),
        references: parsed.references.iter().map(|id| bracketed(id)).collect(),
    }
}
```

```rust
//! Sync's error: a network or a store failure, sorted into the spec's
//! failure kinds so core can pick the fixed response (retry, pause the
//! account, stop, mark the item). The text is for logs only and never
//! holds a password: sync formats no credentials anywhere.

use envio_net::NetError;
use envio_store::StoreError;

#[derive(Debug, thiserror::Error)]
pub enum SyncError {
    #[error(transparent)]
    Net(#[from] NetError),
    #[error(transparent)]
    Store(#[from] StoreError),
}

/// The spec's failure kinds ("Error handling"), as far as sync can tell.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ErrorKind {
    /// Network, timeout, server busy: retry with backoff.
    Temporary,
    /// Wrong or revoked password: pause the account, no retry loop.
    SignIn,
    /// Certificate not trusted or changed: stop and ask.
    Certificate,
    /// The server refused this item for good.
    Refused,
    /// The server spoke nonsense; retried like a temporary failure, but
    /// logged.
    Protocol,
    /// Disk or database trouble.
    Local,
}

impl SyncError {
    pub fn kind(&self) -> ErrorKind {
        match self {
            Self::Net(error) => net_kind(error),
            Self::Store(_) => ErrorKind::Local,
        }
    }
}

pub(crate) fn net_kind(error: &NetError) -> ErrorKind {
    match error {
        NetError::Io(_) | NetError::Timeout | NetError::Busy(_) => ErrorKind::Temporary,
        NetError::SignIn(_) => ErrorKind::SignIn,
        NetError::Untrusted { .. }
        | NetError::PinChanged { .. }
        | NetError::Tls(_)
        | NetError::NoStartTls => ErrorKind::Certificate,
        NetError::Refused(_) => ErrorKind::Refused,
        NetError::Protocol(_) => ErrorKind::Protocol,
    }
}
```

```rust
//! When work is due: the Undo window, retry backoff with jitter, and the
//! poll interval for servers without IDLE. Pure and in memory only; after
//! a restart every pending item is simply due again.

use std::collections::BTreeMap;

/// How long a user action waits before it goes to the server.
pub const UNDO_MS: i64 = 5_000;
/// How often a folder is checked on a server without IDLE.
pub const POLL_MS: i64 = 5 * 60_000;
/// The first retry delay after a temporary failure.
pub const BACKOFF_FIRST_MS: i64 = 1_000;
/// The longest retry delay.
pub const BACKOFF_MAX_MS: i64 = 5 * 60_000;

/// The delay before retry number `failures` (1 for the first failure):
/// 1 s doubling up to 5 min, minus up to a quarter for jitter so that
/// accounts that failed together don't retry together.
pub fn backoff_ms(failures: u32, seed: u64) -> i64 {
    let doublings = failures.saturating_sub(1).min(20);
    let base = (BACKOFF_FIRST_MS << doublings).min(BACKOFF_MAX_MS);
    let quarter = u64::try_from(base / 4).unwrap_or(0);
    let jitter = splitmix(seed) % (quarter + 1);
    base - i64::try_from(jitter).unwrap_or(0)
}

/// What a retry is for: a journal action by its sequence number, or an
/// Outbox item by its id.
#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord)]
pub enum Key {
    Action(u64),
    Outbox(String),
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct Wait {
    failures: u32,
    due_ms: i64,
}

/// Retry times for items that failed temporarily. An item with no entry is
/// due now.
#[derive(Debug, Default)]
pub struct Schedule {
    waits: BTreeMap<Key, Wait>,
}

impl Schedule {
    pub fn is_due(&self, key: &Key, now_ms: i64) -> bool {
        self.waits.get(key).is_none_or(|wait| wait.due_ms <= now_ms)
    }

    /// Records a temporary failure and returns when to try again.
    pub fn failed(&mut self, key: Key, now_ms: i64) -> i64 {
        let failures = self.waits.get(&key).map_or(0, |wait| wait.failures) + 1;
        let seed = seed_of(&key) ^ u64::from(failures) ^ now_ms.unsigned_abs();
        let due_ms = now_ms + backoff_ms(failures, seed);
        self.waits.insert(key, Wait { failures, due_ms });
        due_ms
    }

    /// Forgets an item that went through or is gone.
    pub fn succeeded(&mut self, key: &Key) {
        self.waits.remove(key);
    }

    pub fn failures(&self, key: &Key) -> u32 {
        self.waits.get(key).map_or(0, |wait| wait.failures)
    }

    /// The earliest retry time, if anything is waiting.
    pub fn next_due(&self) -> Option<i64> {
        self.waits.values().map(|wait| wait.due_ms).min()
    }
}

fn seed_of(key: &Key) -> u64 {
    match key {
        Key::Action(seq) => *seq,
        // FNV-1a: stable across runs, unlike the std hasher.
        Key::Outbox(id) => id.bytes().fold(0xcbf2_9ce4_8422_2325, |hash, byte| {
            (hash ^ u64::from(byte)).wrapping_mul(0x0100_0000_01b3)
        }),
    }
}

fn splitmix(seed: u64) -> u64 {
    let mut z = seed.wrapping_add(0x9e37_79b9_7f4a_7c15);
    z = (z ^ (z >> 30)).wrapping_mul(0xbf58_476d_1ce4_e5b9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94d0_49bb_1331_11eb);
    z ^ (z >> 31)
}
```

```rust
//! Which folders the cache should hold: the server's selectable folders,
//! with their roles. Pure.

use envio_net::imap::Folder as ServerFolder;
use envio_store::{Folder, FolderId, FolderRole};

use crate::convert::folder_role;

#[derive(Debug, Default, PartialEq, Eq)]
pub struct FolderChanges {
    /// New folders, and known ones whose role changed.
    pub upsert: Vec<(String, FolderRole)>,
    /// Cached folders the server no longer has.
    pub remove: Vec<FolderId>,
}

pub fn plan_folders(server: &[ServerFolder], cached: &[Folder]) -> FolderChanges {
    let wanted: Vec<(&str, FolderRole)> = server
        .iter()
        .filter(|folder| folder.selectable)
        .map(|folder| (folder.path.as_str(), folder_role(folder.role)))
        .collect();
    let upsert = wanted
        .iter()
        .filter(|(path, role)| {
            !cached
                .iter()
                .any(|folder| folder.path == *path && folder.role == *role)
        })
        .map(|(path, role)| ((*path).to_owned(), *role))
        .collect();
    let remove = cached
        .iter()
        .filter(|folder| !wanted.iter().any(|(path, _)| folder.path == *path))
        .map(|folder| folder.id)
        .collect();
    FolderChanges { upsert, remove }
}

/// The order folders are synced in: what the user looks at first.
pub fn sync_order(folders: &[Folder]) -> Vec<FolderId> {
    let rank = |role: FolderRole| match role {
        FolderRole::Inbox => 0,
        FolderRole::Sent => 1,
        FolderRole::Drafts => 2,
        FolderRole::Archive | FolderRole::Other => 3,
        FolderRole::Junk => 4,
        FolderRole::Trash => 5,
    };
    let mut ordered: Vec<&Folder> = folders.iter().collect();
    ordered.sort_by(|a, b| rank(a.role).cmp(&rank(b.role)).then(a.path.cmp(&b.path)));
    ordered.into_iter().map(|folder| folder.id).collect()
}

/// The account's folder with `role`, e.g. Trash for Delete or Sent for the
/// Outbox.
pub fn with_role(folders: &[Folder], role: FolderRole) -> Option<&Folder> {
    folders.iter().find(|folder| folder.role == role)
}
```

```rust
//! What the journal's pending actions mean for one folder while it syncs:
//! a pending flag change wins over the server's flags, and a message with
//! a pending Move or Delete stays out of the cache, so sync never undoes
//! what the user just did. Pure.

use std::collections::{BTreeMap, BTreeSet};

use envio_store::{Action, ActionKind, Flags};

#[derive(Debug, Default)]
pub struct Pending {
    /// (add, remove) per UID, oldest first.
    flags: BTreeMap<u32, Vec<(Flags, Flags)>>,
    hidden: BTreeSet<u32>,
}

impl Pending {
    /// The pending actions on messages in `path` as of `uidvalidity`.
    /// Actions from before a UIDVALIDITY change name other messages; they
    /// are found by Message-ID when replayed.
    pub fn of<'a>(
        actions: impl IntoIterator<Item = &'a Action>,
        account: &str,
        path: &str,
        uidvalidity: u32,
    ) -> Self {
        let mut pending = Self::default();
        let here = actions.into_iter().filter(|action| {
            action.target.account == account
                && action.target.folder == path
                && action.target.uidvalidity == uidvalidity
        });
        for action in here {
            let uid = action.target.uid;
            match &action.kind {
                ActionKind::SetFlags { add, remove } => {
                    pending.flags.entry(uid).or_default().push((*add, *remove));
                }
                ActionKind::Move { .. } | ActionKind::Delete => {
                    pending.hidden.insert(uid);
                }
            }
        }
        pending
    }

    /// The flags to cache for `uid`: the server's, with pending changes on
    /// top in the order the user made them.
    pub fn flags(&self, uid: u32, server: Flags) -> Flags {
        self.flags.get(&uid).map_or(server, |changes| {
            changes.iter().fold(server, |flags, (add, remove)| {
                flags.with(*add).without(*remove)
            })
        })
    }

    /// The message is on its way out of this folder.
    pub fn is_hidden(&self, uid: u32) -> bool {
        self.hidden.contains(&uid)
    }
}
```

```rust
//! One folder's sync, planned from what the server and the cache hold.
//! The cache keeps the last 30 days (by arrival date). New messages are
//! fetched newest first in batches, one transaction each, and the folder's
//! final state is stored last, so a cut connection resumes with nothing
//! lost and nothing fetched twice. Pure.

use std::collections::BTreeSet;

use envio_net::imap::{FlagUpdate, FolderState, Summary};
use envio_store::{Flags, NewMessage, SyncState};

use crate::convert::{new_message, store_flags};
use crate::plan::pending::Pending;

/// How far back the cache reaches.
pub const WINDOW_SECS: i64 = 30 * 86_400;
/// Messages per fetch and per transaction.
pub const BATCH: usize = 50;

/// The `SEARCH SINCE` argument for the window at `now_ms`.
pub fn window_start(now_ms: i64) -> i64 {
    now_ms / 1_000 - WINDOW_SECS
}

/// What sync knows about a folder before planning.
#[derive(Debug, Clone, Copy)]
pub struct FolderView<'a> {
    /// From SELECT.
    pub server: FolderState,
    /// The server's UIDs inside the window, from `search_since`.
    pub window: &'a [u32],
    /// The cache's state for the folder, `None` before the first sync.
    pub cached: Option<SyncState>,
    /// The cache's UIDs for the folder.
    pub cached_uids: &'a [u32],
    pub condstore: bool,
}

/// Which flags to ask the server for.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FlagCheck {
    /// Nothing changed since the last sync (or nothing is cached).
    Skip,
    /// CONDSTORE: only messages changed after this MODSEQ.
    ChangedSince(u64),
    /// Every cached message in the window.
    All,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct FolderPlan {
    /// UIDVALIDITY changed: drop the folder's cache first.
    pub reset: bool,
    /// Stored in the first step of a first sync or after a reset, so a cut
    /// sync resumes against the right UIDVALIDITY. Its `uidnext` is 0:
    /// the sync isn't finished.
    pub begin: Option<SyncState>,
    /// Cached UIDs to drop: gone from the server or out of the window.
    pub remove: Vec<u32>,
    /// Cached UIDs whose flags to check.
    pub check: Vec<u32>,
    pub flags: FlagCheck,
    /// UIDs to fetch, newest first, in batches of at most [`BATCH`].
    pub fetch: Vec<Vec<u32>>,
    /// Stored last.
    pub finish: SyncState,
}

pub fn plan_folder(view: &FolderView<'_>, pending: &Pending) -> FolderPlan {
    let server = view.server;
    let reset = view
        .cached
        .is_some_and(|cached| cached.uidvalidity != server.uid_validity);
    let fresh = reset || view.cached.is_none();
    let cached: BTreeSet<u32> = if reset {
        BTreeSet::new()
    } else {
        view.cached_uids.iter().copied().collect()
    };
    let window: BTreeSet<u32> = view.window.iter().copied().collect();
    let check: Vec<u32> = cached.intersection(&window).copied().collect();
    let new: Vec<u32> = window
        .iter()
        .rev()
        .copied()
        .filter(|uid| !cached.contains(uid) && !pending.is_hidden(*uid))
        .collect();
    FolderPlan {
        reset,
        begin: fresh.then_some(SyncState {
            uidvalidity: server.uid_validity,
            uidnext: 0,
            highestmodseq: None,
        }),
        remove: cached.difference(&window).copied().collect(),
        flags: flag_check(view, check.is_empty()),
        check,
        fetch: new.chunks(BATCH).map(<[u32]>::to_vec).collect(),
        finish: SyncState {
            uidvalidity: server.uid_validity,
            uidnext: server.uid_next,
            highestmodseq: server.highest_modseq.filter(|_| view.condstore),
        },
    }
}

fn flag_check(view: &FolderView<'_>, nothing_cached: bool) -> FlagCheck {
    if nothing_cached {
        return FlagCheck::Skip;
    }
    let last = view.cached.and_then(|cached| cached.highestmodseq);
    match (view.condstore, last, view.server.highest_modseq) {
        (true, Some(last), Some(now)) if last == now => FlagCheck::Skip,
        (true, Some(last), Some(_)) => FlagCheck::ChangedSince(last),
        _ => FlagCheck::All,
    }
}

/// What a flag check changes in the cache.
#[derive(Debug, Default, PartialEq, Eq)]
pub struct FlagChanges {
    pub set: Vec<(u32, Flags)>,
    /// Marked \Deleted on the server: not shown, so not cached.
    pub remove: Vec<u32>,
}

/// `cached` is the folder's (UID, flags) from the cache.
pub fn plan_flags(
    cached: &[(u32, Flags)],
    updates: &[FlagUpdate],
    pending: &Pending,
) -> FlagChanges {
    let mut changes = FlagChanges::default();
    for update in updates {
        let Some((_, now)) = cached.iter().find(|(uid, _)| *uid == update.uid) else {
            continue;
        };
        if update.flags.deleted {
            changes.remove.push(update.uid);
            continue;
        }
        let wanted = pending.flags(update.uid, store_flags(&update.flags));
        if wanted != *now {
            changes.set.push((update.uid, wanted));
        }
    }
    changes
}

/// The rows to cache for a fetched batch: not \Deleted, not on its way
/// out, with pending flag changes on top.
pub fn rows(summaries: &[Summary], pending: &Pending) -> Vec<NewMessage> {
    summaries
        .iter()
        .filter(|summary| !summary.flags.deleted && !pending.is_hidden(summary.uid))
        .map(|summary| {
            let mut row = new_message(summary);
            row.flags = pending.flags(summary.uid, row.flags);
            row
        })
        .collect()
}
```

```rust
//! What the Outbox does next with an item, and what a send result means.
//! An item leaves the Outbox only once the server accepted it (and it is
//! filed in Sent) or once its Message-ID is found in Sent. Envio never
//! resends on its own. Pure.

use envio_net::smtp::SendError;
use envio_store::SendState;

use crate::error::{ErrorKind, net_kind};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ItemStep {
    /// Queued: send over SMTP.
    Send,
    /// Accepted: APPEND to Sent (unless the server files it itself), then
    /// remove.
    File,
    /// May have been sent: look for it in Sent. Found: remove. Not found:
    /// it waits for the user (Send again, or Move to Sent).
    Resolve,
    /// Failed: waits for the user (Edit, Retry).
    Wait,
}

pub fn item_step(state: &SendState) -> ItemStep {
    match state {
        SendState::Queued => ItemStep::Send,
        SendState::Accepted => ItemStep::File,
        // `Outbox::open` turns a left-over Sending into MayHaveBeenSent;
        // seen here it means the same.
        SendState::Sending | SendState::MayHaveBeenSent => ItemStep::Resolve,
        SendState::Failed { .. } => ItemStep::Wait,
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AfterSend {
    pub state: SendState,
    /// Retry after a backoff (temporary failures only).
    pub retry: bool,
    /// Sign-in or certificate trouble: pause the account.
    pub stop: Option<ErrorKind>,
}

pub fn after_send(result: &Result<(), SendError>) -> AfterSend {
    let error = match result {
        Ok(()) => return settled(SendState::Accepted),
        Err(error) if error.unconfirmed => return settled(SendState::MayHaveBeenSent),
        Err(error) => &error.error,
    };
    match net_kind(error) {
        ErrorKind::Refused => settled(SendState::Failed {
            reason: refusal(error),
        }),
        ErrorKind::Temporary | ErrorKind::Protocol | ErrorKind::Local => AfterSend {
            state: SendState::Queued,
            retry: true,
            stop: None,
        },
        kind @ (ErrorKind::SignIn | ErrorKind::Certificate) => AfterSend {
            state: SendState::Queued,
            retry: false,
            stop: Some(kind),
        },
    }
}

fn settled(state: SendState) -> AfterSend {
    AfterSend {
        state,
        retry: false,
        stop: None,
    }
}

/// The server's own words, shown on the item.
fn refusal(error: &envio_net::NetError) -> String {
    match error {
        envio_net::NetError::Refused(text) => text.clone(),
        other => other.to_string(),
    }
}

/// Gmail files sent mail in Sent itself; an APPEND would make a copy.
pub fn files_itself(smtp_host: &str) -> bool {
    let host = smtp_host.trim_end_matches('.').to_ascii_lowercase();
    ["gmail.com", "googlemail.com"]
        .iter()
        .any(|domain| host == *domain || host.ends_with(&format!(".{domain}")))
}
```

```rust
use envio_net::NetError;
use envio_store::{Action, ActionKind, Flags, MessageRef};

use crate::error::{ErrorKind, net_kind};
use crate::schedule::{Key, Schedule, UNDO_MS};

/// The Undo window has passed and no retry wait is running.
pub fn is_due(action: &Action, schedule: &Schedule, now_ms: i64) -> bool {
    now_ms >= action.at_ms + UNDO_MS && schedule.is_due(&Key::Action(action.seq), now_ms)
}

/// How to find the action's message in its folder.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Find {
    /// Same UIDVALIDITY: the UID still names it.
    Uid(u32),
    /// UIDVALIDITY changed: search by Message-ID.
    ByMessageId(String),
    /// UIDVALIDITY changed and the message has no Message-ID: it can't be
    /// found, so the action is dropped.
    Lost,
}

pub fn find(target: &MessageRef, uid_validity: u32) -> Find {
    if target.uidvalidity == uid_validity {
        return Find::Uid(target.uid);
    }
    target
        .message_id
        .clone()
        .map_or(Find::Lost, Find::ByMessageId)
}

/// What to do on the server.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ServerOp {
    SetFlags {
        add: Flags,
        remove: Flags,
    },
    Move {
        to: String,
    },
    /// Delete for good (in Trash, or no Trash folder).
    Expunge,
}

/// Delete moves to Trash, except in Trash itself or when the account has
/// no Trash folder.
pub fn server_op(action: &Action, trash: Option<&str>) -> ServerOp {
    match &action.kind {
        ActionKind::SetFlags { add, remove } => ServerOp::SetFlags {
            add: *add,
            remove: *remove,
        },
        ActionKind::Move { to } => ServerOp::Move { to: to.clone() },
        ActionKind::Delete => match trash {
            Some(trash) if trash != action.target.folder => ServerOp::Move {
                to: trash.to_owned(),
            },
            _ => ServerOp::Expunge,
        },
    }
}

/// How a move runs.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum MoveRoute {
    /// The server has MOVE: one atomic command.
    Direct,
    /// No MOVE: COPY then delete. A retry after a cut between the two would
    /// copy twice, so first look in the target for this Message-ID; if it's
    /// there, only delete the original.
    CheckTarget(String),
    /// No MOVE and no Message-ID to check by.
    Copy,
}

pub fn move_route(has_move: bool, message_id: Option<&str>) -> MoveRoute {
    match (has_move, message_id) {
        (true, _) => MoveRoute::Direct,
        (false, Some(id)) => MoveRoute::CheckTarget(id.to_owned()),
        (false, None) => MoveRoute::Copy,
    }
}

/// What a server result means for the action.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Outcome {
    /// It reached the server: mark it done.
    Done,
    /// Refused for good: mark it done and undo it locally, with a notice.
    Revert,
    /// Temporary: retry after a backoff. The session is gone.
    Retry,
    /// Sign-in or certificate: pause the account. The action stays pending.
    Stop(ErrorKind),
}

pub fn outcome(result: Result<(), &NetError>) -> Outcome {
    let Err(error) = result else {
        return Outcome::Done;
    };
    match net_kind(error) {
        ErrorKind::Refused => Outcome::Revert,
        ErrorKind::Temporary | ErrorKind::Protocol | ErrorKind::Local => Outcome::Retry,
        kind @ (ErrorKind::SignIn | ErrorKind::Certificate) => Outcome::Stop(kind),
    }
}
```

```rust
//! An in-memory IMAP and SMTP server for driver tests: folders with
//! UIDVALIDITY, UIDNEXT and MODSEQ, messages with flags and arrival dates,
//! and failures injected per operation. It follows IMAP's rules where the
//! driver relies on them: UIDs only grow, MOVE is atomic, and without MOVE

impl FakeServer {

    pub fn deliver(&mut self, path: &str, eml: &[u8], date: i64) -> u32 {
        let folder = self.folders.get_mut(path).expect("no such folder");
        let uid = folder.uid_next;
        folder.uid_next += 1;

    }

    pub fn fail_on(&mut self, op: &'static str, error: NetError) {
        self.failures.push((op, error));
    }

    pub fn uids(&self, path: &str) -> Vec<u32> {

        self.folders[path].messages.get(&uid)
    }

    pub fn ids(&self, path: &str) -> Vec<String> {
        self.folders[path]
            .messages
            .values()
            .filter_map(|message| message_id(&message.eml))
            .collect()
    }

    /// The server renumbers the folder (a UIDVALIDITY change).
    pub fn renumber(&mut self, path: &str) {
        let folder = self.folders.get_mut(path).expect("no such folder");
        folder.uid_validity += 1;
        let messages: Vec<FakeMessage> =
            std::mem::take(&mut folder.messages).into_values().collect();
        folder.uid_next = 1;

            folder.uid_next += 1;
        }

        let folder = self.folders.get_mut(path).expect("no such folder");
        folder.modseq += 1;
        let message = folder.messages.get_mut(&uid).expect("no such message");
        message.flags = flags;
        message.modseq = folder.modseq;

fn set(flags: &mut MessageFlags, flag: &Flag, on: bool) {
    match flag {
        Flag::Seen => flags.seen = on,
        Flag::Answered => flags.answered = on,
        Flag::Flagged => flags.flagged = on,
        Flag::Deleted => flags.deleted = on,
        Flag::Draft => flags.draft = on,
        Flag::Keyword(word) => {
            flags.keywords.retain(|kept| kept != word);
            if on {
                flags.keywords.push(word.clone());
            }
        }
    }
}

fn header(eml: &[u8]) -> Vec<u8> {
    let end = eml
        .windows(4)
        .position(|window| window == b"\r\n\r\n")
        .map_or(eml.len(), |at| at + 4);
    eml[..end].to_vec()
}

        if !self.folders.contains_key(path) {
            return Err(NetError::Refused("[TRYCREATE] no such folder".into()));
        }
        let uid = self.deliver(path, eml, NOW_SECS);
        let message = self
            .folders
            .get_mut(path)
            .and_then(|folder| folder.messages.get_mut(&uid))
            .expect("just delivered");
        for flag in flags {
            set(&mut message.flags, flag, true);
        }
        Ok(())
    }
}

/// An SMTP server that answers each send with the next scripted result
/// (default: accepted) and keeps what it accepted.
#[derive(Default)]
pub struct FakeSender {
    pub results: Vec<std::result::Result<(), SendError>>,
    /// (from, recipients, eml) of each send attempt.
    pub attempts: Vec<(String, Vec<String>, Vec<u8>)>,
}

impl MailSender for FakeSender {
    async fn send(
        &mut self,
        from: &str,
        to: &[String],
        eml: &[u8],
    ) -> std::result::Result<(), SendError> {
        self.attempts
            .push((from.to_owned(), to.to_vec(), eml.to_vec()));
        if self.results.is_empty() {
            Ok(())
        } else {
            self.results.remove(0)
        }
    }
}
```

```rust
//! User actions: recorded in the journal and applied to the cache at once;
//! undone within the Undo window by marking them done and putting the
//! cache back.

use envio_store::{
    ActionKind, BodyState, Flags, FolderId, MessageRef, MessageRowId, NewMessage, StoreError,
};

use super::Local;
use crate::convert::row_of;
use crate::error::Result;

/// What `undo` needs to put the cache back.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Undo {
    /// The journal action this undoes.
    pub seq: u64,
    restore: Restore,
}

#[derive(Debug, Clone, PartialEq, Eq)]
enum Restore {
    Flags {
        folder: FolderId,
        uid: u32,
        flags: Flags,
    },
    Row {
        folder: FolderId,
        row: NewMessage,
        downloaded: bool,
    },
}

/// Records a user action on a cached message: journal first (so it can't
/// be lost), then the cache, so the list shows the result at once.
pub fn record(
    local: &mut Local<'_>,
    id: MessageRowId,
    kind: ActionKind,
    now_ms: i64,
) -> Result<Undo> {
    let message = local.db.message(id)?;
    let folder = local.db.folder(message.folder)?;
    // A cached message's folder has begun syncing, so it has a UIDVALIDITY.
    let sync = folder.sync.ok_or(StoreError::NotFound)?;
    let target = MessageRef {
        account: folder.account.clone(),
        folder: folder.path.clone(),
        uidvalidity: sync.uidvalidity,
        uid: message.uid,
        message_id: message.envelope.message_id.clone(),
    };
    let action = local.journal.push(now_ms, target, kind)?;
    let restore = match &action.kind {
        ActionKind::SetFlags { add, remove } => {
            let flags = message.flags.with(*add).without(*remove);
            local
                .db
                .step(|db| db.set_flags(folder.id, message.uid, flags))?;
            Restore::Flags {
                folder: folder.id,
                uid: message.uid,
                flags: message.flags,
            }
        }
        ActionKind::Move { .. } | ActionKind::Delete => {
            local
                .db
                .step(|db| db.delete_messages(folder.id, &[message.uid]))?;
            Restore::Row {
                folder: folder.id,
                row: row_of(&message),
                downloaded: message.body == BodyState::Downloaded,
            }
        }
    };
    Ok(Undo {
        seq: action.seq,
        restore,
    })
}

/// Takes an action back if it hasn't gone to the server yet. Returns false
/// when it's too late (already replayed).
pub fn undo(local: &mut Local<'_>, undo: &Undo) -> Result<bool> {
    if !local.journal.pending().any(|action| action.seq == undo.seq) {
        return Ok(false);
    }
    local.journal.done(undo.seq)?;
    match &undo.restore {
        Restore::Flags { folder, uid, flags } => {
            local.db.step(|db| db.set_flags(*folder, *uid, *flags))?;
        }
        Restore::Row {
            folder,
            row,
            downloaded,
        } => {
            local.db.step(|db| {
                let id = db.upsert_message(*folder, row)?;
                if *downloaded {
                    db.set_body_state(id, BodyState::Downloaded)?;
                }
                Ok(())
            })?;
        }
    }
    Ok(true)
}
```

```rust
use envio_store::{BodyState, Folder, FolderId, MessageRowId};

/// Brings the account's folder list in line with the server's and returns

    server: &mut impl MailServer,
    local: &mut Local<'_>,
    account: &str,
) -> Result<Vec<Folder>> {

    let changes = plan_folders(&listed, &local.db.folders(account)?);
    local.db.step(|db| {
        for (path, role) in &changes.upsert {

        }
        for id in &changes.remove {
            db.remove_folder(*id)?;
        }
        Ok(())
    })?;

    }

/// What one folder sync changed, for core's notices and counts.
#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub struct Synced {
    pub fetched: usize,
    pub removed: usize,
    pub flags_changed: usize,
}

/// Syncs one folder: reset on a new UIDVALIDITY, drop what's gone, update
/// flags, fetch what's new (newest first), then store the folder's state.
pub async fn sync_folder(
    server: &mut impl MailServer,
    local: &mut Local<'_>,
    id: FolderId,
    now_ms: i64,
) -> Result<Synced> {
    let folder = local.db.folder(id)?;
    let state = server.select(&folder.path).await?;
    let window = server.search_since(window_start(now_ms)).await?;
    let pending = Pending::of(
        local.journal.pending(),
        &folder.account,
        &folder.path,
        state.uid_validity,
    );
    let cached_uids = local.db.uids(id)?;
    let plan = plan_folder(
        &FolderView {
            server: state,
            window: &window,
            cached: folder.sync,
            cached_uids: &cached_uids,
            condstore: server.caps().condstore,
        },
        &pending,
    );
    begin(local, id, &plan)?;
    let mut synced = Synced {
        removed: local.db.step(|db| db.delete_messages(id, &plan.remove))?,
        ..Synced::default()
    };
    synced.flags_changed = check_flags(server, local, id, (&plan, &pending)).await?;
    for batch in &plan.fetch {
        let summaries = server.fetch_summaries(batch).await?;
        let rows = rows(&summaries, &pending);
        local.db.step(|db| {
            for row in &rows {
                db.upsert_message(id, row)?;
            }
            Ok(())
        })?;
        synced.fetched += rows.len();
    }
    local.db.step(|db| db.set_sync_state(id, &plan.finish))?;
    Ok(synced)
}

fn begin(local: &Local<'_>, id: FolderId, plan: &FolderPlan) -> Result<()> {
    let Some(begin) = plan.begin else {
        return Ok(());
    };
    local.db.step(|db| {
        if plan.reset {
            db.reset_folder(id)?;
        }
        db.set_sync_state(id, &begin)
    })?;
    if plan.reset {
        local.bodies.remove_folder(id)?;
    }
    Ok(())
}

/// Applies the server's flag changes; returns how many cached messages
/// changed.
async fn check_flags(
    server: &mut impl MailServer,
    local: &Local<'_>,
    id: FolderId,
    (plan, pending): (&FolderPlan, &Pending),
) -> Result<usize> {
    let since = match plan.flags {
        FlagCheck::Skip => return Ok(0),
        FlagCheck::ChangedSince(modseq) => Some(modseq),
        FlagCheck::All => None,
    };
    let updates = server.fetch_flags(&plan.check, since).await?;
    let changes = plan_flags(&local.db.flags_by_uid(id)?, &updates, pending);
    local.db.step(|db| {
        for (uid, flags) in &changes.set {
            db.set_flags(id, *uid, *flags)?;
        }
        db.delete_messages(id, &changes.remove)
    })?;
    Ok(changes.set.len() + changes.remove.len())
}

/// Downloads a message's body when it's opened: written to disk, then the
/// row gets its preview and is marked downloaded. `None` when the message
/// is gone from the server (its row is dropped) or the folder needs a sync
/// first (its UIDVALIDITY changed).
pub async fn fetch_body(
    server: &mut impl MailServer,
    local: &mut Local<'_>,
    id: MessageRowId,
) -> Result<Option<Vec<u8>>> {
    let message = local.db.message(id)?;
    let folder = local.db.folder(message.folder)?;
    let state = server.select(&folder.path).await?;
    if folder.sync.map(|sync| sync.uidvalidity) != Some(state.uid_validity) {
        return Ok(None);
    }
    let size = usize::try_from(message.size).unwrap_or(usize::MAX);
    let Some(eml) = server.fetch_body(message.uid, size).await? else {
        local
            .db
            .step(|db| db.delete_messages(folder.id, &[message.uid]))?;
        return Ok(None);
    };
    local.bodies.write(folder.id, message.uid, &eml)?;
    let row = with_body(&message, &eml);
    local.db.step(|db| {
        db.upsert_message(folder.id, &row)?;
        db.set_body_state(id, BodyState::Downloaded)
    })?;
    Ok(Some(eml))
}
```

```rust
//! Sends due journal actions to the server, oldest first.

use envio_net::NetError;
use envio_store::{Action, ActionKind, FolderRole};

use super::Local;
use super::folders::apply_flags;
use crate::convert::net_flags;
use crate::error::{ErrorKind, Result};
use crate::plan::pending::Pending;
use crate::plan::replay::{
    Find, MoveRoute, Outcome, ServerOp, find, is_due, move_route, outcome, server_op,
};
use crate::schedule::Key;
use crate::server::MailServer;

/// What a replay run did.
#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct Replayed {
    /// Actions that reached the server (or whose message is gone).
    pub done: usize,
    /// Refused for good and undone locally; core shows a notice for each.
    pub reverted: Vec<Action>,
    /// Why the run stopped early, if it did. Temporary: the action waits
    /// out its backoff. Sign-in or certificate: the account pauses.
    pub stopped: Option<ErrorKind>,
}

/// Replays the account's due actions. Stops at the first error that isn't
/// the server refusing one action, since the session is gone after it.
pub async fn replay(
    server: &mut impl MailServer,
    local: &mut Local<'_>,
    account: &str,
    now_ms: i64,
) -> Result<Replayed> {
    let due: Vec<Action> = local
        .journal
        .pending()
        .filter(|action| action.target.account == account)
        .filter(|action| is_due(action, local.schedule, now_ms))
        .cloned()
        .collect();
    let trash = local
        .db
        .folders(account)?
        .into_iter()
        .find(|folder| folder.role == FolderRole::Trash)
        .map(|folder| folder.path);
    let mut replayed = Replayed::default();
    for action in due {
        let result = apply(server, &action, trash.as_deref()).await;
        let key = Key::Action(action.seq);
        match outcome(result.as_ref().copied()) {
            Outcome::Done => {
                local.journal.done(action.seq)?;
                local.schedule.succeeded(&key);
                replayed.done += 1;
            }
            Outcome::Revert => {
                local.journal.done(action.seq)?;
                local.schedule.succeeded(&key);
                revert(server, local, &action).await?;
                replayed.reverted.push(action);
            }
            Outcome::Retry => {
                local.schedule.failed(key, now_ms);
                replayed.stopped = Some(ErrorKind::Temporary);
                break;
            }
            Outcome::Stop(kind) => {
                replayed.stopped = Some(kind);
                break;
            }
        }
    }
    if replayed.done > 0 || !replayed.reverted.is_empty() {
        local.journal.compact()?;
    }
    Ok(replayed)
}

/// Runs one action. A message or folder that's gone counts as done: there
/// is nothing left to change.
async fn apply(
    server: &mut impl MailServer,
    action: &Action,
    trash: Option<&str>,
) -> std::result::Result<(), NetError> {
    let state = match server.select(&action.target.folder).await {
        Err(NetError::Refused(_)) => return Ok(()),
        selected => selected?,
    };
    let uid = match find(&action.target, state.uid_validity) {
        Find::Uid(uid) => uid,
        Find::ByMessageId(id) => match server.search_message_id(&id).await?.first() {
            Some(uid) => *uid,
            None => return Ok(()),
        },
        Find::Lost => return Ok(()),
    };
    match server_op(action, trash) {
        ServerOp::SetFlags { add, remove } => {
            for (set, flags) in [(true, add), (false, remove)] {
                let flags = net_flags(flags);
                if !flags.is_empty() {
                    server.store_flags(&[uid], set, &flags).await?;
                }
            }
            Ok(())
        }
        ServerOp::Move { to } => move_message(server, action, uid, &to).await,
        ServerOp::Expunge => server.delete(&[uid]).await,
    }
}

/// Without MOVE, a retry after a cut between COPY and the delete would
/// copy twice, so look in the target first.
async fn move_message(
    server: &mut impl MailServer,
    action: &Action,
    uid: u32,
    to: &str,
) -> std::result::Result<(), NetError> {
    let route = move_route(server.caps().r#move, action.target.message_id.as_deref());
    let MoveRoute::CheckTarget(message_id) = route else {
        return server.move_to(&[uid], to).await;
    };
    server.select(to).await?;
    let copied = !server.search_message_id(&message_id).await?.is_empty();
    server.select(&action.target.folder).await?;
    if copied {
        server.delete(&[uid]).await
    } else {
        server.move_to(&[uid], to).await
    }
}

/// Puts the cache back after the server refused an action. A flag change
/// takes the server's flags again; a moved or deleted row comes back on
/// the folder's next sync, as nothing hides it any more.
async fn revert(server: &mut impl MailServer, local: &Local<'_>, action: &Action) -> Result<()> {
    let ActionKind::SetFlags { .. } = action.kind else {
        return Ok(());
    };
    let target = &action.target;
    let Some(folder) = local.db.folder_by_path(&target.account, &target.folder)? else {
        return Ok(());
    };
    if folder.sync.map(|sync| sync.uidvalidity) != Some(target.uidvalidity) {
        return Ok(());
    }
    let updates = server.fetch_flags(&[target.uid], None).await?;
    let pending = Pending::of(
        local.journal.pending(),
        &target.account,
        &target.folder,
        target.uidvalidity,
    );
    apply_flags(local, folder.id, &updates, &pending)?;
    Ok(())
}
```

```rust
//! One account as a whole: a sync run, and removing the account.

use envio_store::{Drafts, FolderId, SendState};

use super::Local;
use super::folders::{Synced, sync_folder, sync_folders};
use super::replay::{Replayed, replay};
use crate::error::Result;
use crate::plan::folders::sync_order;
use crate::plan::outbox::{ItemStep, item_step};
use crate::schedule::Key;
use crate::server::MailServer;

/// What a sync run did.
#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct AccountSynced {
    pub replayed: Replayed,
    /// In the order they were synced.
    pub folders: Vec<(FolderId, Synced)>,
}

/// One sync run over IMAP: the folder list, then the user's due actions
/// (so the server shows them before folders are compared), then each
/// folder, Inbox first. A replay that stopped ends the run: the session is
/// gone or the account is paused.
pub async fn sync_account(
    server: &mut impl MailServer,
    local: &mut Local<'_>,
    account: &str,
    now_ms: i64,
) -> Result<AccountSynced> {
    let folders = sync_folders(server, local, account).await?;
    let mut synced = AccountSynced {
        replayed: replay(server, local, account, now_ms).await?,
        folders: Vec::new(),
    };
    if synced.replayed.stopped.is_some() {
        return Ok(synced);
    }
    for id in sync_order(&folders) {
        let one = sync_folder(server, local, id, now_ms).await?;
        synced.folders.push((id, one));
    }
    Ok(synced)
}

/// Whether a run needs SMTP: an Outbox item of the account is Queued and
/// past its backoff.
pub fn has_due_mail(local: &Local<'_>, account: &str, now_ms: i64) -> Result<bool> {
    Ok(local.outbox.items()?.iter().any(|item| {
        item.meta.account == account
            && item_step(&item.meta.state) == ItemStep::Send
            && local.schedule.is_due(&Key::Outbox(item.id.clone()), now_ms)
    }))
}

/// The account's unsent work, for the warning before it's removed.
#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub struct Unsent {
    /// Outbox items not yet accepted by the server (Queued, Sending, May
    /// have been sent, Failed). Accepted ones only wait for filing.
    pub outbox: usize,
    pub drafts: usize,
    /// Actions not yet on the server.
    pub actions: usize,
}

pub fn unsent(local: &Local<'_>, drafts: &Drafts, account: &str) -> Result<Unsent> {
    Ok(Unsent {
        outbox: local
            .outbox
            .items()?
            .iter()
            .filter(|item| item.meta.account == account)
            .filter(|item| item.meta.state != SendState::Accepted)
            .count(),
        drafts: drafts
            .list()?
            .iter()
            .filter(|(_, draft)| draft.account == account)
            .count(),
        actions: local
            .journal
            .pending()
            .filter(|action| action.target.account == account)
            .count(),
    })
}

/// Removes everything Envio holds for an account: its pending actions,
/// Outbox items and drafts (core asks first, showing `unsent`), then its
/// cache and bodies. The password and pins are core's to remove.
pub fn remove_account(local: &mut Local<'_>, drafts: &Drafts, account: &str) -> Result<()> {
    let actions: Vec<u64> = local
        .journal
        .pending()
        .filter(|action| action.target.account == account)
        .map(|action| action.seq)
        .collect();
    for seq in actions {
        local.journal.done(seq)?;
        local.schedule.succeeded(&Key::Action(seq));
    }
    local.journal.compact()?;
    for item in local.outbox.items()? {
        if item.meta.account == account {
            local.outbox.remove(&item.id)?;
            local.schedule.succeeded(&Key::Outbox(item.id));
        }
    }
    for (id, draft) in drafts.list()? {
        if draft.account == account {
            drafts.delete(&id)?;
        }
    }
    for folder in local.db.step(|db| db.remove_account_cache(account))? {
        local.bodies.remove_folder(folder)?;
    }
    Ok(())
}
```

```rust
//! Sends queued Outbox items and files them in Sent. An item leaves the
//! Outbox only when the server accepted it and it is in Sent, or when its
//! Message-ID turns up in Sent. Nothing is ever resent on its own.

use envio_net::imap::Flag;
use envio_store::{FolderRole, OutboxItem, SendState};

use super::Local;
use crate::error::{ErrorKind, Result};
use crate::plan::outbox::{ItemStep, after_send, item_step};
use crate::schedule::Key;
use crate::server::{MailSender, MailServer};

/// What a send run did, by Outbox item id.
#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct Sent {
    pub accepted: Vec<String>,
    /// Refused for good: shown as failed with the server's reason.
    pub failed: Vec<String>,
    /// The connection broke after the message was handed over: it may have
    /// been sent. `file_sent` looks for it in Sent.
    pub unconfirmed: Vec<String>,
    /// Temporary: the item waits out its backoff. Sign-in or certificate:
    /// the account pauses.
    pub stopped: Option<ErrorKind>,
}

/// Sends the account's due Queued items, oldest first. Stops at the first
/// error: the SMTP session is not reused after one.
pub async fn send_outbox(
    sender: &mut impl MailSender,
    local: &mut Local<'_>,
    account: &str,
    now_ms: i64,
) -> Result<Sent> {
    let mut sent = Sent::default();
    for item in items(local, account)? {
        let key = Key::Outbox(item.id.clone());
        if item_step(&item.meta.state) != ItemStep::Send || !local.schedule.is_due(&key, now_ms) {
            continue;
        }
        let eml = local.outbox.eml(&item.id)?;
        local.outbox.set_state(&item.id, SendState::Sending)?;
        let result = sender
            .send(&item.meta.from, &item.meta.recipients, &eml)
            .await;
        let after = after_send(&result);
        local.outbox.set_state(&item.id, after.state.clone())?;
        match after.state {
            SendState::Accepted => sent.accepted.push(item.id.clone()),
            SendState::Failed { .. } => sent.failed.push(item.id.clone()),
            SendState::MayHaveBeenSent => sent.unconfirmed.push(item.id.clone()),
            SendState::Queued | SendState::Sending => {}
        }
        if after.retry {
            local.schedule.failed(key, now_ms);
            sent.stopped = Some(ErrorKind::Temporary);
        } else {
            local.schedule.succeeded(&key);
            sent.stopped = after.stop;
        }
        if result.is_err() {
            break;
        }
    }
    Ok(sent)
}

/// What filing did, by Outbox item id.
#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct Filed {
    /// Done: in Sent and out of the Outbox.
    pub removed: Vec<String>,
    /// May have been sent and not found in Sent: the user decides (Send
    /// again, or Move to Sent).
    pub ask: Vec<String>,
}

/// Files accepted items in Sent (APPEND, unless the server does it itself
/// or the account has no Sent folder) and looks in Sent for items that may
/// have been sent. A retried APPEND first checks Sent, so a cut never
/// files a message twice.
pub async fn file_sent(
    server: &mut impl MailServer,
    local: &mut Local<'_>,
    account: &str,
    files_itself: bool,
) -> Result<Filed> {
    let sent_folder = local
        .db
        .folders(account)?
        .into_iter()
        .find(|folder| folder.role == FolderRole::Sent)
        .map(|folder| folder.path);
    let mut filed = Filed::default();
    for item in items(local, account)? {
        let step = item_step(&item.meta.state);
        if !matches!(step, ItemStep::File | ItemStep::Resolve) {
            continue;
        }
        let done = match &sent_folder {
            Some(path) if step == ItemStep::Resolve || !files_itself => {
                server.select(path).await?;
                let found = !server
                    .search_message_id(&item.meta.message_id)
                    .await?
                    .is_empty();
                if !found && step == ItemStep::File {
                    let eml = local.outbox.eml(&item.id)?;
                    server.append(path, &[Flag::Seen], &eml).await?;
                }
                found || step == ItemStep::File
            }
            // Gmail files it itself; with no Sent folder there's nowhere
            // to file it. Only an accepted item counts as done then.
            _ => step == ItemStep::File,
        };
        if done {
            local.outbox.remove(&item.id)?;
            filed.removed.push(item.id);
        } else {
            filed.ask.push(item.id);
        }
    }
    Ok(filed)
}

/// The account's readable Outbox items, oldest first.
fn items(local: &Local<'_>, account: &str) -> Result<Vec<OutboxItem>> {
    let mut items: Vec<OutboxItem> = local
        .outbox
        .items()?
        .into_iter()
        .filter(|item| item.meta.account == account)
        .collect();
    items.sort_by_key(|item| item.meta.queued_at_ms);
    Ok(items)
}
```

```rust
    fn below(&mut self, n: u64) -> u64 {
        self.0 ^= self.0 << 13;
        self.0 ^= self.0 >> 7;
        self.0 ^= self.0 << 17;

    }

/// Fails the test if a message the server took (or may have taken) is
/// handed over again; keeps the messages the server accepted.
#[derive(Default)]
struct Recording {
    inner: FakeSender,
    taken: HashSet<Vec<u8>>,
    accepted: Vec<String>,
}

impl MailSender for Recording {
    async fn send(&mut self, from: &str, to: &[String], eml: &[u8]) -> Result<(), SendError> {
        assert!(!self.taken.contains(eml), "resent a message");
        let result = self.inner.send(from, to, eml).await;
        match &result {
            Ok(()) => self
                .accepted
                .push(String::from_utf8_lossy(eml).into_owned()),
            Err(error) if !error.unconfirmed => return result,
            Err(_) => {}
        }
        self.taken.insert(eml.to_vec());
        result
    }

fn send_result(rng: &mut Rng) -> Result<(), SendError> {
    let (error, unconfirmed) = match rng.below(5) {
        0 => return Ok(()),
        1 => (NetError::Timeout, true),
        2 => (NetError::Busy("421 later".into()), false),
        3 => (NetError::Refused("550 no".into()), false),
        _ => (NetError::SignIn("535 no".into()), false),
    };
    Err(SendError { error, unconfirmed })
}
```
