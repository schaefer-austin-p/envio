Drafts list, status chip (tint A)
Every local draft with no current server copy gets a row here with the Not uploaded status chip (tint A, same ink as other tint A elements): never tried, offline, or refused by the server (#266). Once it uploads, the server row takes its place, matched by Message-ID, so a draft never shows twice. Tap opens it in Compose at once. Any other row opens the reader. Rows show To, not From. Long-press selects; no swipe actions.

In a Drafts-role folder the reader's Reply, Reply all and Forward are gone, from the bottom bar and from More. The bottom bar is one filled Edit button with a pencil. Delete stays and removes the server copy and the local file (#284). Archive and Move are hidden, here and in the Drafts list's selection bar: a draft moved anywhere but Trash would leave its local file behind, so Delete is the only way out. A draft made on another device (no local file): Edit makes a local draft from the server message and records that server copy, so the first save replaces it on the server instead of adding a duplicate.
