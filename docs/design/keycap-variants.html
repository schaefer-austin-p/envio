Keycap variants for the shortcut chip (#434)
Comparison sheet. Each variant at 1x in Carbon and Airmail, light and dark, on the dialog surface. Airmail labels use the UI font (Theme.fontLabel).
Every variant is plain QtQuick 2.15 Rectangles (no shaders, no QtGraphicalEffects), with colours derived from Theme tokens so all four palettes follow. Light skirts derive from hairline; dark skirts from ground, because the dark hairline is barely darker than the surface and a skirt from it would vanish. Once one is picked, frame 7 of carbon-two-pane.html gets updated and the chip rebuilt.
