Icon rules
Icon sizeSheet rows 24 px (theme.iconSize); menu rows 20 px. Always drawn on the 24 grid and scaled, so the 2 px stroke is 2 px at 24 and 1.67 px at 20.
Stroke2 on the 24 grid, round caps, round joins, no fill. Lucide as it ships.
Icon to textSheet rows 16 px (2 gu); menu rows 12 px (1.5 gu); icons inside buttons 8 px (as the existing boards).
InsetsSheet rows keep the 20 px side inset; the icon starts there and the text starts at 60 px. Captions start at the text column, not under the icon. Menu rows keep 16 px padding; the menu stays 200 px wide.
Row heightUnchanged: 48 px minimum (theme.touch). A two-line row grows; its icon is centred on the text block.
Colour, normalThe icon takes the label's colour: text, not accent or heading. One rule for icon and label means a disabled or destructive row changes both.
Colour, destructiveaccent for icon and label (Remove, Delete, Sign in again). Discard draft stays in text as built today (it asks first); see the open question.
Colour, disabledsecondary for icon and label (Cut and Copy with nothing selected). Pressed and highlighted rows keep the selected fill; the icon does not change.
Dark modeNo separate icon colours: the same roles resolve to their dark values (Dark section). Text and accent on ground already reach 4.5:1, so the icon, a graphic needing 3:1, passes.
Titles, CancelA sheet's title and the Cancel button have no icon. Buttons that perform an action (Open, Copy) take a 20 px icon before the label.
Check or radioIcon in the leading slot, a 22 px check at the trailing edge for the chosen row. RadioRow (Settings) is unchanged and never carries an icon.
Folder rowsMove sheet: role icon by folder role, folder for folders without one; child folders keep today's per-level indent (16 px), applied to the icon too.

Custom icons

None needed. Every item has a stock Lucide icon, so nothing is drawn by hand. Where the label is abstract the closest fit was taken (Add sender to Contacts: user-plus; Move to folder: folder-input). If a later feature has no fit, it is drawn on the same 24 grid, 2 px stroke, round caps and joins, and listed here.

Notes for the implementation step

Lucide ships line, rect, circle and path elements; the svg map in Icon.qml takes path strings, so each shape is converted to path data (arc flags space-separated, as that file's comment requires). Version pinned: lucide-static@0.460.0; the sprite at the top of this file is that version, unmodified.
